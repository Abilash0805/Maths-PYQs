@topic Chain rule
Differential of $\log\left[\log\left(\log x^5\right)\right]$ w.r.t. $x$ is
(A) $\dfrac{5}{x\log(x^5)\log(\log x^5)}$
(B) $\dfrac{5}{x\log(\log x^5)}$
(C) $\dfrac{5x^4}{\log(x^5)\log(\log x^5)}$
(D) $\dfrac{5x^4}{\log x^5\log(\log x^5)}$
--- ans A
Let $y = \log\left[\log\left(\log x^5\right)\right]$. By the chain rule,
$$\frac{dy}{dx} = \frac{1}{\log(\log x^5)} \cdot \frac{1}{\log x^5} \cdot \frac{1}{x^5} \cdot 5x^4 = \frac{5}{x\log(x^5)\log(\log x^5)}$$

@topic Maximum and minimum values
A function $f : \mathbb{R} \to \mathbb{R}$ is defined as $f(x) = x^3 + 1$. Then the function has
(A) no minimum value
(B) no maximum value
(C) both maximum and minimum values
(D) neither maximum value nor minimum value
--- ans D
$f'(x) = 3x^2 \ge 0$ for all $x$, with $f'(x) = 0$ only at $x = 0$, so $f$ is strictly increasing on $\mathbb{R}$ ($x = 0$ is a point of inflexion, not an extremum).
Also $f(x) \to \infty$ as $x \to \infty$ and $f(x) \to -\infty$ as $x \to -\infty$.
Hence $f$ has **neither a maximum nor a minimum value**.

@topic Implicit differentiation
If $\sin y = x\cos(a + y)$, then $\dfrac{dx}{dy}$ is
(A) $\dfrac{\cos a}{\cos^2(a + y)}$
(B) $\dfrac{-\cos a}{\cos^2(a + y)}$
(C) $\dfrac{\cos a}{\sin^2 y}$

$x = \dfrac{\sin y}{\cos(a + y)}$. Differentiating w.r.t. $y$ (quotient rule):

@topic Implicit differentiation
If $(x^2 + y^2)^2 = xy$, then $\dfrac{dy}{dx}$ is
(A) $\dfrac{y + 4x(x^2 + y^2)}{4y(x^2 + y^2) - x}$

Let $X = \{x^2 : x \in \mathbb{N}\}$ and the function $f : \mathbb{N} \to X$ is defined by $f(x) = x^2,\ x \in \mathbb{N}$. Then this function is
