=== 3 | de | 2 | sub
@topic Variable separable
Find the general solution of the differential equation: $\dfrac{dy}{dx} = \dfrac{3e^{2x} + 3e^{4x}}{e^x + e^{-x}}$
--- ans
$$\frac{dy}{dx} = \frac{3e^{2x}(1 + e^{2x})}{e^{-x}(e^{2x} + 1)} = 3e^{2x}\cdot e^{x} = 3e^{3x}$$
$$\Rightarrow dy = 3e^{3x}\,dx$$
Integrating both sides:
$$y = 3\cdot\frac{e^{3x}}{3} + C \Rightarrow y = e^{3x} + C$$
is the general solution.

@topic Shortest distance between lines
Find the shortest distance between the following lines:
$$\vec{r} = 3\hat{i} + 5\hat{j} + 7\hat{k} + \lambda(\hat{i} - 2\hat{j} + \hat{k}) \quad\text{and}\quad \vec{r} = (-\hat{i} - \hat{j} - \hat{k}) + \mu(7\hat{i} - 6\hat{j} + \hat{k})$$
--- ans
Here $\vec{a}_1 = 3\hat{i} + 5\hat{j} + 7\hat{k}$, $\vec{b}_1 = \hat{i} - 2\hat{j} + \hat{k}$, $\vec{a}_2 = -\hat{i} - \hat{j} - \hat{k}$, $\vec{b}_2 = 7\hat{i} - 6\hat{j} + \hat{k}$.
$$\vec{a}_2 - \vec{a}_1 = -4\hat{i} - 6\hat{j} - 8\hat{k}$$
$$\vec{b}_1 \times \vec{b}_2 = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 1 & -2 & 1 \\ 7 & -6 & 1 \end{vmatrix} = (-2 + 6)\hat{i} - (1 - 7)\hat{j} + (-6 + 14)\hat{k} = 4\hat{i} + 6\hat{j} + 8\hat{k}$$
$|\vec{b}_1 \times \vec{b}_2| = \sqrt{16 + 36 + 64} = \sqrt{116} = 2\sqrt{29}$
$$d = \frac{\left|(\vec{a}_2 - \vec{a}_1) \cdot (\vec{b}_1 \times \vec{b}_2)\right|}{|\vec{b}_1 \times \vec{b}_2|} = \frac{|-16 - 36 - 64|}{\sqrt{116}} = \frac{116}{\sqrt{116}} = \sqrt{116} = 2\sqrt{29}\ \text{units}$$

=== 10 | int | 3 | sub
@topic Properties of definite integrals
Evaluate: $\displaystyle\int_{-\pi/2}^{\pi/2} \left(\sin|x| + \cos|x|\right)dx$
--- ans
Let $f(x) = \sin|x| + \cos|x|$. Then $f(-x) = \sin|-x| + \cos|-x| = f(x)$, so $f$ is even.
$$\therefore\ I = 2\int_0^{\pi/2}\left(\sin|x| + \cos|x|\right)dx = 2\int_0^{\pi/2}(\sin x + \cos x)\,dx \quad(\because |x| = x \text{ for } x \ge 0)$$
$$= 2\Big[-\cos x + \sin x\Big]_0^{\pi/2} = 2\left[(0 + 1) - (-1 + 0)\right] = 2(2) = 4$$

=== 13 | aoi | 4 | sub
@topic Area under a curve
Find the area of the region enclosed by the curves $y^2 = x$, $x = \dfrac{1}{4}$, $y \ge 0$ and $x = 1$, using integration.
--- ans
For $y \ge 0$, the curve is $y = \sqrt{x}$. The region lies under $y = \sqrt{x}$, above the X-axis, between the ordinates $x = \dfrac{1}{4}$ and $x = 1$.

```plot
{"x":[-0.3,1.5],"y":[-0.4,1.4],"fns":[{"f":"sqrt(x)","from":0,"to":1.45,"label":"y² = x (y ≥ 0)"}],"lines":[{"a":1,"b":0,"c":0.25,"label":"x = 1/4"},{"a":1,"b":0,"c":1,"label":"x = 1"}],"areas":[{"upper":"sqrt(x)","lower":"0","from":0.25,"to":1}],"points":[{"x":0.25,"y":0.5,"label":"(1/4, 1/2)"},{"x":1,"y":1,"label":"(1, 1)"}]}
```

$$A = \int_{1/4}^{1} \sqrt{x}\,dx = \left[\frac{2}{3}x^{3/2}\right]_{1/4}^{1} = \frac{2}{3}\left[1 - \left(\frac{1}{4}\right)^{3/2}\right] = \frac{2}{3}\left[1 - \frac{1}{8}\right] = \frac{2}{3}\cdot\frac{7}{8} = \frac{7}{12}$$
Required area $= \dfrac{7}{12}$ sq. units.
