@topic Rate of change
The volume of a sphere is increasing at the rate of $8\ \text{cm}^3/\text{s}$. Find the rate at which its surface area is increasing when the radius of the sphere is 12 cm.
--- ans
$V = \dfrac{4}{3}\pi r^3$, $S = 4\pi r^2$, $\dfrac{dV}{dt} = 8\ \text{cm}^3/\text{s}$.
$$\frac{dV}{dt} = 4\pi r^2\frac{dr}{dt} \Rightarrow \frac{dr}{dt} = \frac{8}{4\pi r^2} = \frac{2}{\pi r^2}$$
$$\frac{dS}{dt} = 8\pi r\frac{dr}{dt} = 8\pi r\cdot\frac{2}{\pi r^2} = \frac{16}{r}$$
At $r = 12$ cm: $\dfrac{dS}{dt} = \dfrac{16}{12} = \boxed{\dfrac{4}{3}\ \text{cm}^2/\text{s}}$

@topic Partial fractions
Find : $\displaystyle\int \frac{e^x\,dx}{(e^x - 1)^2(e^x + 2)}$
--- ans
Put $e^x = t$, $e^x\,dx = dt$: $\quad I = \displaystyle\int \frac{dt}{(t - 1)^2(t + 2)}$.
$$\frac{1}{(t - 1)^2(t + 2)} = \frac{A}{t + 2} + \frac{B}{t - 1} + \frac{C}{(t - 1)^2} \Rightarrow 1 = A(t - 1)^2 + B(t - 1)(t + 2) + C(t + 2)$$
$t = 1$: $1 = 3C \Rightarrow C = \dfrac{1}{3}$. $\quad t = -2$: $1 = 9A \Rightarrow A = \dfrac{1}{9}$. $\quad$ Coefficient of $t^2$: $A + B = 0 \Rightarrow B = -\dfrac{1}{9}$.
$$I = \frac{1}{9}\int\frac{dt}{t + 2} - \frac{1}{9}\int\frac{dt}{t - 1} + \frac{1}{3}\int\frac{dt}{(t - 1)^2} = \frac{1}{9}\log|t + 2| - \frac{1}{9}\log|t - 1| - \frac{1}{3(t - 1)} + c$$
$$\boxed{I = \dfrac{1}{9}\log\left|\dfrac{e^x + 2}{e^x - 1}\right| - \dfrac{1}{3(e^x - 1)} + c}$$

@topic Scalar product and projection
If $\vec{a} = 2\hat{i} - \hat{j} - 2\hat{k}$ and $\vec{b} = 7\hat{i} + 2\hat{j} - 3\hat{k}$, then express $\vec{b}$ in the form of $\vec{b} = \vec{b}_1 + \vec{b}_2$, where $\vec{b}_1$ is parallel to $\vec{a}$ and $\vec{b}_2$ is perpendicular to $\vec{a}$.
--- ans
Since $\vec{b}_1 \parallel \vec{a}$, let $\vec{b}_1 = \lambda\vec{a} = 2\lambda\hat{i} - \lambda\hat{j} - 2\lambda\hat{k}$. Then
$$\vec{b}_2 = \vec{b} - \vec{b}_1 = (7 - 2\lambda)\hat{i} + (2 + \lambda)\hat{j} + (-3 + 2\lambda)\hat{k}$$
$\vec{b}_2 \perp \vec{a} \Rightarrow \vec{b}_2\cdot\vec{a} = 0$:
$$2(7 - 2\lambda) - (2 + \lambda) - 2(-3 + 2\lambda) = 0 \Rightarrow 18 - 9\lambda = 0 \Rightarrow \lambda = 2$$
$\vec{b}_1 = 4\hat{i} - 2\hat{j} - 4\hat{k}$, $\quad\vec{b}_2 = 3\hat{i} + 4\hat{j} + \hat{k}$ (check: $\vec{b}_2\cdot\vec{a} = 6 - 4 - 2 = 0$).
$$\boxed{7\hat{i} + 2\hat{j} - 3\hat{k} = (4\hat{i} - 2\hat{j} - 4\hat{k}) + (3\hat{i} + 4\hat{j} + \hat{k})}$$

@topic Linear differential equations
Find the general solution of the differential equation
$$\frac{dy}{dx} - y = \sin x.$$
--- ans
Linear in $y$ with $P = -1$, $Q = \sin x$. $\quad\text{I.F.} = e^{\int -1\,dx} = e^{-x}$.
$$ye^{-x} = \int e^{-x}\sin x\,dx = I_1$$
Integrating by parts twice:
$$I_1 = -e^{-x}\sin x + \int e^{-x}\cos x\,dx = -e^{-x}\sin x - e^{-x}\cos x - \int e^{-x}\sin x\,dx = -e^{-x}(\sin x + \cos x) - I_1$$
$$\Rightarrow I_1 = -\frac{1}{2}e^{-x}(\sin x + \cos x)$$
$$ye^{-x} = -\frac{1}{2}e^{-x}(\sin x + \cos x) + c \Rightarrow \boxed{y = -\dfrac{1}{2}(\sin x + \cos x) + ce^x}$$

=== 29 | aod | 6 | sub
@topic Optimisation problems
A window is in the form of a rectangle surmounted by a semicircular opening. The total perimeter of the window is 10 m. Find the dimensions of the window to admit maximum light through the whole opening.
--- ans
Let the width of the rectangle be $x$ m (the diameter of the semicircle, radius $\frac{x}{2}$) and its height $y$ m.
Perimeter: $x + 2y + \pi\dfrac{x}{2} = 10 \Rightarrow y = 5 - \dfrac{x}{2} - \dfrac{\pi x}{4}$.
Maximum light means maximum area:
$$A = xy + \frac{1}{2}\pi\left(\frac{x}{2}\right)^2 = x\left(5 - \frac{x}{2} - \frac{\pi x}{4}\right) + \frac{\pi x^2}{8} = 5x - \frac{x^2}{2} - \frac{\pi x^2}{8}$$
$$\frac{dA}{dx} = 5 - x - \frac{\pi x}{4} = 0 \Rightarrow x\left(1 + \frac{\pi}{4}\right) = 5 \Rightarrow x = \frac{20}{4 + \pi}$$
$$\frac{d^2A}{dx^2} = -1 - \frac{\pi}{4} < 0$$
so $A$ is maximum at $x = \dfrac{20}{4 + \pi}$. Then
$$y = 5 - \frac{x(2 + \pi)}{4} = 5 - \frac{5(2 + \pi)}{4 + \pi} = \frac{10}{4 + \pi}$$
**Dimensions for maximum light:** width of rectangle $= \dfrac{20}{4 + \pi}$ m, height of rectangle $= \dfrac{10}{4 + \pi}$ m (radius of the semicircle $= \dfrac{10}{4 + \pi}$ m).
