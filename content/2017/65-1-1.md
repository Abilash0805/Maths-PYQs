@topic Symmetric and skew-symmetric matrices
Show that all the diagonal elements of a skew symmetric matrix are zero.
--- ans
Let $A = [a_{ij}]_{n \times n}$ be a skew symmetric matrix. Then $A' = -A$, i.e.
$$a_{ji} = -a_{ij} \quad \text{for all } i, j$$
For a diagonal element put $j = i$:
$$a_{ii} = -a_{ii} \Rightarrow 2a_{ii} = 0 \Rightarrow a_{ii} = 0$$
Hence all the diagonal elements of a skew symmetric matrix are zero.

@topic Chain rule and implicit differentiation
Find $\dfrac{dy}{dx}$ at $x = 1,\ y = \dfrac{\pi}{4}$ if $\sin^2 y + \cos xy = K$.
--- ans
Differentiating both sides w.r.t. $x$:
$$2\sin y\cos y\,\frac{dy}{dx} - \sin xy\left(x\frac{dy}{dx} + y\right) = 0$$
$$\Rightarrow \frac{dy}{dx}\left(\sin 2y - x\sin xy\right) = y\sin xy \Rightarrow \frac{dy}{dx} = \frac{y\sin xy}{\sin 2y - x\sin xy}$$
At $x = 1,\ y = \dfrac{\pi}{4}$: $\sin xy = \sin\dfrac{\pi}{4} = \dfrac{1}{\sqrt{2}}$, $\sin 2y = \sin\dfrac{\pi}{2} = 1$.
$$\frac{dy}{dx} = \frac{\frac{\pi}{4}\cdot\frac{1}{\sqrt{2}}}{1 - \frac{1}{\sqrt{2}}} = \frac{\pi}{4(\sqrt{2} - 1)}$$

@topic Rate of change
The volume of a sphere is increasing at the rate of 3 cubic centimeter per second. Find the rate of increase of its surface area, when the radius is 2 cm.
--- ans
Let $r$ be the radius, $V$ the volume and $S$ the surface area at time $t$.
$$V = \frac{4}{3}\pi r^3 \Rightarrow \frac{dV}{dt} = 4\pi r^2\frac{dr}{dt} \Rightarrow \frac{dr}{dt} = \frac{3}{4\pi r^2}$$
$$S = 4\pi r^2 \Rightarrow \frac{dS}{dt} = 8\pi r\frac{dr}{dt} = 8\pi r\cdot\frac{3}{4\pi r^2} = \frac{6}{r}$$
At $r = 2$ cm: $\dfrac{dS}{dt} = \dfrac{6}{2} = 3\ \text{cm}^2/\text{s}$.

=== 10 | prob | 2 | sub
@topic Multiplication theorem and independent events
Prove that if E and F are independent events, then the events E and F' are also independent.
--- ans
Since E and F are independent, $P(E \cap F) = P(E)\,P(F)$.
E is the union of the mutually exclusive events $E \cap F$ and $E \cap F'$, so
$$P(E \cap F') = P(E) - P(E \cap F) = P(E) - P(E)P(F) = P(E)\big[1 - P(F)\big] = P(E)\,P(F')$$
Hence E and F' are independent events.

@topic Simplification
Prove that $\tan\left\{\dfrac{\pi}{4} + \dfrac{1}{2}\cos^{-1}\dfrac{a}{b}\right\} + \tan\left\{\dfrac{\pi}{4} - \dfrac{1}{2}\cos^{-1}\dfrac{a}{b}\right\} = \dfrac{2b}{a}$
--- ans
Let $\dfrac{1}{2}\cos^{-1}\dfrac{a}{b} = \theta$. Then $\cos^{-1}\dfrac{a}{b} = 2\theta \Rightarrow \cos 2\theta = \dfrac{a}{b}$.

LHS $= \tan\left(\dfrac{\pi}{4} + \theta\right) + \tan\left(\dfrac{\pi}{4} - \theta\right)$
$$= \frac{1 + \tan\theta}{1 - \tan\theta} + \frac{1 - \tan\theta}{1 + \tan\theta} = \frac{(1 + \tan\theta)^2 + (1 - \tan\theta)^2}{1 - \tan^2\theta}$$
$$= \frac{2(1 + \tan^2\theta)}{1 - \tan^2\theta} = \frac{2}{\left(\dfrac{1 - \tan^2\theta}{1 + \tan^2\theta}\right)} = \frac{2}{\cos 2\theta}$$
$$= \frac{2}{a/b} = \frac{2b}{a} = \text{RHS}$$
Hence proved.

@topic Logarithmic differentiation
Differentiate the function $(\sin x)^x + \sin^{-1}\sqrt{x}$ with respect to $x$.
--- ans
Let $y = u + v$, where $u = (\sin x)^x$ and $v = \sin^{-1}\sqrt{x}$. Then $\dfrac{dy}{dx} = \dfrac{du}{dx} + \dfrac{dv}{dx}$.

$\log u = x\log\sin x$. Differentiating w.r.t. $x$:
$$\frac{1}{u}\frac{du}{dx} = \log\sin x + x\cdot\frac{\cos x}{\sin x} \Rightarrow \frac{du}{dx} = (\sin x)^x\left[x\cot x + \log\sin x\right]$$
$$\frac{dv}{dx} = \frac{1}{\sqrt{1 - x}}\cdot\frac{1}{2\sqrt{x}} = \frac{1}{2\sqrt{x - x^2}}$$
$$\therefore\ \frac{dy}{dx} = (\sin x)^x\left[x\cot x + \log\sin x\right] + \frac{1}{2\sqrt{x - x^2}}$$

=== 15b | cd | 4 | sub
@topic Second order derivatives
If $x^m y^n = (x + y)^{m + n}$, prove that $\dfrac{d^2y}{dx^2} = 0$.
--- ans
Taking logarithm: $m\log x + n\log y = (m + n)\log(x + y)$.
Differentiating w.r.t. $x$:
$$\frac{m}{x} + \frac{n}{y}\frac{dy}{dx} = \frac{m + n}{x + y}\left(1 + \frac{dy}{dx}\right)$$
$$\Rightarrow \frac{dy}{dx}\left[\frac{n}{y} - \frac{m + n}{x + y}\right] = \frac{m + n}{x + y} - \frac{m}{x}$$
$$\Rightarrow \frac{dy}{dx}\cdot\frac{nx - my}{y(x + y)} = \frac{nx - my}{x(x + y)} \Rightarrow \frac{dy}{dx} = \frac{y}{x} \quad\cdots(1)$$
Differentiating (1) w.r.t. $x$:
$$\frac{d^2y}{dx^2} = \frac{x\dfrac{dy}{dx} - y}{x^2} = \frac{x\cdot\dfrac{y}{x} - y}{x^2} = 0 \quad\text{(using (1))}$$
Hence proved.

Find $\displaystyle\int \frac{2x}{(x^2 + 1)(x^2 + 2)^2}\,dx$
--- ans

=== 18 | de | 4 | sub
@topic Homogeneous equations
Prove that $x^2 - y^2 = c(x^2 + y^2)^2$ is the general solution of the differential equation $(x^3 - 3xy^2)\,dx = (y^3 - 3x^2y)\,dy$, where C is a parameter.
--- ans
$$\frac{dy}{dx} = \frac{x^3 - 3xy^2}{y^3 - 3x^2y}$$
The right side is a homogeneous function of degree 0, so put $y = vx$, $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{1 - 3v^2}{v^3 - 3v} \Rightarrow x\frac{dv}{dx} = \frac{1 - 3v^2 - v^4 + 3v^2}{v^3 - 3v} = \frac{1 - v^4}{v^3 - 3v}$$
$$\Rightarrow \frac{v(v^2 - 3)}{(1 - v^2)(1 + v^2)}\,dv = \frac{dx}{x}$$
Put $v^2 = t$, $2v\,dv = dt$, and use $\dfrac{t - 3}{(1 - t)(1 + t)} = \dfrac{-1}{1 - t} + \dfrac{-2}{1 + t}$:
$$\frac{1}{2}\int\left(\frac{-1}{1 - t} - \frac{2}{1 + t}\right)dt = \int \frac{dx}{x}$$
$$\Rightarrow \frac{1}{2}\Big[\log|1 - t| - 2\log|1 + t|\Big] = \log|x| + \log k \Rightarrow \frac{|1 - v^2|}{(1 + v^2)^2} = k^2x^2$$
Replacing $v = \dfrac{y}{x}$ (and absorbing the sign into the constant):
$$\frac{(x^2 - y^2)/x^2}{(x^2 + y^2)^2/x^4} = cx^2 \Rightarrow \frac{x^2(x^2 - y^2)}{(x^2 + y^2)^2} = cx^2$$
$$\Rightarrow x^2 - y^2 = c\left(x^2 + y^2\right)^2$$
This contains one arbitrary constant and the equation is of order 1, so it is the general solution. Hence proved.

=== 22 | prob | 4 | sub
@topic Total probability and Bayes' theorem
Often it is taken that a truthful person commands, more respect in the society. A man is known to speak the truth 4 out of 5 times. He throws a die and reports that it is a six. Find the probability that it is actually a six.

--- ans

@topic Optimisation problems
If the sum of lengths of the hypotenuse and a side of a right angled triangle is given, show that the area of the triangle is maximum, when the angle between them is $\dfrac{\pi}{3}$.
--- ans
Let ABC be right-angled at B, with side $BC = x$ and hypotenuse $AC = y$, and let $\theta$ be the angle between them, so $\cos\theta = \dfrac{x}{y}$.
Given $x + y = k$ (constant), so $y = k - x$ with $0 < x < \dfrac{k}{2}$. Then $AB = \sqrt{y^2 - x^2}$ and the area is
$$S = \frac{1}{2}x\sqrt{y^2 - x^2} = \frac{1}{2}x\sqrt{(k - x)^2 - x^2} = \frac{1}{2}x\sqrt{k^2 - 2kx}$$
$S$ is maximum when $Z = S^2 = \dfrac{1}{4}\left(k^2x^2 - 2kx^3\right)$ is maximum.
$$\frac{dZ}{dx} = \frac{1}{4}\left(2k^2x - 6kx^2\right) = \frac{kx}{2}(k - 3x) = 0 \Rightarrow x = \frac{k}{3}$$
$$\frac{d^2Z}{dx^2} = \frac{1}{4}\left(2k^2 - 12kx\right); \quad \left.\frac{d^2Z}{dx^2}\right|_{x = k/3} = \frac{1}{4}\left(2k^2 - 4k^2\right) = -\frac{k^2}{2} < 0$$
So the area is maximum when $x = \dfrac{k}{3}$, i.e. $y = k - \dfrac{k}{3} = \dfrac{2k}{3} = 2x$.
$$\therefore\ \cos\theta = \frac{x}{y} = \frac{1}{2} \Rightarrow \theta = \frac{\pi}{3}$$
Hence the area is maximum when the angle between the hypotenuse and the side is $\dfrac{\pi}{3}$.

Solve the differential equation $x\dfrac{dy}{dx} + y = x\cos x + \sin x$, given that $y = 1$ when $x = \dfrac{\pi}{2}$
--- ans
Dividing by $x$:

I.F. $= e^{\int \frac{1}{x}dx} = e^{\log x} = x$.
Solution: $\displaystyle y\cdot x = \int x\left(\cos x + \frac{\sin x}{x}\right)dx + c = \int (x\cos x + \sin x)\,dx + c$
Since $\displaystyle\int x\cos x\,dx = x\sin x + \cos x$ and $\displaystyle\int \sin x\,dx = -\cos x$:
$$xy = x\sin x + c$$
When $x = \dfrac{\pi}{2}$, $y = 1$: $\dfrac{\pi}{2} = \dfrac{\pi}{2}\cdot 1 + c \Rightarrow c = 0$.
$\therefore$ The required particular solution is $\boxed{y = \sin x}$
