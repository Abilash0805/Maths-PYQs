@topic Rate of change
The length $x$, of a rectangle is decreasing at the rate of 5 cm/minute and the width $y$, is increasing at the rate of 4 cm/minute. When $x = 8$ cm and $y = 6$ cm, find the rate of change of the area of the rectangle.
--- ans
Given $\dfrac{dx}{dt} = -5$ cm/min and $\dfrac{dy}{dt} = 4$ cm/min. Area $A = xy$.
$$\frac{dA}{dt} = x\frac{dy}{dt} + y\frac{dx}{dt} = 8(4) + 6(-5) = 32 - 30 = 2$$
**The area is increasing at the rate of $2\ \text{cm}^2/\text{minute}$.**

@topic Partial fractions
Find : $\displaystyle\int \frac{\sin\theta\,d\theta}{(4 + \cos^2\theta)(2 - \sin^2\theta)}$
--- ans
$2 - \sin^2\theta = 1 + \cos^2\theta$. Put $\cos\theta = t$, $-\sin\theta\,d\theta = dt$:
$$I = -\int \frac{dt}{(4 + t^2)(1 + t^2)}$$
Treating $t^2 = u$: $\dfrac{1}{(4 + u)(1 + u)} = \dfrac{1}{3}\left(\dfrac{1}{1 + u} - \dfrac{1}{4 + u}\right)$.
$$I = -\frac{1}{3}\int\frac{dt}{1 + t^2} + \frac{1}{3}\int\frac{dt}{4 + t^2} = -\frac{1}{3}\tan^{-1}t + \frac{1}{3}\cdot\frac{1}{2}\tan^{-1}\frac{t}{2} + c$$
$$\boxed{I = \dfrac{1}{6}\tan^{-1}\left(\dfrac{\cos\theta}{2}\right) - \dfrac{1}{3}\tan^{-1}(\cos\theta) + c}$$

@topic Graphical method – bounded region
Solve the following linear programming problem graphically:
Maximise $Z = 34x + 45y$
under the following constraints
$$x + y \le 300,\quad 2x + 3y \le 70,\quad x \ge 0,\ y \ge 0$$
--- ans
Draw $x + y = 300$ (through $(300, 0), (0, 300)$) and $2x + 3y = 70$ (through $(35, 0), \left(0, \frac{70}{3}\right)$). The origin satisfies both inequalities, so the feasible region is on the origin side of both lines. Since every point with $2x + 3y \le 70$, $x, y \ge 0$ already has $x + y \le 35 < 300$, the first constraint is redundant and the feasible region is the triangle OBA.

@topic Linear differential equations
Find the general solution of the differential equation $y\,dx - (x + 2y^2)\,dy = 0$
--- ans
$$y\frac{dx}{dy} = x + 2y^2 \Rightarrow \frac{dx}{dy} - \frac{1}{y}\,x = 2y$$
Linear in $x$ with $P = -\dfrac{1}{y}$, $Q = 2y$. $\quad\text{I.F.} = e^{\int -\frac{1}{y}dy} = e^{-\log y} = \dfrac{1}{y}$.
$$x\cdot\frac{1}{y} = \int 2y\cdot\frac{1}{y}\,dy = 2y + c$$
$$\boxed{x = 2y^2 + cy}$$

@topic Optimisation problems
AB is the diameter of a circle and C is any point on the circle. Show that the area of triangle ABC is maximum, when it is an isosceles triangle.
--- ans
Let $r$ be the radius, so $AB = 2r$. The angle in a semicircle is a right angle, so $\angle ACB = 90^\circ$.
Let $AC = x$, $BC = y$. Then $x^2 + y^2 = 4r^2 \Rightarrow y = \sqrt{4r^2 - x^2}$, and
$$\text{Area } A = \frac{1}{2}xy = \frac{1}{2}x\sqrt{4r^2 - x^2}$$
$A$ is maximum when $S = A^2 = \dfrac{1}{4}(4r^2x^2 - x^4)$ is maximum ($0 < x < 2r$).
$$\frac{dS}{dx} = \frac{1}{4}(8r^2x - 4x^3) = x(2r^2 - x^2)$$
$\dfrac{dS}{dx} = 0 \Rightarrow x^2 = 2r^2 \Rightarrow x = \sqrt{2}\,r$.
$$\frac{d^2S}{dx^2} = 2r^2 - 3x^2 = 2r^2 - 6r^2 = -4r^2 < 0 \text{ at } x = \sqrt{2}\,r$$
So the area is maximum at $x = \sqrt{2}\,r$, and then $y = \sqrt{4r^2 - 2r^2} = \sqrt{2}\,r = x$.
Thus $AC = BC$: the area of $\triangle ABC$ is maximum when it is **isosceles**.
