@topic Evaluation of determinants
If A is a skew-symmetric matrix of order 3, then prove that $\det A = 0$.
--- ans
A is skew-symmetric, so $A' = -A$. Taking determinants (order $n = 3$):
$$|A'| = |-A| = (-1)^3|A| = -|A|$$
But $|A'| = |A|$. Hence $|A| = -|A| \Rightarrow 2|A| = 0 \Rightarrow |A| = 0$.
(Alternatively, $A = \begin{bmatrix} 0 & a & b \\ -a & 0 & c \\ -b & -c & 0 \end{bmatrix} \Rightarrow |A| = 0 - a(0 + bc) + b(ac - 0) = 0$.)
Hence $\det A = 0$.

@topic Rate of change
The volume of a cube is increasing at the rate of $9\ \text{cm}^3/\text{s}$. How fast is its surface area increasing when the length of an edge is 10 cm ?
--- ans
Let the edge be $x$, volume $V = x^3$, surface area $S = 6x^2$. Given $\dfrac{dV}{dt} = 9\ \text{cm}^3/\text{s}$.
$$\frac{dV}{dt} = 3x^2\frac{dx}{dt} \Rightarrow \frac{dx}{dt} = \frac{9}{3x^2} = \frac{3}{x^2}$$
$$\frac{dS}{dt} = 12x\frac{dx}{dt} = 12x\cdot\frac{3}{x^2} = \frac{36}{x}$$
At $x = 10$ cm: $\dfrac{dS}{dt} = \dfrac{36}{10} = \boxed{3.6\ \text{cm}^2/\text{s}}$

Show that the function $f(x) = x^3 - 3x^2 + 6x - 100$ is increasing on $\mathbb{R}$.
--- ans
$$f'(x) = 3x^2 - 6x + 6 = 3(x^2 - 2x + 2) = 3\left[(x - 1)^2 + 1\right]$$

@topic Multiplication theorem and independent events
A die, whose faces are marked 1, 2, 3 in red and 4, 5, 6 in green, is tossed. Let A be the event "number obtained is even" and B be the event "number obtained is red". Find the A and B are independent events.
--- ans

$$P(A) = \frac{3}{6} = \frac{1}{2},\quad P(B) = \frac{3}{6} = \frac{1}{2},\quad P(A \cap B) = \frac{1}{6}$$

@topic Simplification
If $\tan^{-1}\dfrac{x - 3}{x - 4} + \tan^{-1}\dfrac{x + 3}{x + 4} = \dfrac{\pi}{4}$, then find the value of $x$.
--- ans
Let $\alpha = \tan^{-1}\dfrac{x - 3}{x - 4}$ and $\beta = \tan^{-1}\dfrac{x + 3}{x + 4}$, so $\tan\alpha = \dfrac{x - 3}{x - 4}$, $\tan\beta = \dfrac{x + 3}{x + 4}$ and $\alpha + \beta = \dfrac{\pi}{4}$.
Taking tangent of both sides and using $\tan(\alpha + \beta) = \dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$:
$$\frac{\frac{x - 3}{x - 4} + \frac{x + 3}{x + 4}}{1 - \frac{x - 3}{x - 4}\cdot\frac{x + 3}{x + 4}} = \tan\frac{\pi}{4} = 1$$
Numerator: $\dfrac{(x - 3)(x + 4) + (x + 3)(x - 4)}{x^2 - 16} = \dfrac{2x^2 - 24}{x^2 - 16}$; denominator: $\dfrac{(x^2 - 16) - (x^2 - 9)}{x^2 - 16} = \dfrac{-7}{x^2 - 16}$.
$$\frac{2x^2 - 24}{-7} = 1 \Rightarrow 2x^2 = 17 \Rightarrow x^2 = \frac{17}{2} \Rightarrow x = \pm\sqrt{\frac{17}{2}}$$
Check: for $x^2 = \frac{17}{2}$ ($|x| < 3$), both fractions $\dfrac{x - 3}{x - 4}$ and $\dfrac{x + 3}{x + 4}$ are positive, so $\alpha, \beta \in \left(0, \dfrac{\pi}{2}\right)$ and $\alpha + \beta \in (0, \pi)$; the only angle in $(0, \pi)$ with tangent 1 is $\dfrac{\pi}{4}$. So both values satisfy the equation.
$$\boxed{x = \pm\sqrt{\dfrac{17}{2}}}$$

@topic Logarithmic differentiation
If $x^y + y^x = a^b$, then find $\dfrac{dy}{dx}$.
--- ans
Let $u = x^y$ and $v = y^x$, so $u + v = a^b \Rightarrow \dfrac{du}{dx} + \dfrac{dv}{dx} = 0$. $\quad\ldots(1)$
$\log u = y\log x \Rightarrow \dfrac{1}{u}\dfrac{du}{dx} = \dfrac{y}{x} + \log x\dfrac{dy}{dx} \Rightarrow \dfrac{du}{dx} = x^y\left[\dfrac{y}{x} + \log x\dfrac{dy}{dx}\right]$
$\log v = x\log y \Rightarrow \dfrac{1}{v}\dfrac{dv}{dx} = \log y + \dfrac{x}{y}\dfrac{dy}{dx} \Rightarrow \dfrac{dv}{dx} = y^x\left[\log y + \dfrac{x}{y}\dfrac{dy}{dx}\right]$
Substituting in (1):
$$yx^{y-1} + x^y\log x\frac{dy}{dx} + y^x\log y + xy^{x-1}\frac{dy}{dx} = 0$$
$$\boxed{\dfrac{dy}{dx} = -\dfrac{y^x\log y + yx^{y-1}}{x^y\log x + xy^{x-1}}}$$

@topic Second order derivatives
If $e^y(x + 1) = 1$, then show that $\dfrac{d^2y}{dx^2} = \left(\dfrac{dy}{dx}\right)^2$.
--- ans
Differentiating $e^y(x + 1) = 1$ w.r.t. $x$:
$$e^y + (x + 1)e^y\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\frac{1}{x + 1}$$
Differentiating again:
$$\frac{d^2y}{dx^2} = \frac{1}{(x + 1)^2} = \left(-\frac{1}{x + 1}\right)^2 = \left(\frac{dy}{dx}\right)^2$$
Hence proved.

@topic Properties of definite integrals
Evaluate: $\displaystyle\int_0^{\pi} \frac{x\tan x}{\sec x + \tan x}\,dx$
--- ans
$I = \displaystyle\int_0^{\pi} \frac{x\tan x}{\sec x + \tan x}\,dx \quad\ldots(1)$
Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$, with $\tan(\pi - x) = -\tan x$, $\sec(\pi - x) = -\sec x$:
$$I = \int_0^{\pi} \frac{(\pi - x)\tan x}{\sec x + \tan x}\,dx \quad\ldots(2)$$
Adding (1) and (2):
$$2I = \pi\int_0^{\pi} \frac{\tan x}{\sec x + \tan x}\,dx = \pi\int_0^{\pi} \tan x(\sec x - \tan x)\,dx \quad(\because \sec^2 x - \tan^2 x = 1)$$
$$= \pi\int_0^{\pi}(\sec x\tan x - \sec^2 x + 1)\,dx = \pi\Big[\sec x - \tan x + x\Big]_0^{\pi}$$
(Here $\sec x - \tan x = \dfrac{1 - \sin x}{\cos x} = \dfrac{\cos x}{1 + \sin x}$ is continuous on $[0, \pi]$.)
$$2I = \pi\left[(-1 - 0 + \pi) - (1 - 0 + 0)\right] = \pi(\pi - 2) \Rightarrow \boxed{I = \dfrac{\pi(\pi - 2)}{2}}$$

@topic Total probability and Bayes' theorem
Of the students in a school, it is known that 30% have 100% attendance and 70% students are irregular. Previous year results report that 70% of all students who have 100% attendance attain A grade and 10% irregular students attain A grade in their annual examination. At the end of the year, one students is chosen at random from the school and he was found to have an A grade. What is the probability that the student has 100% attendance? Is regularity required only in school ? justify your answer.
--- ans
Let $E_1$: student has 100% attendance, $E_2$: student is irregular, $A$: student attains A grade.
$$P(E_1) = \frac{30}{100},\quad P(E_2) = \frac{70}{100},\quad P(A \mid E_1) = \frac{70}{100},\quad P(A \mid E_2) = \frac{10}{100}$$
By Bayes' theorem,
$$P(E_1 \mid A) = \frac{P(E_1)P(A \mid E_1)}{P(E_1)P(A \mid E_1) + P(E_2)P(A \mid E_2)} = \frac{0.3 \times 0.7}{0.3 \times 0.7 + 0.7 \times 0.1} = \frac{0.21}{0.28} = \boxed{\dfrac{3}{4}}$$
No. Regularity (punctuality and discipline) is required in every sphere of life, not only in school: regular, disciplined work leads to success everywhere.

@topic Optimisation problems
Show that the surface area of a closed cuboid with square base and given volume is minimum, when it is a cube.
--- ans
Let the base be a square of side $x$ and the height be $y$. Volume $V = x^2y = k$ (constant) $\Rightarrow y = \dfrac{k}{x^2}$.
Surface area:
$$S = 2(x^2 + xy + xy) = 2x^2 + 4xy = 2x^2 + \frac{4k}{x}$$
$$\frac{dS}{dx} = 4x - \frac{4k}{x^2}$$
$\dfrac{dS}{dx} = 0 \Rightarrow x^3 = k = x^2y \Rightarrow x = y$.
$$\frac{d^2S}{dx^2} = 4 + \frac{8k}{x^3} > 0$$
So $S$ is minimum when $x = y$, i.e. when length = breadth = height.
Hence the surface area is minimum when the cuboid is a **cube**.

@topic Homogeneous equations
Find the particular solution of the differential equation $(x - y)\dfrac{dy}{dx} = (x + 2y)$, given that $y = 0$ when $x = 1$.
--- ans
$\dfrac{dy}{dx} = \dfrac{x + 2y}{x - y} = \dfrac{1 + 2\frac{y}{x}}{1 - \frac{y}{x}}$ is homogeneous. Put $y = vx$, $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{1 + 2v}{1 - v} \Rightarrow x\frac{dv}{dx} = \frac{1 + 2v - v + v^2}{1 - v} = \frac{v^2 + v + 1}{1 - v}$$
$$\int\frac{1 - v}{v^2 + v + 1}\,dv = \int\frac{dx}{x}$$
Write $1 - v = -\dfrac{1}{2}(2v + 1) + \dfrac{3}{2}$:
$$-\frac{1}{2}\int\frac{2v + 1}{v^2 + v + 1}\,dv + \frac{3}{2}\int\frac{dv}{\left(v + \frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = \log|x| + C$$
$$-\frac{1}{2}\log|v^2 + v + 1| + \frac{3}{2}\cdot\frac{2}{\sqrt{3}}\tan^{-1}\frac{2v + 1}{\sqrt{3}} = \log|x| + C$$
Multiplying by $-2$: $\log|v^2 + v + 1| + 2\log|x| - 2\sqrt{3}\tan^{-1}\dfrac{2v + 1}{\sqrt{3}} = C_1$. With $v = \dfrac{y}{x}$:
$$\log|x^2 + xy + y^2| - 2\sqrt{3}\tan^{-1}\left(\frac{x + 2y}{\sqrt{3}\,x}\right) = C_1$$
At $x = 1$, $y = 0$: $\log 1 - 2\sqrt{3}\tan^{-1}\dfrac{1}{\sqrt{3}} = -2\sqrt{3}\cdot\dfrac{\pi}{6} = -\dfrac{\pi}{\sqrt{3}} = C_1$.
$$\boxed{\log|x^2 + xy + y^2| = 2\sqrt{3}\tan^{-1}\left(\dfrac{x + 2y}{\sqrt{3}\,x}\right) - \dfrac{\pi}{\sqrt{3}}}$$
