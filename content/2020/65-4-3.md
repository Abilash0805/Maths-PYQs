@topic Simplification
The value of $\tan\left[\dfrac{1}{2}\cos^{-1}\left(\dfrac{\sqrt{5}}{3}\right)\right]$ is
(A) $\dfrac{3 + \sqrt{5}}{2}$
(B) $\dfrac{3 - \sqrt{5}}{2}$
(C) $\dfrac{-3 + \sqrt{5}}{2}$
(D) $\dfrac{-3 - \sqrt{5}}{2}$
--- ans B
Let $\cos^{-1}\dfrac{\sqrt{5}}{3} = \theta$, so $\cos\theta = \dfrac{\sqrt{5}}{3}$, $\theta \in \left(0, \dfrac{\pi}{2}\right)$ and $\tan\dfrac{\theta}{2} > 0$.
$$\tan\frac{\theta}{2} = \sqrt{\frac{1 - \cos\theta}{1 + \cos\theta}} = \sqrt{\frac{3 - \sqrt{5}}{3 + \sqrt{5}}} = \sqrt{\frac{(3 - \sqrt{5})^2}{9 - 5}} = \frac{3 - \sqrt{5}}{2}$$

@topic Differentiability
Fill in the blank:
If $f(x) = x|x|$, then $f'(x) = $ ..................
--- ans
$f(x) = \begin{cases} x^2, & x \ge 0 \\ -x^2, & x < 0 \end{cases}$, so $f'(x) = 2x$ for $x > 0$ and $f'(x) = -2x$ for $x < 0$.
At $x = 0$: $\displaystyle\lim_{h \to 0}\frac{h|h|}{h} = \lim_{h \to 0}|h| = 0$, so $f'(0) = 0$.
Hence $f'(x) = \mathbf{2|x|}$ for all $x \in \mathbb{R}$.

@topic Partial fractions
Find $\displaystyle\int \frac{1}{x(1 + x^2)}\,dx$
--- ans
$$\frac{1}{x(1 + x^2)} = \frac{(1 + x^2) - x^2}{x(1 + x^2)} = \frac{1}{x} - \frac{x}{1 + x^2}$$
$$\int \frac{dx}{x(1 + x^2)} = \log|x| - \frac{1}{2}\log(1 + x^2) + C = \frac{1}{2}\log\left(\frac{x^2}{1 + x^2}\right) + C$$

=== 20 | int | 1 | sub
@topic Properties of definite integrals
If $[x]$ denotes the greatest integer function, then find $\displaystyle\int_0^{3/2} [x^2]\,dx$
--- ans
On $[0, \tfrac{3}{2}]$, $x^2 \in [0, \tfrac{9}{4}]$, so
$[x^2] = 0$ for $0 \le x < 1$, $[x^2] = 1$ for $1 \le x < \sqrt{2}$, $[x^2] = 2$ for $\sqrt{2} \le x \le \dfrac{3}{2}$.
$$\int_0^{3/2} [x^2]\,dx = \int_0^1 0\,dx + \int_1^{\sqrt{2}} 1\,dx + \int_{\sqrt{2}}^{3/2} 2\,dx = (\sqrt{2} - 1) + 2\left(\frac{3}{2} - \sqrt{2}\right) = 2 - \sqrt{2}$$

=== 25 | aod | 2 | sub
@topic Increasing and decreasing functions
Show that the function $f(x) = \dfrac{x}{3} + \dfrac{3}{x}$ decreases in the intervals $(-3, 0) \cup (0, 3)$.
--- ans
$$f'(x) = \frac{1}{3} - \frac{3}{x^2} = \frac{x^2 - 9}{3x^2} = \frac{(x - 3)(x + 3)}{3x^2}, \quad x \ne 0$$
For $x \in (-3, 0) \cup (0, 3)$: $x^2 < 9$, so $x^2 - 9 < 0$, while $3x^2 > 0$.
$\therefore\ f'(x) < 0$, so $f$ is decreasing in $(-3, 0)$ and in $(0, 3)$.

=== 26 | prob | 2 | sub
@topic Conditional probability
Three distinct numbers are chosen randomly from the first 50 natural numbers. Find the probability that all the three numbers are divisible by both 2 and 3.
--- ans
A number is divisible by both 2 and 3 iff it is divisible by 6. Multiples of 6 among $1, 2, \dots, 50$: $6, 12, 18, 24, 30, 36, 42, 48$, i.e. 8 numbers.
$$P = \frac{{}^8C_3}{{}^{50}C_3} = \frac{8 \times 7 \times 6}{50 \times 49 \times 48} = \frac{336}{117600} = \frac{1}{350}$$

=== 31 | int | 4 | sub
@topic Special forms
Evaluate $\displaystyle\int_0^1 \sqrt{3 - 2x - x^2}\,dx$
--- ans
$$3 - 2x - x^2 = 4 - (x^2 + 2x + 1) = 2^2 - (x + 1)^2$$
Put $x + 1 = t \Rightarrow dx = dt$; when $x = 0$, $t = 1$ and when $x = 1$, $t = 2$.
Using $\displaystyle\int \sqrt{a^2 - t^2}\,dt = \frac{t}{2}\sqrt{a^2 - t^2} + \frac{a^2}{2}\sin^{-1}\frac{t}{a} + C$:
$$\int_1^2 \sqrt{4 - t^2}\,dt = \left[\frac{t}{2}\sqrt{4 - t^2} + 2\sin^{-1}\frac{t}{2}\right]_1^2$$
$$= \left[0 + 2\cdot\frac{\pi}{2}\right] - \left[\frac{1}{2}\sqrt{3} + 2\cdot\frac{\pi}{6}\right] = \pi - \frac{\sqrt{3}}{2} - \frac{\pi}{3} = \frac{2\pi}{3} - \frac{\sqrt{3}}{2}$$
$$\therefore\ \int_0^1 \sqrt{3 - 2x - x^2}\,dx = \frac{4\pi - 3\sqrt{3}}{6}$$

=== 32 | de | 4 | sub
@topic Variable separable
Find the general solution of the differential equation $\dfrac{dy}{dx} + \dfrac{1}{x} = \dfrac{e^y}{x}$.
--- ans
$$\frac{dy}{dx} = \frac{e^y - 1}{x} \Rightarrow \frac{dy}{e^y - 1} = \frac{dx}{x} \Rightarrow \frac{e^{-y}\,dy}{1 - e^{-y}} = \frac{dx}{x}$$
Put $1 - e^{-y} = t \Rightarrow e^{-y}\,dy = dt$:
$$\int \frac{dt}{t} = \int \frac{dx}{x} \Rightarrow \log|1 - e^{-y}| = \log|x| + \log|C|$$
$\therefore$ The general solution is
$$1 - e^{-y} = Cx \quad \left(\text{equivalently } e^y = \frac{1}{1 - Cx}\right)$$
