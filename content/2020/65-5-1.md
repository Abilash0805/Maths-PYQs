A card is picked at random from a pack of 52 playing cards. Given that the picked card is a queen, the probability of this card to be a card of spade is

@topic Local maxima and minima
Fill in the blank:
The least value of the function $f(x) = ax + \dfrac{b}{x}$ $(a > 0,\ b > 0,\ x > 0)$ is ..................
--- ans
$f'(x) = a - \dfrac{b}{x^2} = 0 \Rightarrow x = \sqrt{\dfrac{b}{a}}$ (as $x > 0$).
$f''(x) = \dfrac{2b}{x^3} > 0$ for $x > 0$, so $f$ has its minimum at $x = \sqrt{b/a}$ (the only critical point in $(0, \infty)$).

@topic Principal values
Solve for $x$ : $\sin^{-1}(1 - x) - 2\sin^{-1}(x) = \dfrac{\pi}{2}$.
--- ans
Let $\sin^{-1}x = \theta$, so $x = \sin\theta$ with $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$. The equation becomes
$$\sin^{-1}(1 - x) = \frac{\pi}{2} + 2\theta$$

=== 28 | cd | 4 | sub
@topic Logarithmic differentiation
If $y = (\log x)^x + x^{\log x}$, then find $\dfrac{dy}{dx}$.
--- ans
Let $u = (\log x)^x$ and $v = x^{\log x}$, so $y = u + v$ and $\dfrac{dy}{dx} = \dfrac{du}{dx} + \dfrac{dv}{dx}$.

**For $u$:** $\log u = x\log(\log x)$. Differentiating w.r.t. $x$:
$$\frac{1}{u}\frac{du}{dx} = \log(\log x) + x\cdot\frac{1}{\log x}\cdot\frac{1}{x} \Rightarrow \frac{du}{dx} = (\log x)^x\left[\log(\log x) + \frac{1}{\log x}\right]$$

**For $v$:** $\log v = \log x \cdot \log x = (\log x)^2$. Differentiating w.r.t. $x$:
$$\frac{1}{v}\frac{dv}{dx} = \frac{2\log x}{x} \Rightarrow \frac{dv}{dx} = x^{\log x}\cdot\frac{2\log x}{x} = 2x^{\log x - 1}\log x$$

$$\therefore\ \frac{dy}{dx} = (\log x)^x\left[\frac{1}{\log x} + \log(\log x)\right] + 2x^{\log x - 1}\log x$$

@topic Word problems
A company manufactures two types of novelty souvenirs made of plywood. Souvenirs of type A requires 5 minutes each for cutting and 10 minutes each for assembling. Souvenirs of type B require 8 minutes each for cutting and 8 minutes each for assembling. Given that total time for cutting is 3 hours 20 minutes and for assembling 4 hours. The profit for type A souvenir is ₹ 100 each and for type B souvenir, profit is ₹ 120 each. How many souvenirs of each type should the company manufacture in order to maximize the profit? Formulate the problem as an LPP and solve it graphically.
--- ans
Let the company manufacture $x$ souvenirs of type A and $y$ souvenirs of type B.
Cutting time available $= 3$ h 20 min $= 200$ min; assembling time $= 4$ h $= 240$ min.

**LPP:** Maximise $Z = 100x + 120y$
subject to
$5x + 8y \le 200$ (cutting)
$10x + 8y \le 240$ (assembling)
$x \ge 0,\ y \ge 0$

Lines: $5x + 8y = 200$ through $(40, 0)$, $(0, 25)$; $10x + 8y = 240$ through $(24, 0)$, $(0, 30)$.
Both inequalities hold at $(0, 0)$, so the feasible region is on the origin side of both lines in the first quadrant.
Intersection: subtracting, $5x = 40 \Rightarrow x = 8$, then $8y = 160 \Rightarrow y = 20$, i.e. $(8, 20)$.


| Corner point | $Z = 100x + 120y$ (₹) |
|---|---|
| $O(0, 0)$ | $0$ |
| $A(24, 0)$ | $2400$ |
| $B(8, 20)$ | $3200$ ← maximum |
| $C(0, 25)$ | $3000$ |

$\therefore$ The company should make **8 souvenirs of type A and 20 souvenirs of type B**; maximum profit $=$ **₹ 3200**.

@topic Optimisation problems
Find the minimum value of $(ax + by)$, where $xy = c^2$.
--- ans
(Here $a, b, c$ are positive constants and $x, y > 0$, as intended in the question.)
From $xy = c^2$: $y = \dfrac{c^2}{x}$. Let
$$S = ax + by = ax + \frac{bc^2}{x}, \quad x > 0$$
$$\frac{dS}{dx} = a - \frac{bc^2}{x^2}$$
For critical points, $\dfrac{dS}{dx} = 0 \Rightarrow x^2 = \dfrac{bc^2}{a} \Rightarrow x = c\sqrt{\dfrac{b}{a}}$ (taking $x > 0$).
$$\frac{d^2S}{dx^2} = \frac{2bc^2}{x^3} > 0 \text{ at } x = c\sqrt{\frac{b}{a}}$$
So $S$ is minimum at $x = c\sqrt{\dfrac{b}{a}}$, where $y = \dfrac{c^2}{x} = c\sqrt{\dfrac{a}{b}}$.
$$S_{\min} = a\cdot c\sqrt{\frac{b}{a}} + b\cdot c\sqrt{\frac{a}{b}} = c\sqrt{ab} + c\sqrt{ab} = 2c\sqrt{ab}$$
$\therefore$ Minimum value of $ax + by$ is $\boxed{2c\sqrt{ab}}$.

@topic Evaluation of determinants
If $a, b, c$ are $p^{\text{th}}$, $q^{\text{th}}$ and $r^{\text{th}}$ terms respectively of a G.P., then prove that
$$\begin{vmatrix} \log a & p & 1 \\ \log b & q & 1 \\ \log c & r & 1 \end{vmatrix} = 0$$
--- ans
Let the G.P. have first term $\alpha$ and common ratio $\beta$ (terms positive, so that the logarithms are defined). Then
$$a = \alpha\beta^{p-1},\quad b = \alpha\beta^{q-1},\quad c = \alpha\beta^{r-1}$$
Writing $u = \log\alpha$, $v = \log\beta$:
$$\log a = u + (p - 1)v,\quad \log b = u + (q - 1)v,\quad \log c = u + (r - 1)v$$
Expanding the determinant $\Delta$ along $C_1$:
$$\Delta = \log a\,(q - r) - \log b\,(p - r) + \log c\,(p - q) = \log a\,(q - r) + \log b\,(r - p) + \log c\,(p - q)$$
Substituting:
$$\Delta = u\big[(q - r) + (r - p) + (p - q)\big] + v\big[(p - 1)(q - r) + (q - 1)(r - p) + (r - 1)(p - q)\big]$$
The first bracket is $0$. The second bracket is
$$\big[p(q - r) + q(r - p) + r(p - q)\big] - \big[(q - r) + (r - p) + (p - q)\big] = 0 - 0 = 0$$
$$\therefore\ \Delta = 0. \quad \text{Hence proved.}$$
