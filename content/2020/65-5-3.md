@topic Properties of |A| and |adj A|
If $A$ is skew symmetric matrix of order 3, then the value of $|A|$ is
(A) $3$
(B) $0$
(C) $9$
(D) $27$
--- ans B
For a skew symmetric matrix $A' = -A$, so $|A| = |A'| = |-A| = (-1)^3|A| = -|A|$.
$\Rightarrow 2|A| = 0 \Rightarrow |A| = 0$.

@topic Second order derivatives
If $y = \log_e\left(\dfrac{x^2}{e^2}\right)$, then $\dfrac{d^2y}{dx^2}$ equals
(A) $-\dfrac{1}{x}$
(B) $-\dfrac{1}{x^2}$
(C) $\dfrac{2}{x^2}$

--- ans D
$y = \log_e x^2 - \log_e e^2 = 2\log x - 2$ (for $x > 0$).
$$\frac{dy}{dx} = \frac{2}{x}, \qquad \frac{d^2y}{dx^2} = -\frac{2}{x^2}$$

=== 17 | cd | 1 | sub
@topic Differentiability
Let $f(x) = x|x|$, for all $x \in \mathbb{R}$ check its differentiability at $x = 0$.
--- ans
$f(x) = \begin{cases} x^2, & x \ge 0 \\ -x^2, & x < 0 \end{cases}$, and $f(0) = 0$.
$$Rf'(0) = \lim_{h \to 0^+}\frac{f(h) - f(0)}{h} = \lim_{h \to 0^+}\frac{h^2}{h} = 0, \qquad Lf'(0) = \lim_{h \to 0^-}\frac{f(h) - f(0)}{h} = \lim_{h \to 0^-}\frac{-h^2}{h} = 0$$
Since $Lf'(0) = Rf'(0) = 0$, $f$ is **differentiable at $x = 0$** (with $f'(0) = 0$).

@topic Partial fractions
Find $\displaystyle\int \frac{x + 1}{(x + 2)(x + 3)}\,dx$.
--- ans
Let
$$\frac{x + 1}{(x + 2)(x + 3)} = \frac{A}{x + 2} + \frac{B}{x + 3} \Rightarrow x + 1 = A(x + 3) + B(x + 2)$$
Putting $x = -2$: $A = -1$. Putting $x = -3$: $-2 = -B \Rightarrow B = 2$.
$$\int \frac{x + 1}{(x + 2)(x + 3)}\,dx = -\int \frac{dx}{x + 2} + 2\int \frac{dx}{x + 3} = 2\log|x + 3| - \log|x + 2| + C$$

=== 26 | int | 2 | sub
@topic Properties of definite integrals
Find the value of $\displaystyle\int_0^1 \tan^{-1}\left(\frac{1 - 2x}{1 + x - x^2}\right)dx$.
--- ans
Let $f(x) = \tan^{-1}\left(\dfrac{1 - 2x}{1 + x - x^2}\right)$ and $I = \displaystyle\int_0^1 f(x)\,dx$. (On $[0, 1]$, $1 + x - x^2 \ge 1 > 0$, so $f$ is continuous.)
Replace $x$ by $1 - x$:
$1 - 2(1 - x) = 2x - 1$ and $1 + (1 - x) - (1 - x)^2 = 1 + x - x^2$, so
$$f(1 - x) = \tan^{-1}\left(\frac{-(1 - 2x)}{1 + x - x^2}\right) = -\tan^{-1}\left(\frac{1 - 2x}{1 + x - x^2}\right) = -f(x)$$
(using $\tan^{-1}(-\theta) = -\tan^{-1}\theta$).
By the property $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$:
$$I = \int_0^1 f(1 - x)\,dx = -\int_0^1 f(x)\,dx = -I \Rightarrow 2I = 0$$
$$\therefore\ \int_0^1 \tan^{-1}\left(\frac{1 - 2x}{1 + x - x^2}\right)dx = 0$$

=== 27 | itf | 4 | sub
@topic Principal values
Solve the equation $x$: $\sin^{-1}\left(\dfrac{5}{x}\right) + \sin^{-1}\left(\dfrac{12}{x}\right) = \dfrac{\pi}{2}\ (x \ne 0)$
--- ans
For the terms to be defined, $\left|\dfrac{5}{x}\right| \le 1$ and $\left|\dfrac{12}{x}\right| \le 1$, i.e. $|x| \ge 12$.
Let $\sin^{-1}\dfrac{5}{x} = \theta$, so $\sin\theta = \dfrac{5}{x}$, $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$. The equation gives
$$\sin^{-1}\left(\frac{12}{x}\right) = \frac{\pi}{2} - \theta$$
This must lie in $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$, so $0 \le \theta \le \dfrac{\pi}{2}$; hence $\sin\theta = \dfrac{5}{x} \ge 0$, i.e. $x > 0$. $\quad\cdots(1)$
Taking sine: $\dfrac{12}{x} = \sin\left(\dfrac{\pi}{2} - \theta\right) = \cos\theta$.
Using $\sin^2\theta + \cos^2\theta = 1$:
$$\frac{25}{x^2} + \frac{144}{x^2} = 1 \Rightarrow x^2 = 169 \Rightarrow x = \pm 13$$
By (1), $x = -13$ is rejected (then both terms are negative and their sum is $-\dfrac{\pi}{2}$).
Check $x = 13$: with $\theta = \sin^{-1}\dfrac{5}{13} \in \left(0, \dfrac{\pi}{2}\right)$, $\cos\theta = \dfrac{12}{13}$, so $\dfrac{\pi}{2} - \theta \in \left(0, \dfrac{\pi}{2}\right)$ has sine $\dfrac{12}{13}$, i.e. $\sin^{-1}\dfrac{12}{13} = \dfrac{\pi}{2} - \theta$ ✓.
$\therefore\ \boxed{x = 13}$

=== 28 | de | 4 | sub
@topic Homogeneous equations
Find the general solution of the differential equation
$$ye^{x/y}\,dx = \left(xe^{x/y} + y^2\right)dy,\ y \ne 0$$
--- ans
$$\frac{dx}{dy} = \frac{xe^{x/y} + y^2}{ye^{x/y}} = \frac{x}{y} + \frac{y}{e^{x/y}}$$
Put $x = vy \Rightarrow \dfrac{dx}{dy} = v + y\dfrac{dv}{dy}$:
$$v + y\frac{dv}{dy} = v + \frac{y}{e^v} \Rightarrow y\frac{dv}{dy} = \frac{y}{e^v} \Rightarrow \frac{dv}{dy} = e^{-v}$$
Separating the variables: $e^v\,dv = dy$.
Integrating: $e^v = y + C$.
$\therefore$ The general solution is
$$e^{x/y} = y + C$$
