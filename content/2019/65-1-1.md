@topic Properties of |A| and |adj A|
If A and B are square matrices of the same order 3, such that $|A| = 2$ and $AB = 2I$, write the value of $|B|$.
--- ans
$$AB = 2I \Rightarrow |AB| = |2I| \Rightarrow |A|\,|B| = 2^3|I| = 8$$
$$\Rightarrow 2|B| = 8 \Rightarrow |B| = 4$$

@topic Order and degree
Find the order and the degree of the differential equation $x^2\dfrac{d^2y}{dx^2} = \left\{1 + \left(\dfrac{dy}{dx}\right)^2\right\}^4$.
--- ans
The highest order derivative present is $\dfrac{d^2y}{dx^2}$, so the **order is 2**.
The equation is a polynomial in the derivatives and the highest order derivative $\dfrac{d^2y}{dx^2}$ occurs with power 1, so the **degree is 1**.

=== 7 | int | 2 | sub
@topic Special forms
Find: $\displaystyle\int \frac{\sec^2 x}{\sqrt{\tan^2 x + 4}}\,dx$.
--- ans
Put $\tan x = t \Rightarrow \sec^2 x\,dx = dt$.
$$\int \frac{\sec^2 x}{\sqrt{\tan^2 x + 4}}\,dx = \int \frac{dt}{\sqrt{t^2 + 2^2}} = \log\left|t + \sqrt{t^2 + 4}\right| + C$$
$$= \log\left|\tan x + \sqrt{\tan^2 x + 4}\right| + C$$

=== 8a | int | 2 | sub
@topic Standard integrals
Find: $\displaystyle\int \sqrt{1 - \sin 2x}\,dx$, $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$.
--- ans
$1 - \sin 2x = \sin^2 x + \cos^2 x - 2\sin x\cos x = (\sin x - \cos x)^2$.
For $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$, $\sin x > \cos x$, so $\sqrt{1 - \sin 2x} = \sin x - \cos x$.
$$\int \sqrt{1 - \sin 2x}\,dx = \int (\sin x - \cos x)\,dx = -\cos x - \sin x + C$$

=== 8b | int | 2 | sub
@topic Integration by parts
Find: $\displaystyle\int \sin^{-1}(2x)\,dx$.
--- ans
Integrating by parts, taking $\sin^{-1}(2x)$ as the first function and $1$ as the second:
$$I = x\sin^{-1}(2x) - \int \frac{2}{\sqrt{1 - 4x^2}}\cdot x\,dx = x\sin^{-1}(2x) + \frac{1}{4}\int \frac{-8x}{\sqrt{1 - 4x^2}}\,dx$$
Putting $1 - 4x^2 = u$, $-8x\,dx = du$: $\displaystyle\int \frac{-8x}{\sqrt{1 - 4x^2}}\,dx = 2\sqrt{u} = 2\sqrt{1 - 4x^2}$.
$$\therefore\ I = x\sin^{-1}(2x) + \frac{1}{2}\sqrt{1 - 4x^2} + C$$

=== 19 | int | 4 | sub
@topic Partial fractions
Find: $\displaystyle\int \frac{3x + 5}{x^2 + 3x - 18}\,dx$.
--- ans
$x^2 + 3x - 18 = (x - 3)(x + 6)$.
Let $\dfrac{3x + 5}{(x - 3)(x + 6)} = \dfrac{A}{x - 3} + \dfrac{B}{x + 6} \Rightarrow 3x + 5 = A(x + 6) + B(x - 3)$.
Putting $x = 3$: $14 = 9A \Rightarrow A = \dfrac{14}{9}$. Putting $x = -6$: $-13 = -9B \Rightarrow B = \dfrac{13}{9}$.
$$\int \frac{3x + 5}{x^2 + 3x - 18}\,dx = \frac{14}{9}\int \frac{dx}{x - 3} + \frac{13}{9}\int \frac{dx}{x + 6}$$
$$= \frac{14}{9}\log|x - 3| + \frac{13}{9}\log|x + 6| + C$$
(Equivalently, $\dfrac{3}{2}\log\left|x^2 + 3x - 18\right| + \dfrac{1}{18}\log\left|\dfrac{x - 3}{x + 6}\right| + C$.)

=== 21a | de | 4 | sub
@topic Homogeneous equations
Solve the differential equation: $x\,dy - y\,dx = \sqrt{x^2 + y^2}\,dx$, given that $y = 0$ when $x = 1$.
--- ans
$$\frac{dy}{dx} = \frac{y + \sqrt{x^2 + y^2}}{x} = \frac{y}{x} + \sqrt{1 + \left(\frac{y}{x}\right)^2} \quad (x > 0)$$
This is homogeneous. Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = v + \sqrt{1 + v^2} \Rightarrow \int \frac{dv}{\sqrt{1 + v^2}} = \int \frac{dx}{x}$$
$$\Rightarrow \log\left|v + \sqrt{1 + v^2}\right| = \log|x| + \log C \Rightarrow v + \sqrt{1 + v^2} = Cx$$
$$\Rightarrow \frac{y}{x} + \frac{\sqrt{x^2 + y^2}}{x} = Cx \Rightarrow y + \sqrt{x^2 + y^2} = Cx^2$$
When $x = 1$, $y = 0$: $0 + 1 = C \Rightarrow C = 1$.
$\therefore$ The particular solution is
$$y + \sqrt{x^2 + y^2} = x^2$$

=== 21b | de | 4 | sub
@topic Linear differential equations
Solve the differential equation: $(1 + x^2)\dfrac{dy}{dx} + 2xy - 4x^2 = 0$, subject to the initial condition $y(0) = 0$.
--- ans
Dividing by $1 + x^2$:
$$\frac{dy}{dx} + \frac{2x}{1 + x^2}\,y = \frac{4x^2}{1 + x^2}$$
This is linear with $P = \dfrac{2x}{1 + x^2}$, $Q = \dfrac{4x^2}{1 + x^2}$.
$$\text{I.F.} = e^{\int \frac{2x}{1 + x^2}dx} = e^{\log(1 + x^2)} = 1 + x^2$$
Solution:
$$y(1 + x^2) = \int \frac{4x^2}{1 + x^2}\,(1 + x^2)\,dx = \int 4x^2\,dx = \frac{4x^3}{3} + C$$
When $x = 0$, $y = 0$: $0 = 0 + C \Rightarrow C = 0$.
$\therefore$ The particular solution is
$$y(1 + x^2) = \frac{4x^3}{3} \quad\text{or}\quad y = \frac{4x^3}{3(1 + x^2)}$$

@topic Area enclosed by lines
Using integration, find the area of triangle $ABC$, whose vertices are $A(2, 5)$, $B(4, 7)$ and $C(6, 2)$.
--- ans
Equation of AB: $y - 5 = \dfrac{7 - 5}{4 - 2}(x - 2) \Rightarrow y = x + 3$
Equation of BC: $y - 7 = \dfrac{2 - 7}{6 - 4}(x - 4) \Rightarrow y = -\dfrac{5x}{2} + 17$
Equation of AC: $y - 5 = \dfrac{2 - 5}{6 - 2}(x - 2) \Rightarrow y = -\dfrac{3x}{4} + \dfrac{13}{2}$

$$\text{Area of }\triangle ABC = \int_2^4 (x + 3)\,dx + \int_4^6 \left(-\frac{5x}{2} + 17\right)dx - \int_2^6 \left(-\frac{3x}{4} + \frac{13}{2}\right)dx$$
$$\int_2^4 (x + 3)\,dx = \left[\frac{x^2}{2} + 3x\right]_2^4 = 20 - 8 = 12$$
$$\int_4^6 \left(-\frac{5x}{2} + 17\right)dx = \left[-\frac{5x^2}{4} + 17x\right]_4^6 = 57 - 48 = 9$$
$$\int_2^6 \left(-\frac{3x}{4} + \frac{13}{2}\right)dx = \left[-\frac{3x^2}{8} + \frac{13x}{2}\right]_2^6 = \frac{51}{2} - \frac{23}{2} = 14$$
$\therefore$ Area $= 12 + 9 - 14 = 7$ sq. units.

=== 28 | prob | 6 | sub
@topic Total probability and Bayes' theorem
A manufacturer has three machine operators A, B and C. The first operator A produces 1% of defective items, whereas the other two operators B and C produces 5% and 7% defective items respectively. A is on the job for 50% of the time, B on the job 30% of the time and C on the job for 20% of the time. All the items are put into one stockpile and then one item is chosen at random from this and is found to be defective. What is the probability that it was produced by A?
--- ans
Let $E_1$, $E_2$, $E_3$ be the events that the item is produced by A, B, C respectively, and $D$: the item is defective.
$$P(E_1) = \frac{50}{100},\quad P(E_2) = \frac{30}{100},\quad P(E_3) = \frac{20}{100}$$
$$P(D|E_1) = \frac{1}{100},\quad P(D|E_2) = \frac{5}{100},\quad P(D|E_3) = \frac{7}{100}$$
By Bayes' theorem,
$$P(E_1|D) = \frac{P(E_1)P(D|E_1)}{P(E_1)P(D|E_1) + P(E_2)P(D|E_2) + P(E_3)P(D|E_3)}$$
$$= \frac{\frac{50}{100}\cdot\frac{1}{100}}{\frac{50}{100}\cdot\frac{1}{100} + \frac{30}{100}\cdot\frac{5}{100} + \frac{20}{100}\cdot\frac{7}{100}} = \frac{50}{50 + 150 + 140} = \frac{50}{340} = \frac{5}{34}$$
$\therefore$ Required probability $= \dfrac{5}{34}$.
