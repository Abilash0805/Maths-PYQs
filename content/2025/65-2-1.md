@topic Scalar product and projection
The projection vector of vector $\vec{a}$ on vector $\vec{b}$ is:
(A) $\left(\dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\right)\vec{b}$
(B) $\dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|}$
(C) $\dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|}$
(D) $\left(\dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|^2}\right)\vec{b}$
--- ans A
The scalar projection of $\vec{a}$ on $\vec{b}$ is $\dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|}$; the projection **vector** is this times the unit vector $\hat{b} = \dfrac{\vec{b}}{|\vec{b}|}$:
$$\left(\frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\right)\vec{b}$$
(Option (B) is only the scalar projection.)

@topic Logarithmic differentiation
If $x = e^{\frac{x}{y}}$, then prove that $\dfrac{dy}{dx} = \dfrac{x - y}{x\log x}$.
--- ans
Taking logarithms: $\log x = \dfrac{x}{y} \Rightarrow y = \dfrac{x}{\log x}$.
$$\frac{dy}{dx} = \frac{\log x\cdot 1 - x\cdot\frac{1}{x}}{(\log x)^2} = \frac{\log x - 1}{(\log x)^2}$$
RHS: $\dfrac{x - y}{x\log x} = \dfrac{x - \frac{x}{\log x}}{x\log x} = \dfrac{x\left(\frac{\log x - 1}{\log x}\right)}{x\log x} = \dfrac{\log x - 1}{(\log x)^2}$.
Hence $\dfrac{dy}{dx} = \dfrac{x - y}{x\log x}$. Proved.

@topic Second order derivatives
If $y = \log\left(\sqrt{x} + \dfrac{1}{\sqrt{x}}\right)^2$, then show that $x(x + 1)^2y_2 + (x + 1)^2y_1 = 2$.
--- ans

=== 29b | cd | 3 | sub
@topic Chain rule and implicit differentiation
If $x\sqrt{1 + y} + y\sqrt{1 + x} = 0$, $-1 < x < 1$, $x \ne y$, then prove that $\dfrac{dy}{dx} = \dfrac{-1}{(1 + x)^2}$.
--- ans
$x\sqrt{1 + y} = -y\sqrt{1 + x}$. Squaring: $x^2(1 + y) = y^2(1 + x)$
$$x^2 - y^2 + x^2y - xy^2 = 0 \Rightarrow (x - y)(x + y) + xy(x - y) = 0 \Rightarrow (x - y)(x + y + xy) = 0$$
Since $x \ne y$: $x + y + xy = 0 \Rightarrow y(1 + x) = -x \Rightarrow y = -\dfrac{x}{1 + x}$.
$$\frac{dy}{dx} = -\frac{(1 + x)\cdot 1 - x\cdot 1}{(1 + x)^2} = \frac{-1}{(1 + x)^2}$$
Hence proved.
