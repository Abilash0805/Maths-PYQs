@topic Scalar product and projection
If $\vec{p}$ and $\vec{q}$ are unit vectors, then which of the following values of $\vec{p}\cdot\vec{q}$ is not possible ?
(A) $\dfrac{-1}{2}$
(B) $\dfrac{1}{\sqrt{2}}$
(C) $\dfrac{\sqrt{3}}{2}$
(D) $\sqrt{3}$
--- ans D
$\vec{p}\cdot\vec{q} = |\vec{p}||\vec{q}|\cos\theta = \cos\theta \in [-1, 1]$. Since $\sqrt{3} > 1$, $\vec{p}\cdot\vec{q} = \sqrt{3}$ is not possible.

@topic Definite integrals
If $\displaystyle\int_0^a x\,dx \le \frac{a}{2} + 6$, then
(A) $-4 \le a \le 3$
(B) $a \ge 4,\ a \le -3$
(C) $-3 \le a \le 4$
(D) $-3 \le a \le 0$
--- ans C
$\displaystyle\int_0^a x\,dx = \frac{a^2}{2} \le \frac{a}{2} + 6 \Rightarrow a^2 - a - 12 \le 0 \Rightarrow (a - 4)(a + 3) \le 0 \Rightarrow -3 \le a \le 4$.

@topic Symmetric and skew-symmetric matrices
If A and B are square matrices of same order, then $(AB^T - BA^T)$ is a
(A) symmetric matrix
(B) skew-symmetric matrix
(C) null matrix
(D) unit matrix
--- ans B
$$(AB^T - BA^T)^T = (B^T)^TA^T - (A^T)^TB^T = BA^T - AB^T = -(AB^T - BA^T)$$
So the matrix is skew-symmetric.

@topic Principal values
The value of $\cos\left(\dfrac{\pi}{6} + \cot^{-1}(-\sqrt{3})\right)$ is
(A) $-1$
(B) $\dfrac{-\sqrt{3}}{2}$
(C) $0$
(D) $1$
--- ans A
$\cot^{-1}(-\sqrt{3}) = \pi - \cot^{-1}\sqrt{3} = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}$ (principal branch $(0, \pi)$).
$\cos\left(\dfrac{\pi}{6} + \dfrac{5\pi}{6}\right) = \cos\pi = -1$.

=== 22 | int | 2 | sub
@topic Integration by substitution
Find : $\displaystyle\int 2x^3e^{x^2}\,dx$.
--- ans
Put $x^2 = t$, $2x\,dx = dt$:
$$\int 2x^3e^{x^2}\,dx = \int x^2e^{x^2}\cdot 2x\,dx = \int te^t\,dt$$
By parts: $\displaystyle\int te^t\,dt = te^t - \int e^t\,dt = te^t - e^t + C$.
$$\boxed{\int 2x^3e^{x^2}\,dx = e^{x^2}(x^2 - 1) + C}$$

=== 27 | rf | 3 | sub
@topic Types of relations
Let R be a relation on set of real numbers $\mathbb{R}$ defined as $\{(x, y) : x - y + \sqrt{3} \text{ is an irrational number},\ x, y \in \mathbb{R}\}$ Verify R for reflexivity, symmetry and transitivity.
--- ans
**Reflexive:** For every $x \in \mathbb{R}$, $x - x + \sqrt{3} = \sqrt{3}$, which is irrational. So $(x, x) \in R$; R is reflexive.
**Symmetric:** Take $x = \sqrt{3}$, $y = 1$: $\sqrt{3} - 1 + \sqrt{3} = 2\sqrt{3} - 1$ is irrational, so $(\sqrt{3}, 1) \in R$.
But $1 - \sqrt{3} + \sqrt{3} = 1$ is rational, so $(1, \sqrt{3}) \notin R$. R is not symmetric.
**Transitive:** Take $x = 1$, $y = \sqrt{2}$, $z = 1 + \sqrt{3}$:
$1 - \sqrt{2} + \sqrt{3}$ is irrational $\Rightarrow (1, \sqrt{2}) \in R$; $\ \sqrt{2} - (1 + \sqrt{3}) + \sqrt{3} = \sqrt{2} - 1$ is irrational $\Rightarrow (\sqrt{2}, 1 + \sqrt{3}) \in R$;
but $1 - (1 + \sqrt{3}) + \sqrt{3} = 0$ is rational $\Rightarrow (1, 1 + \sqrt{3}) \notin R$. R is not transitive.
**R is reflexive, but neither symmetric nor transitive.**

@topic Graphical method – unbounded region
Solve the following linear programming problem graphically :
Minimise $Z = 2x + y$
subject to the constraints :
$$3x + y \ge 9,\quad x + y \ge 7,\quad x + 2y \ge 8,\quad x, y \ge 0$$
--- ans
Draw $3x + y = 9$ (through $(3, 0), (0, 9)$), $x + y = 7$ (through $(7, 0), (0, 7)$) and $x + 2y = 8$ (through $(8, 0), (0, 4)$). Each inequality is satisfied on the side away from the origin, so the feasible region is **unbounded**.
Corner points:
$A(0, 9)$; $\ B$: $3x + y = 9$, $x + y = 7 \Rightarrow (1, 6)$; $\ C$: $x + y = 7$, $x + 2y = 8 \Rightarrow (6, 1)$; $\ D(8, 0)$.

| Corner point | $Z = 2x + y$ |
|---|---|
| $A(0, 9)$ | $9$ |
| $B(1, 6)$ | $8$ ← smallest |

@topic Definite integrals
If $\displaystyle\int_a^b x^3\,dx = 0$ and $\displaystyle\int_a^b x^2\,dx = \frac{2}{3}$, then find the values of a and b.
--- ans
$$\int_a^b x^3\,dx = \frac{b^4 - a^4}{4} = 0 \Rightarrow b^4 = a^4 \Rightarrow b = \pm a$$
$$\int_a^b x^2\,dx = \frac{b^3 - a^3}{3} = \frac{2}{3} \Rightarrow b^3 - a^3 = 2$$
If $b = a$, then $b^3 - a^3 = 0 \ne 2$. So $b = -a$: $-a^3 - a^3 = 2 \Rightarrow a^3 = -1 \Rightarrow a = -1$, $b = 1$.
**$a = -1$, $b = 1$.**

=== 33 | int | 5 | sub
@topic Integration by substitution
Find : $\displaystyle\int\left(\sqrt{\tan x} + \sqrt{\cot x}\right)dx$.
--- ans
$$\sqrt{\tan x} + \sqrt{\cot x} = \frac{\sqrt{\sin x}}{\sqrt{\cos x}} + \frac{\sqrt{\cos x}}{\sqrt{\sin x}} = \frac{\sin x + \cos x}{\sqrt{\sin x\cos x}}$$
Put $\sin x - \cos x = t$, $(\cos x + \sin x)\,dx = dt$. Then $t^2 = 1 - 2\sin x\cos x \Rightarrow \sin x\cos x = \dfrac{1 - t^2}{2}$.
$$I = \int\frac{dt}{\sqrt{\frac{1 - t^2}{2}}} = \sqrt{2}\int\frac{dt}{\sqrt{1 - t^2}} = \sqrt{2}\sin^{-1}t + C$$
$$\boxed{I = \sqrt{2}\sin^{-1}(\sin x - \cos x) + C}$$
(Equivalently, $\sqrt{2}\tan^{-1}\left(\dfrac{\tan x - 1}{\sqrt{2\tan x}}\right) + C$.)
