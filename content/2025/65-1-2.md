@topic Transpose
Let $A$ be a matrix of order $m \times n$ and $B$ is a matrix such that $A^TB$ and $BA^T$ are defined. Then, the order of $B$ is:
(A) $m \times m$
(B) $n \times n$
(C) $m \times n$
(D) $n \times m$
--- ans C
$A^T$ is of order $n \times m$. $A^TB$ defined $\Rightarrow$ $B$ has $m$ rows. $BA^T$ defined $\Rightarrow$ $B$ has $n$ columns.
So $B$ is of order $m \times n$.

=== 12 | de | 1 | mcq
@topic Linear differential equations
The integrating factor of the differential equation $\dfrac{dy}{dx} + y = \dfrac{1 + y}{x}$ is
(A) $xe^x$
(B) $\dfrac{e^x}{x}$
(C) $\dfrac{x}{e^x}$
(D) $xe^{\frac{1}{x}}$
--- ans B
$\dfrac{dy}{dx} + y - \dfrac{y}{x} = \dfrac{1}{x} \Rightarrow \dfrac{dy}{dx} + \left(1 - \dfrac{1}{x}\right)y = \dfrac{1}{x}$.
$$\text{I.F.} = e^{\int\left(1 - \frac{1}{x}\right)dx} = e^{x - \log x} = \frac{e^x}{x}$$

=== 13 | mat | 1 | mcq
@topic Types of matrices
Let $A = [a_{ij}]$ be a square matrix of order 3 such that $a_{ij} = \hat{j} - 2\hat{i}$. Then which of the following is true?
(A) $a_{12} > 0$
(B) all $a_{ij} < 0$
(C) $a_{13} + a_{31} = -6$
(D) $a_{23} > a_{32}$
--- ans D
(The hats are a printing slip: the rule is $a_{ij} = j - 2i$.)
$a_{12} = 2 - 2 = 0$, so (A) is false. $a_{13} = 3 - 2 = 1 > 0$, so (B) is false. $a_{13} + a_{31} = 1 + (1 - 6) = -4$, so (C) is false.
$a_{23} = 3 - 4 = -1$ and $a_{32} = 2 - 6 = -4$, so $a_{23} > a_{32}$ — (D) is true.

=== 22 | aod | 2 | sub
@topic Increasing and decreasing functions
Find the values of '$a$' for which $f(x) = x^2 - 2ax + b$ is an increasing function for $x > 0$.
--- ans
$f'(x) = 2x - 2a = 2(x - a)$.
$f$ is increasing for $x > 0$ if $f'(x) \ge 0$ for all $x > 0$, i.e. $x \ge a$ for every $x > 0$.
This holds exactly when $a \le 0$ (if $a > 0$, then $f'(x) < 0$ on $(0, a)$).
**Hence $a \le 0$, i.e. $a \in (-\infty, 0]$.**

=== 24 | itf | 2 | sub
@topic Principal values
Evaluate : $\sin^{-1}\left(\sin\dfrac{3\pi}{5}\right)$
--- ans
$\dfrac{3\pi}{5} \notin \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$, the principal value branch of $\sin^{-1}$.
$\sin\dfrac{3\pi}{5} = \sin\left(\pi - \dfrac{3\pi}{5}\right) = \sin\dfrac{2\pi}{5}$, and $\dfrac{2\pi}{5} \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.
$$\sin^{-1}\left(\sin\frac{3\pi}{5}\right) = \sin^{-1}\left(\sin\frac{2\pi}{5}\right) = \frac{2\pi}{5}$$

=== 28 | aod | 3 | sub
@topic Rate of change
The area of an expanding rectangle is increasing at the rate of $48\ \text{cm}^2/\text{s}$. The length of the rectangle is always square of its breadth. At what rate the length of rectangle increasing at an instant, when breadth $= 4.5$ cm?
--- ans
Let breadth $= x$ cm, length $= y = x^2$ cm, area $A = xy = x^3$. Given $\dfrac{dA}{dt} = 48$ cm²/s.
$$\frac{dA}{dt} = 3x^2\frac{dx}{dt} \Rightarrow 48 = 3(4.5)^2\frac{dx}{dt} = 60.75\frac{dx}{dt} \Rightarrow \frac{dx}{dt} = \frac{48}{60.75} = \frac{64}{81}\ \text{cm/s}$$
$$\frac{dy}{dt} = 2x\frac{dx}{dt} = 2(4.5)\cdot\frac{64}{81} = 9 \cdot \frac{64}{81} = \frac{64}{9}\ \text{cm/s}$$
**The length is increasing at $\dfrac{64}{9} \approx 7.11$ cm/s.**

=== 30a | int | 3 | sub
@topic Integration by substitution
Find : $\displaystyle\int \frac{\cos 2x}{(\sin x + \cos x)^2}\,dx$
--- ans
$\cos 2x = \cos^2 x - \sin^2 x = (\cos x - \sin x)(\cos x + \sin x)$, so
$$I = \int \frac{\cos x - \sin x}{\sin x + \cos x}\,dx$$
Put $\sin x + \cos x = t$, $(\cos x - \sin x)\,dx = dt$:
$$I = \int\frac{dt}{t} = \log|t| + C = \boxed{\log|\sin x + \cos x| + C}$$

=== 30b | int | 3 | sub
@topic Properties of definite integrals
Evaluate : $\displaystyle\int_0^{\frac{\pi}{2}} \frac{5\sin x + 3\cos x}{\sin x + \cos x}\,dx$
--- ans
Let $I = \displaystyle\int_0^{\pi/2}\frac{5\sin x + 3\cos x}{\sin x + \cos x}\,dx$.
Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$ (with $\sin\left(\frac{\pi}{2} - x\right) = \cos x$, $\cos\left(\frac{\pi}{2} - x\right) = \sin x$):
$$I = \int_0^{\pi/2}\frac{5\cos x + 3\sin x}{\cos x + \sin x}\,dx$$
Adding,
$$2I = \int_0^{\pi/2}\frac{8(\sin x + \cos x)}{\sin x + \cos x}\,dx = 8 \cdot \frac{\pi}{2} = 4\pi \Rightarrow \boxed{I = 2\pi}$$

=== 32a | cd | 5 | sub
@topic Derivatives of inverse trigonometric functions
Differentiate $\tan^{-1}\dfrac{\sqrt{1 - x^2}}{x}$ w.r.t. $\cos^{-1}\left(2x\sqrt{1 - x^2}\right)$, $x \in \left(\dfrac{1}{\sqrt{2}}, 1\right)$.
--- ans
Let $u = \tan^{-1}\dfrac{\sqrt{1 - x^2}}{x}$, $v = \cos^{-1}\left(2x\sqrt{1 - x^2}\right)$. Put $x = \cos\theta$; since $x \in \left(\frac{1}{\sqrt{2}}, 1\right)$, $\theta \in \left(0, \frac{\pi}{4}\right)$.
$$u = \tan^{-1}\frac{\sin\theta}{\cos\theta} = \tan^{-1}(\tan\theta) = \theta \quad\left(\theta \in \left(0, \tfrac{\pi}{4}\right)\right)$$
$$v = \cos^{-1}(2\cos\theta\sin\theta) = \cos^{-1}(\sin 2\theta) = \cos^{-1}\left(\cos\left(\frac{\pi}{2} - 2\theta\right)\right) = \frac{\pi}{2} - 2\theta$$
(valid as $\frac{\pi}{2} - 2\theta \in \left(0, \frac{\pi}{2}\right) \subset [0, \pi]$).
$$\frac{du}{d\theta} = 1,\quad \frac{dv}{d\theta} = -2 \Rightarrow \boxed{\frac{du}{dv} = -\frac{1}{2}}$$

=== 32b | cd | 5 | sub
@topic Logarithmic differentiation
Find $\dfrac{dy}{dx}$, if $y = x^{\tan x} + \dfrac{\sqrt{x^2 + 1}}{2}$.
--- ans
Let $u = x^{\tan x}$ and $v = \dfrac{\sqrt{x^2 + 1}}{2}$, so $y = u + v$.
$\log u = \tan x\log x$. Differentiating:
$$\frac{1}{u}\frac{du}{dx} = \sec^2 x\log x + \frac{\tan x}{x} \Rightarrow \frac{du}{dx} = x^{\tan x}\left(\sec^2 x\log x + \frac{\tan x}{x}\right)$$
$$\frac{dv}{dx} = \frac{1}{2}\cdot\frac{2x}{2\sqrt{x^2 + 1}} = \frac{x}{2\sqrt{x^2 + 1}}$$
$$\boxed{\frac{dy}{dx} = x^{\tan x}\left(\sec^2 x\log x + \frac{\tan x}{x}\right) + \frac{x}{2\sqrt{x^2 + 1}}}$$
