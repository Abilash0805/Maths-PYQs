@topic Scalar product and projection
The values of $x$ for which the angle between the vectors $\vec{a} = 2x^2\hat{i} + 4x\hat{j} + \hat{k}$ and $\vec{b} = 7\hat{i} - 2\hat{j} + x\hat{k}$ is obtuse, is:
(A) $0$ or $\dfrac{1}{2}$
(B) $x > \dfrac{1}{2}$
(C) $\left(0, \dfrac{1}{2}\right)$
(D) $\left[0, \dfrac{1}{2}\right]$
--- ans C
The angle is obtuse iff $\vec{a}\cdot\vec{b} < 0$ (the vectors are never anti-parallel here, since $\frac{4x}{-2} = \frac{1}{x}$ would need $x^2 = -\frac{1}{2}$):
$$14x^2 - 8x + x < 0 \Rightarrow 7x(2x - 1) < 0 \Rightarrow 0 < x < \frac{1}{2}$$

@topic Evaluation of determinants
Let P be a skew-symmetric matrix of order 3. If $\det(P) = \alpha$, then $(2025)^\alpha$ is:
(A) $0$
(B) $1$
(C) $2025$
(D) $(2025)^3$
--- ans B
For a skew-symmetric matrix of odd order, $|P| = |P'| = |-P| = (-1)^3|P| = -|P| \Rightarrow |P| = 0$.
So $\alpha = 0$ and $(2025)^0 = 1$.

The principal value of $\sin^{-1}\left(\cos\dfrac{43\pi}{5}\right)$ is:
(A) $\dfrac{-7\pi}{5}$

(C) $\dfrac{\pi}{10}$

=== 22 | int | 2 | sub
@topic Properties of definite integrals
Evaluate: $\displaystyle\int_0^{\pi} \frac{\sin 2px}{\sin x}\,dx$, $p \in \mathbb{N}$.
--- ans
Let $I = \displaystyle\int_0^{\pi}\frac{\sin 2px}{\sin x}\,dx$. Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$:
$$I = \int_0^{\pi}\frac{\sin(2p\pi - 2px)}{\sin(\pi - x)}\,dx = \int_0^{\pi}\frac{-\sin 2px}{\sin x}\,dx = -I$$
(since $\sin(2p\pi - \theta) = -\sin\theta$ for $p \in \mathbb{N}$).
$\therefore 2I = 0 \Rightarrow \boxed{I = 0}$.

=== 24 | vec | 2 | sub
@topic Basic concepts of vectors
Let $\vec{p} = 2\hat{i} - 3\hat{j} - \hat{k}$, $\vec{q} = -3\hat{i} + 4\hat{j} + \hat{k}$ and $\vec{r} = \hat{i} + \hat{j} + 2\hat{k}$. Express $\vec{r}$ in the form of $\vec{r} = \lambda\vec{p} + \mu\vec{q}$ and hence, find the values of $\lambda$ and $\mu$.
--- ans
$\hat{i} + \hat{j} + 2\hat{k} = \lambda(2\hat{i} - 3\hat{j} - \hat{k}) + \mu(-3\hat{i} + 4\hat{j} + \hat{k})$. Comparing components:
$$2\lambda - 3\mu = 1,\qquad -3\lambda + 4\mu = 1,\qquad -\lambda + \mu = 2$$
From the third, $\mu = \lambda + 2$; then $2\lambda - 3\lambda - 6 = 1 \Rightarrow \lambda = -7$, $\mu = -5$.
Check: $-3(-7) + 4(-5) = 21 - 20 = 1$ ✓.
**$\lambda = -7$, $\mu = -5$, i.e. $\vec{r} = -7\vec{p} - 5\vec{q}$.**

=== 27 | rf | 3 | sub
@topic One-one and onto functions
Prove that $f : \mathbb{N} \to \mathbb{N}$ defined as $f(x) = ax + b$ $(a, b \in \mathbb{N})$ is one-one but not onto
--- ans
**One-one:** Let $x_1, x_2 \in \mathbb{N}$ with $f(x_1) = f(x_2)$. Then $ax_1 + b = ax_2 + b \Rightarrow a(x_1 - x_2) = 0 \Rightarrow x_1 = x_2$ (as $a \ne 0$). So $f$ is one-one.
**Not onto:** For every $x \in \mathbb{N}$, $f(x) = ax + b \ge a + b \ge 2$ (as $a, b, x \ge 1$). Hence $1 \in \mathbb{N}$ (co-domain) has no pre-image, i.e. there is no $x \in \mathbb{N}$ with $ax + b = 1$.
(More generally $x = \frac{y - b}{a}$ need not be a natural number.) So $f$ is not onto.
**Hence $f$ is one-one but not onto.**

=== 31 | int | 3 | sub
@topic Properties of definite integrals
$f$ and $g$ are continuos functions on interval $[a, b]$. Given that $f(a - x) = f(x)$ and $g(x) + g(a - x) = a$, show that $\displaystyle\int_0^a f(x)g(x)\,dx = \frac{a}{2}\int_0^a f(x)\,dx$.
--- ans
Let $I = \displaystyle\int_0^a f(x)g(x)\,dx$. Using $\displaystyle\int_0^a \phi(x)\,dx = \int_0^a \phi(a - x)\,dx$:
$$I = \int_0^a f(a - x)g(a - x)\,dx = \int_0^a f(x)\left[a - g(x)\right]dx = a\int_0^a f(x)\,dx - I$$
$$\Rightarrow 2I = a\int_0^a f(x)\,dx \Rightarrow I = \frac{a}{2}\int_0^a f(x)\,dx$$
Hence proved.

@topic Partial fractions
Find: $\displaystyle\int \frac{5x}{(x + 1)(x^2 + 9)}\,dx$
--- ans
Let $\dfrac{5x}{(x + 1)(x^2 + 9)} = \dfrac{A}{x + 1} + \dfrac{Bx + C}{x^2 + 9} \Rightarrow 5x = A(x^2 + 9) + (Bx + C)(x + 1)$.
$x = -1$: $-5 = 10A \Rightarrow A = -\dfrac{1}{2}$. Coefficient of $x^2$: $A + B = 0 \Rightarrow B = \dfrac{1}{2}$. Constant: $9A + C = 0 \Rightarrow C = \dfrac{9}{2}$.
(Check $x$: $B + C = 5$ ✓.)
$$I = -\frac{1}{2}\int\frac{dx}{x + 1} + \frac{1}{4}\int\frac{2x}{x^2 + 9}\,dx + \frac{9}{2}\int\frac{dx}{x^2 + 9}$$
$$\boxed{I = -\frac{1}{2}\log|x + 1| + \frac{1}{4}\log(x^2 + 9) + \frac{3}{2}\tan^{-1}\frac{x}{3} + C}$$
