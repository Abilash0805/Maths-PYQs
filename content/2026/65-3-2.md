@topic Integration by substitution
$\displaystyle\int \frac{dx}{\sqrt{e^{-2x} - 1}}$ is equal to :
(A) $\sin^{-1}e^{-x} + C$
(B) $\log\left|e^{-x} + \sqrt{e^{-2x} - 1}\right| + C$
(C) $\sin^{-1}e^{x} + C$
(D) $\log\left|e^{-x} - \sqrt{e^{-2x} - 1}\right| + C$
--- ans C
$\sqrt{e^{-2x} - 1} = \sqrt{\dfrac{1 - e^{2x}}{e^{2x}}} = \dfrac{\sqrt{1 - e^{2x}}}{e^x}$, so
$$\int \frac{dx}{\sqrt{e^{-2x} - 1}} = \int \frac{e^x\,dx}{\sqrt{1 - (e^x)^2}}$$
Put $e^x = t \Rightarrow e^x\,dx = dt$: $\displaystyle\int \frac{dt}{\sqrt{1 - t^2}} = \sin^{-1}t + C = \sin^{-1}e^x + C$.

@topic Parametric differentiation
If $x = e^{t + \frac{1}{t}}$ and $y = e^{t - \frac{1}{t}}$, then find $\dfrac{dy}{dx}$ at $t = -2$.
--- ans
$$\frac{dx}{dt} = e^{t + \frac{1}{t}}\left(1 - \frac{1}{t^2}\right),\qquad \frac{dy}{dt} = e^{t - \frac{1}{t}}\left(1 + \frac{1}{t^2}\right)$$
$$\therefore\ \frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{e^{t - \frac{1}{t}}}{e^{t + \frac{1}{t}}}\cdot\frac{1 + \frac{1}{t^2}}{1 - \frac{1}{t^2}} = e^{-\frac{2}{t}}\cdot\frac{t^2 + 1}{t^2 - 1}$$
At $t = -2$: $e^{-2/(-2)} = e$, so
$$\left(\frac{dy}{dx}\right)_{t = -2} = e\cdot\frac{4 + 1}{4 - 1} = \frac{5e}{3}$$

=== 25 | aod | 2 | sub
@topic Increasing and decreasing functions
Find the sub-interval of $(0, \infty)$ in which $f(x) = x^2e^{-x}$ is increasing.
--- ans
$$f'(x) = 2xe^{-x} - x^2e^{-x} = x(2 - x)e^{-x}$$
$f'(x) = 0 \Rightarrow x = 0$ or $x = 2$; in $(0, \infty)$ the point $x = 2$ splits it into $(0, 2)$ and $(2, \infty)$.
Since $e^{-x} > 0$ and $x > 0$, the sign of $f'(x)$ is the sign of $(2 - x)$:
for $0 < x < 2$, $f'(x) > 0$; for $x > 2$, $f'(x) < 0$.
$\therefore f$ is increasing in $(0, 2)$ (or $(0, 2]$).

=== 27a | de | 3 | sub
@topic Homogeneous equations
Find the general solution of the differential equation $(x^2 + y^2)\,dy = xy\,dx$.
--- ans
$$\frac{dy}{dx} = \frac{xy}{x^2 + y^2}$$
which is homogeneous. Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v}{1 + v^2} \Rightarrow x\frac{dv}{dx} = \frac{v - v - v^3}{1 + v^2} = -\frac{v^3}{1 + v^2}$$
Separating the variables:
$$\int \frac{1 + v^2}{v^3}\,dv = -\int \frac{dx}{x} \Rightarrow \int \left(\frac{1}{v^3} + \frac{1}{v}\right)dv = -\int \frac{dx}{x}$$
$$\Rightarrow -\frac{1}{2v^2} + \log|v| = -\log|x| + C$$
Putting $v = \dfrac{y}{x}$:
$$-\frac{x^2}{2y^2} + \log\left|\frac{y}{x}\right| + \log|x| = C \Rightarrow \log|y| = \frac{x^2}{2y^2} + C$$
which is the required general solution.

=== 27b | de | 3 | sub
@topic Linear differential equations
Find the particular solution of the differential equation $\dfrac{dy}{dx} - 3y\cot x = \sin 2x$, given that $y = 2$ when $x = \dfrac{\pi}{2}$.
--- ans
This is linear, of the form $\dfrac{dy}{dx} + Py = Q$ with $P = -3\cot x$, $Q = \sin 2x$.
$$\text{I.F.} = e^{\int -3\cot x\,dx} = e^{-3\log|\sin x|} = \frac{1}{\sin^3 x} = \operatorname{cosec}^3 x$$
The general solution is
$$y\operatorname{cosec}^3 x = \int \sin 2x\cdot\frac{1}{\sin^3 x}\,dx = \int \frac{2\cos x}{\sin^2 x}\,dx = 2\int \operatorname{cosec}x\cot x\,dx = -2\operatorname{cosec}x + C$$
$$\Rightarrow y = -2\sin^2 x + C\sin^3 x$$
Putting $x = \dfrac{\pi}{2}$, $y = 2$: $2 = -2 + C \Rightarrow C = 4$.
$\therefore$ The particular solution is
$$y = 4\sin^3 x - 2\sin^2 x \quad\left(\text{or } y\operatorname{cosec}^3 x = -2\operatorname{cosec}x + 4\right)$$

@topic Properties of definite integrals
Evaluate : $\displaystyle\int_{-\pi/2}^{\pi/2} \frac{\cos^2 x}{2^x + 1}\,dx$
--- ans
Let $I = \displaystyle\int_{-\pi/2}^{\pi/2} \frac{\cos^2 x}{2^x + 1}\,dx \quad\cdots(1)$
Using $\displaystyle\int_a^b f(x)\,dx = \int_a^b f(a + b - x)\,dx$ (here $a + b = 0$, so $x \to -x$):
$$I = \int_{-\pi/2}^{\pi/2} \frac{\cos^2 x}{2^{-x} + 1}\,dx = \int_{-\pi/2}^{\pi/2} \frac{2^x\cos^2 x}{1 + 2^x}\,dx \quad\cdots(2)$$
Adding (1) and (2):
$$2I = \int_{-\pi/2}^{\pi/2} \cos^2 x\,dx = 2\int_0^{\pi/2} \cos^2 x\,dx \quad (\cos^2 x \text{ is even})$$
$$\Rightarrow I = \int_0^{\pi/2} \cos^2 x\,dx = \int_0^{\pi/2} \frac{1 + \cos 2x}{2}\,dx = \frac{1}{2}\left[x + \frac{\sin 2x}{2}\right]_0^{\pi/2} = \frac{1}{2}\cdot\frac{\pi}{2}$$
$$\therefore\ I = \frac{\pi}{4}$$

=== 34 | rf | 5 | sub
@topic One-one and onto functions
Show that $f : \mathbb{R}_+ \to [-5, \infty)$ given by $f(x) = 4x^2 + 4x - 5$ is both one-one and onto where $\mathbb{R}_+ = [0, \infty)$. Also, find $p \in \mathbb{R}_+$ such that $f(p) = 3$.
--- ans
**One-one:** Let $x_1, x_2 \in \mathbb{R}_+$ with $f(x_1) = f(x_2)$:
$$4x_1^2 + 4x_1 - 5 = 4x_2^2 + 4x_2 - 5 \Rightarrow 4(x_1^2 - x_2^2) + 4(x_1 - x_2) = 0$$
$$\Rightarrow 4(x_1 - x_2)(x_1 + x_2 + 1) = 0$$
Since $x_1, x_2 \ge 0$, $x_1 + x_2 + 1 > 0$; hence $x_1 = x_2$. So $f$ is **one-one**.

**Onto:** Let $y \in [-5, \infty)$ and suppose $f(x) = y$:
$$4x^2 + 4x - 5 = y \Rightarrow (2x + 1)^2 = y + 6$$
Since $y + 6 \ge 1 > 0$, take $2x + 1 = \sqrt{y + 6}$ (we need $2x + 1 \ge 1 > 0$):
$$x = \frac{\sqrt{y + 6} - 1}{2}$$
As $y \ge -5$, $\sqrt{y + 6} \ge 1$, so $x \ge 0$, i.e. $x \in \mathbb{R}_+$, and
$$f(x) = \left(\sqrt{y + 6}\right)^2 - 6 = y$$
Thus every $y \in [-5, \infty)$ has a pre-image in $\mathbb{R}_+$, so $f$ is **onto**.

Hence $f$ is both one-one and onto.

**Finding p:** $f(p) = 3 \Rightarrow 4p^2 + 4p - 5 = 3 \Rightarrow 4p^2 + 4p - 8 = 0 \Rightarrow p^2 + p - 2 = 0$
$$\Rightarrow (p + 2)(p - 1) = 0 \Rightarrow p = 1 \text{ or } p = -2$$
Since $p \in \mathbb{R}_+$, $\boxed{p = 1}$.

@topic Graphical method – bounded region
Solve the following Linear Programming Problem graphically :
Maximise $Z = 12x + 18y$
subject to the constraints
$x + y \le 1200$
$x - 2y \ge 0$
$x + 3y \ge 600$
$x \ge 0,\ y \ge 0$
--- ans
Draw the lines
$x + y = 1200$ through $(1200, 0)$ and $(0, 1200)$;
$x - 2y = 0$ through $(0, 0)$ and $(800, 400)$;
$x + 3y = 600$ through $(600, 0)$ and $(0, 200)$.
$(0, 0)$ satisfies $x + y \le 1200$ but not $x + 3y \ge 600$; the test point $(1, 0)$ satisfies $x - 2y \ge 0$, so that region lies below the line $x = 2y$.
Intersection of $x + 3y = 600$ and $x = 2y$: $5y = 600 \Rightarrow C(240, 120)$.
Intersection of $x + y = 1200$ and $x = 2y$: $3y = 1200 \Rightarrow B(800, 400)$.
