@topic Direction cosines of a line
Direction cosines of line $\dfrac{1 - x}{0} = y = z$ are
(A) $1, 1, 1$
(B) $0, \dfrac{-1}{\sqrt{2}}, \dfrac{-1}{\sqrt{2}}$
(C) $1, 0, 0$
(D) $0, -1, -1$
--- ans B
In standard form: $\dfrac{x - 1}{0} = \dfrac{y - 0}{-1} = \dfrac{z - 0}{-1}$, so the direction ratios are $0, -1, -1$ (or $0, 1, 1$).
$\sqrt{0^2 + (-1)^2 + (-1)^2} = \sqrt{2}$.
Direction cosines: $0, \dfrac{-1}{\sqrt{2}}, \dfrac{-1}{\sqrt{2}}$ (check: $0 + \frac{1}{2} + \frac{1}{2} = 1$).
Option (D) gives direction ratios, not direction cosines, since $0 + 1 + 1 \ne 1$.

@topic Types of relations
A relation R on set $A = \{1, 2, 3\}$ is defined as $R = \{(1, 3), (3, 3), (1, 1), (2, 2), (3, 1)\}$ is
(A) only reflexive and symmetric
(B) reflexive only
(C) only reflexive and transitive
(D) reflexive, symmetric and transitive
--- ans D
**Reflexive:** $(1, 1), (2, 2), (3, 3) \in R$.
**Symmetric:** $(1, 3) \in R$ and $(3, 1) \in R$; the other pairs are of the form $(a, a)$.
**Transitive:** $(1, 3), (3, 1) \Rightarrow (1, 1) \in R$; $(3, 1), (1, 3) \Rightarrow (3, 3) \in R$; every other chain involves a pair $(a, a)$ and gives back a pair already in R.
So R is reflexive, symmetric and transitive (an equivalence relation).

@topic Transpose of a matrix
If $A = \begin{bmatrix} \tan x & \cot x \\ -\cot x & \tan x \end{bmatrix}$ and $A + A' = 2I$, then value of $x \in \left[0, \dfrac{\pi}{2}\right]$ is
(A) $0$
(B) $\dfrac{\pi}{3}$
(C) $\dfrac{\pi}{4}$
(D) $\dfrac{\pi}{2}$
--- ans C
$$A + A' = \begin{bmatrix} \tan x & \cot x \\ -\cot x & \tan x \end{bmatrix} + \begin{bmatrix} \tan x & -\cot x \\ \cot x & \tan x \end{bmatrix} = \begin{bmatrix} 2\tan x & 0 \\ 0 & 2\tan x \end{bmatrix} = \begin{bmatrix} 2 & 0 \\ 0 & 2 \end{bmatrix}$$
$\Rightarrow \tan x = 1 \Rightarrow x = \dfrac{\pi}{4}$ in $\left[0, \dfrac{\pi}{2}\right]$.

@topic Derivative of implicit function
If $x + y = xy$, then $\dfrac{dy}{dx}$ is
(A) $\dfrac{y}{x - 1}$
(B) $\dfrac{1}{x - 1}$
(C) $\dfrac{y - 1}{x - 1}$
(D) $\dfrac{1 - y}{x - 1}$
--- ans D
Differentiating w.r.t. $x$: $1 + \dfrac{dy}{dx} = y + x\dfrac{dy}{dx}$
$$\Rightarrow (1 - x)\frac{dy}{dx} = y - 1 \Rightarrow \frac{dy}{dx} = \frac{y - 1}{1 - x} = \frac{1 - y}{x - 1}$$

=== 12 | int | 1 | mcq
@topic Integration by substitution
$\displaystyle\int \frac{dx}{\sec x + \tan x}$ is equal to
(A) $\log\left|\sec x + \tan x\right| + C$
(B) $\log\left|\sec x - \tan x\right| + C$
(C) $\log\left|1 + \cos x\right| + C$
(D) $\log\left|1 + \sin x\right| + C$
--- ans D
$$\int \frac{dx}{\sec x + \tan x} = \int \frac{dx}{\frac{1}{\cos x} + \frac{\sin x}{\cos x}} = \int \frac{\cos x}{1 + \sin x}\,dx$$
Put $1 + \sin x = t \Rightarrow \cos x\,dx = dt$: $\displaystyle\int \frac{dt}{t} = \log|t| + C = \log\left|1 + \sin x\right| + C$.

@topic Cartesian equation of a line – general point
Find the co-ordinates of the point on line $x = \dfrac{y - 1}{2} = \dfrac{z - 2}{3}$ whose y co-ordinate is 3 times the $x$ co-ordinate.
--- ans
Let $\dfrac{x - 0}{1} = \dfrac{y - 1}{2} = \dfrac{z - 2}{3} = \lambda$.
Any point on the line is $A(\lambda,\ 2\lambda + 1,\ 3\lambda + 2)$.
Given $y$ co-ordinate $= 3 \times x$ co-ordinate:

$\therefore$ The required point is $\boxed{A(1, 3, 5)}$

@topic Derivatives of functions in parametric form
If $x = e^{\sin^{-1}t}$, $y = e^{\cos^{-1}t}$, find $\dfrac{dy}{dx}$ at $t = \dfrac{1}{\sqrt{2}}$
--- ans
$$\frac{dx}{dt} = e^{\sin^{-1}t}\cdot\frac{1}{\sqrt{1 - t^2}}, \qquad \frac{dy}{dt} = e^{\cos^{-1}t}\cdot\frac{-1}{\sqrt{1 - t^2}}$$
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = -\frac{e^{\cos^{-1}t}}{e^{\sin^{-1}t}} = -e^{\cos^{-1}t - \sin^{-1}t}$$
At $t = \dfrac{1}{\sqrt{2}}$: $\sin^{-1}\dfrac{1}{\sqrt{2}} = \cos^{-1}\dfrac{1}{\sqrt{2}} = \dfrac{\pi}{4}$, so
$$\left.\frac{dy}{dx}\right|_{t = \frac{1}{\sqrt{2}}} = -e^{\frac{\pi}{4} - \frac{\pi}{4}} = -e^0 = -1$$

=== 27 | int | 3 | sub
@topic Integrals of the form ∫(px+q)/√(ax²+bx+c)
Find: $\displaystyle\int \frac{3x - 1}{\sqrt{x^2 - 4x}}\,dx$
--- ans
Write $3x - 1 = A\dfrac{d}{dx}(x^2 - 4x) + B = A(2x - 4) + B$.
Comparing: $2A = 3 \Rightarrow A = \dfrac{3}{2}$; $\ -4A + B = -1 \Rightarrow B = 5$.
$$I = \frac{3}{2}\int \frac{2x - 4}{\sqrt{x^2 - 4x}}\,dx + 5\int \frac{dx}{\sqrt{x^2 - 4x}}$$
For the first integral put $x^2 - 4x = t$, $(2x - 4)\,dx = dt$: $\displaystyle\frac{3}{2}\int \frac{dt}{\sqrt{t}} = 3\sqrt{t} = 3\sqrt{x^2 - 4x}$.
For the second, $x^2 - 4x = (x - 2)^2 - 2^2$:
$$\int \frac{dx}{\sqrt{(x - 2)^2 - 2^2}} = \log\left|(x - 2) + \sqrt{x^2 - 4x}\right|$$
$$\therefore\ I = 3\sqrt{x^2 - 4x} + 5\log\left|(x - 2) + \sqrt{x^2 - 4x}\right| + C$$

@topic Graphical method – maximisation
Solve the following linear programming problem graphically:
Maximize $Z = 4500x + 5000y$
Subject to constraints
$x + y \le 250$
$25x + 40y \le 7000$
$x \ge 0,\ y \ge 0$
--- ans
Draw the lines $x + y = 250$ (through $(250, 0)$, $(0, 250)$) and $25x + 40y = 7000$, i.e. $5x + 8y = 1400$ (through $(280, 0)$, $(0, 175)$).
$(0, 0)$ satisfies both inequalities, so the feasible region lies on the origin side of both lines, in the first quadrant.
Intersection of $x + y = 250$ and $5x + 8y = 1400$: putting $x = 250 - y$, $1250 - 5y + 8y = 1400 \Rightarrow y = 50,\ x = 200$, i.e. $(200, 50)$.

=== 32a | aod | 5 | sub
@topic Increasing and decreasing functions
Find the sub-interval of $\left(0, \dfrac{\pi}{2}\right)$ in which $f(x) = \log(\sin x + \cos x)$ is increasing and decreasing.
--- ans
For $x \in \left(0, \dfrac{\pi}{2}\right)$, $\sin x + \cos x > 0$, so $f$ is defined there.
$$f'(x) = \frac{1}{\sin x + \cos x}\cdot(\cos x - \sin x) = \frac{\cos x - \sin x}{\sin x + \cos x}$$
For critical points, $f'(x) = 0 \Rightarrow \cos x = \sin x \Rightarrow \tan x = 1 \Rightarrow x = \dfrac{\pi}{4} \in \left(0, \dfrac{\pi}{2}\right)$.
The denominator is positive, so the sign of $f'(x)$ is the sign of $\cos x - \sin x$. The point $x = \dfrac{\pi}{4}$ divides $\left(0, \dfrac{\pi}{2}\right)$ into:

| Interval | Sign of $\cos x - \sin x$ | Nature of $f$ |
|---|---|---|
| $\left(0, \dfrac{\pi}{4}\right)$ | $+$ (here $\cos x > \sin x$) | strictly increasing |
| $\left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ | $-$ (here $\sin x > \cos x$) | strictly decreasing |

$\therefore f$ is **increasing in $\left(0, \dfrac{\pi}{4}\right]$** and **decreasing in $\left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$**.

=== 32b | aod | 5 | sub
@topic Maxima and minima – word problem
@fig 2026-65-2-3-q32.webp
A rectangle of perimeter 30 cm is revolved along one of its sides to sweep out a cylinder of maximum volume. Find the dimensions of the rectangle.
--- ans
Let the rectangle have sides $x$ cm and $y$ cm, and let it be revolved about the side of length $y$.
Then the cylinder has radius $r = x$ and height $h = y$.
Perimeter: $2(x + y) = 30 \Rightarrow y = 15 - x$, $\ 0 < x < 15$.
$$V = \pi r^2h = \pi x^2(15 - x) = \pi\left(15x^2 - x^3\right)$$
$$\frac{dV}{dx} = \pi\left(30x - 3x^2\right) = 3\pi x(10 - x)$$
$\dfrac{dV}{dx} = 0 \Rightarrow x = 10$ (as $x \ne 0$).
$$\frac{d^2V}{dx^2} = \pi(30 - 6x);\quad \left.\frac{d^2V}{dx^2}\right|_{x = 10} = \pi(30 - 60) = -30\pi < 0$$
So $V$ is maximum when $x = 10$, and then $y = 15 - 10 = 5$.
$\therefore$ The dimensions of the rectangle are **10 cm × 5 cm** (revolved about the 5 cm side); maximum volume $= \pi(10)^2(5) = 500\pi\ \text{cm}^3$.

=== 33 | itf | 5 | sub
@topic Domain and range of inverse trigonometric functions
Find the domain of $q(x) = \cos^{-1}(4x^2 - 3)$. Hence, find the value of $x$ for which $q(x) = 0$. Also, write the range of $3q(x) - \pi$.
--- ans
**Domain:** $\cos^{-1}t$ is defined for $-1 \le t \le 1$, so
$$-1 \le 4x^2 - 3 \le 1 \Rightarrow 2 \le 4x^2 \le 4 \Rightarrow \frac{1}{2} \le x^2 \le 1$$
$$\Rightarrow -1 \le x \le -\frac{1}{\sqrt{2}} \quad\text{or}\quad \frac{1}{\sqrt{2}} \le x \le 1$$
Domain of $q = \left[-1, -\dfrac{1}{\sqrt{2}}\right] \cup \left[\dfrac{1}{\sqrt{2}}, 1\right]$.

**$q(x) = 0$:**
$$\cos^{-1}(4x^2 - 3) = 0 \Rightarrow 4x^2 - 3 = \cos 0 = 1 \Rightarrow x^2 = 1 \Rightarrow x = \pm 1$$
Both values lie in the domain, so $x = 1$ or $x = -1$.

**Range of $3q(x) - \pi$:** As $x$ varies over the domain, $4x^2 - 3$ takes every value in $[-1, 1]$, so the range of $q(x) = \cos^{-1}(4x^2 - 3)$ is $[0, \pi]$.
$$0 \le q(x) \le \pi \Rightarrow 0 \le 3q(x) \le 3\pi \Rightarrow -\pi \le 3q(x) - \pi \le 2\pi$$
$\therefore$ Range of $3q(x) - \pi$ is $[-\pi, 2\pi]$.
