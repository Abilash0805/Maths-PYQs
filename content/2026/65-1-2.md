@topic Order and degree
The order and degree of the differential equation : $\dfrac{d}{dx}(\sin y) = y^2$ respectively are
(A) $1, 1$
(B) $2, 1$
(C) $2, 2$
(D) $1, 2$
--- ans A
$\dfrac{d}{dx}(\sin y) = y^2 \Rightarrow \cos y\,\dfrac{dy}{dx} = y^2$.
The highest order derivative is $\dfrac{dy}{dx}$ (order 1) and its power is 1 (degree 1).

@topic Perpendicular distance of a point from a line
The length of perpendicular drawn from the point $(1, 2, 3)$ on line $\dfrac{x}{0} = \dfrac{y}{1} = \dfrac{z}{0}$ is
(A) $2$
(B) $6$
(C) $\sqrt{10}$
(D) $\sqrt{14}$
--- ans C
The line $\dfrac{x}{0} = \dfrac{y}{1} = \dfrac{z}{0}$ passes through the origin with direction $\hat{j}$, i.e. it is the $y$-axis.
Foot of the perpendicular from $(1, 2, 3)$ is $(0, 2, 0)$.
Length $= \sqrt{1^2 + 0^2 + 3^2} = \sqrt{10}$.

@topic Range of principal value branch
If $\tan^{-1}x = 3y$, then
(A) $-\dfrac{\pi}{2} < y < \dfrac{\pi}{2}$
(B) $-\dfrac{3\pi}{2} < y < \dfrac{3\pi}{2}$
(C) $-\dfrac{\pi}{6} < y < \dfrac{\pi}{6}$

The principal value branch of $\tan^{-1}x$ is the open interval $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$, so

Which of the following cannot be an order of a column-matrix ?
(A) $1 \times 2$
(B) $2 \times 1$
(C) $1 \times 1$
(D) $m \times 1$, where $m \in \mathbb{N}$
--- ans A
A column matrix has exactly **one column**, so its order is $m \times 1$.
$1 \times 2$ has two columns (it is a row matrix), so it cannot be the order of a column matrix.

=== 17 | mat | 1 | mcq
@topic Symmetric and skew-symmetric matrices
If A and B are symmetric matrices of same order, then which of the following matrices is a skew-symmetric matrix ?
(A) $A^2 + B^2$
(B) $A^2 - B^2$
(C) $AB + BA$
(D) $AB - BA$
--- ans D
Given $A' = A$, $B' = B$.
$(AB - BA)' = (AB)' - (BA)' = B'A' - A'B' = BA - AB = -(AB - BA)$, so $AB - BA$ is skew-symmetric.
(For comparison, $(A^2)' = (A')^2 = A^2$, so $A^2 \pm B^2$ are symmetric, and $(AB + BA)' = BA + AB$ is symmetric.)

The absolute maximum value of $f(x) = x^2 + 1$ in $[-5, 2]$ is
(A) $26$

@topic Direction ratios and projection of a vector
A vector $\vec{a}$ of magnitude 14 has direction ratios $\langle 2, 3, -6 \rangle$. Find the projection of the vector $\vec{a}$ on $\hat{i}$.
--- ans
Direction ratios $2, 3, -6$ give $\sqrt{2^2 + 3^2 + (-6)^2} = \sqrt{49} = 7$, so the direction cosines are
$$l = \frac{2}{7},\quad m = \frac{3}{7},\quad n = -\frac{6}{7}$$
$$\therefore\ \vec{a} = |\vec{a}|\left(l\hat{i} + m\hat{j} + n\hat{k}\right) = 14\left(\frac{2}{7}\hat{i} + \frac{3}{7}\hat{j} - \frac{6}{7}\hat{k}\right) = 4\hat{i} + 6\hat{j} - 12\hat{k}$$
Projection of $\vec{a}$ on $\hat{i}$ $= \dfrac{\vec{a} \cdot \hat{i}}{|\hat{i}|} = \dfrac{(4\hat{i} + 6\hat{j} - 12\hat{k}) \cdot \hat{i}}{1} = 4$.
$\therefore$ The projection of $\vec{a}$ on $\hat{i}$ is $\boxed{4}$.

@topic Simplification using principal values
Simplify : $\cot^{-1}\sqrt{\dfrac{1 + \cos 2x}{1 - \cos 2x}}$, $x \in \left(0, \dfrac{\pi}{2}\right)$.
--- ans
Using $1 + \cos 2x = 2\cos^2 x$ and $1 - \cos 2x = 2\sin^2 x$:
$$\cot^{-1}\sqrt{\frac{2\cos^2 x}{2\sin^2 x}} = \cot^{-1}\left|\cot x\right|$$
For $x \in \left(0, \dfrac{\pi}{2}\right)$, $\cot x > 0$, so $|\cot x| = \cot x$; also $x$ lies in $(0, \pi)$, the principal value branch of $\cot^{-1}$.
$$\therefore\ \cot^{-1}\sqrt{\frac{1 + \cos 2x}{1 - \cos 2x}} = \cot^{-1}(\cot x) = \boxed{x}$$

=== 27a | de | 3 | sub
@topic Homogeneous differential equation
Find the general solution of the differential equation :
$$y^2\,dx + (x^2 - xy + y^2)\,dy = 0$$
--- ans
$$\frac{dx}{dy} = -\frac{x^2 - xy + y^2}{y^2} = -\left(\frac{x}{y}\right)^2 + \frac{x}{y} - 1$$
which is homogeneous. Put $x = vy \Rightarrow \dfrac{dx}{dy} = v + y\dfrac{dv}{dy}$:
$$v + y\frac{dv}{dy} = -v^2 + v - 1 \Rightarrow y\frac{dv}{dy} = -(1 + v^2)$$
$$\Rightarrow \frac{dv}{1 + v^2} = -\frac{dy}{y}$$
Integrating both sides: $\tan^{-1}v = -\log|y| + C$
$$\therefore\ \boxed{\tan^{-1}\left(\frac{x}{y}\right) + \log|y| = C}$$
is the general solution.

=== 27b | de | 3 | sub
@topic Variable separable – particular solution
Find the particular solution of the differential equation $\dfrac{dy}{dx} = y\tan x$, given that $y = 2$ if $x = 0$.
--- ans
Separating the variables:
$$\frac{dy}{y} = \tan x\,dx$$
Integrating both sides:
$$\log|y| = \log|\sec x| + \log C \Rightarrow \log\left|\frac{y}{\sec x}\right| = \log C \Rightarrow y = C\sec x$$
Using $y = 2$ when $x = 0$: $2 = C\sec 0 = C \Rightarrow C = 2$.
$\therefore$ The required particular solution is $\boxed{y = 2\sec x}$.

=== 30 | int | 3 | sub
@topic Integration by parts (definite)
Evaluate : $\displaystyle\int_{0}^{1} x\sin^{-1}x\,dx$
--- ans
Integrating by parts, taking $\sin^{-1}x$ as the first function:
$$I = \left[\sin^{-1}x\cdot\frac{x^2}{2}\right]_0^1 - \int_0^1 \frac{1}{\sqrt{1 - x^2}}\cdot\frac{x^2}{2}\,dx = \frac{\pi}{4} + \frac{1}{2}\int_0^1 \frac{(1 - x^2) - 1}{\sqrt{1 - x^2}}\,dx$$
$$= \frac{\pi}{4} + \frac{1}{2}\left[\int_0^1 \sqrt{1 - x^2}\,dx - \int_0^1 \frac{dx}{\sqrt{1 - x^2}}\right]$$
$$= \frac{\pi}{4} + \frac{1}{2}\left[\frac{x}{2}\sqrt{1 - x^2} + \frac{1}{2}\sin^{-1}x - \sin^{-1}x\right]_0^1$$
$$= \frac{\pi}{4} + \frac{1}{2}\left[\frac{x}{2}\sqrt{1 - x^2} - \frac{1}{2}\sin^{-1}x\right]_0^1 = \frac{\pi}{4} + \frac{1}{2}\left(0 - \frac{\pi}{4}\right)$$
$$\therefore\ I = \frac{\pi}{4} - \frac{\pi}{8} = \boxed{\frac{\pi}{8}}$$

=== 32 | cd | 5 | sub
@topic Second order derivative – parametric form
If $x = 3\sin t - \sin 3t$, $y = 3\cos t - \cos 3t$
find $\dfrac{dy}{dx}$ and prove that $\dfrac{d^2y}{dx^2} = \dfrac{-\operatorname{cosec}^3 2t \cdot \operatorname{cosec} t}{3}$
--- ans
$$\frac{dx}{dt} = 3\cos t - 3\cos 3t, \qquad \frac{dy}{dt} = -3\sin t + 3\sin 3t$$
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{3(\sin 3t - \sin t)}{3(\cos t - \cos 3t)}$$
Using $\sin C - \sin D = 2\cos\dfrac{C + D}{2}\sin\dfrac{C - D}{2}$ and $\cos C - \cos D = -2\sin\dfrac{C + D}{2}\sin\dfrac{C - D}{2}$:
$$\frac{dy}{dx} = \frac{2\cos 2t\,\sin t}{2\sin 2t\,\sin t} = \cot 2t$$
Differentiating w.r.t. $x$:
$$\frac{d^2y}{dx^2} = -2\operatorname{cosec}^2 2t\cdot\frac{dt}{dx} = \frac{-2\operatorname{cosec}^2 2t}{3(\cos t - \cos 3t)}$$
$$= \frac{-2\operatorname{cosec}^2 2t}{3\cdot 2\sin 2t\,\sin t} = \frac{-\operatorname{cosec}^2 2t\cdot\operatorname{cosec} 2t\cdot\operatorname{cosec} t}{3}$$
$$\therefore\ \frac{d^2y}{dx^2} = \frac{-\operatorname{cosec}^3 2t\cdot\operatorname{cosec} t}{3}$$
Hence proved, with $\dfrac{dy}{dx} = \cot 2t$.

=== 33 | 3d | 5 | sub
@topic Intersection of two lines
Prove that the line through points $A(0, -1, -1)$ and $B(4, 5, 1)$ intersects the line through points $C(3, 9, 4)$ and $D(-4, 4, 4)$. Hence, write the equation of line passing through the point of intersection of lines AB and CD as well as origin.
--- ans
Direction ratios of AB: $4 - 0,\ 5 + 1,\ 1 + 1 = 4, 6, 2$, i.e. $2, 3, 1$.
Direction ratios of CD: $-4 - 3,\ 4 - 9,\ 4 - 4 = -7, -5, 0$.
$$AB: \frac{x}{2} = \frac{y + 1}{3} = \frac{z + 1}{1} = \lambda, \qquad CD: \frac{x - 3}{-7} = \frac{y - 9}{-5} = \frac{z - 4}{0} = \mu$$
Any point on AB: $(2\lambda,\ 3\lambda - 1,\ \lambda - 1)$
Any point on CD: $(-7\mu + 3,\ -5\mu + 9,\ 4)$
The lines intersect if for some $\lambda, \mu$:
$2\lambda = -7\mu + 3 \quad\cdots(1)$
$3\lambda - 1 = -5\mu + 9 \quad\cdots(2)$
$\lambda - 1 = 4 \quad\cdots(3)$
From (3): $\lambda = 5$. Then (1): $10 = -7\mu + 3 \Rightarrow \mu = -1$.
Check in (2): LHS $= 15 - 1 = 14$, RHS $= 5 + 9 = 14$ ✓.
All three equations are satisfied, so **the lines AB and CD intersect**.

Point of intersection (put $\lambda = 5$ in AB): $P(10, 14, 4)$.

The required line passes through $O(0, 0, 0)$ and $P(10, 14, 4)$; its direction ratios are $10, 14, 4$, i.e. $5, 7, 2$.
$$\therefore\ \boxed{\frac{x}{5} = \frac{y}{7} = \frac{z}{2}} \quad\text{or}\quad \vec{r} = \lambda\left(5\hat{i} + 7\hat{j} + 2\hat{k}\right)$$
