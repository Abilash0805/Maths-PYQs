@topic Perpendicular distance of a point from a line
The length of perpendicular drawn from the point $(3, 4, 2)$ on the line $\dfrac{x}{0} = \dfrac{y}{0} = \dfrac{z}{1}$ is
(A) $2$
(B) $9$
(C) $5$
(D) $\sqrt{29}$
--- ans C
The line $\dfrac{x}{0} = \dfrac{y}{0} = \dfrac{z}{1}$ passes through the origin with direction $\hat{k}$, i.e. it is the $z$-axis.
Foot of the perpendicular from $(3, 4, 2)$ is $(0, 0, 2)$.
Length $= \sqrt{3^2 + 4^2 + 0^2} = \sqrt{25} = 5$.

@topic Range of principal value branch
If $\sin^{-1}x + \pi = y$, then
(A) $-\dfrac{\pi}{2} \le y \le \dfrac{\pi}{2}$
(B) $-\dfrac{3\pi}{2} \le y \le -\dfrac{\pi}{2}$
(C) $\dfrac{\pi}{2} \le y \le \dfrac{3\pi}{2}$
(D) $0 \le y \le \pi$
--- ans C
The principal value branch of $\sin^{-1}x$ is $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$, so
$$-\frac{\pi}{2} \le \sin^{-1}x \le \frac{\pi}{2} \;\Rightarrow\; -\frac{\pi}{2} + \pi \le \sin^{-1}x + \pi \le \frac{\pi}{2} + \pi \;\Rightarrow\; \frac{\pi}{2} \le y \le \frac{3\pi}{2}$$

=== 6 | mat | 1 | mcq
@topic Types of matrices
If $A = [a_{ij}]_{3 \times 3}$ is a scalar matrix then which of the following must be true ?
(A) A must be a symmetric matrix.
(B) A must be a skew-symmetric matrix.
(C) A must be an identity matrix.
(D) A must be a null matrix.
--- ans A
A scalar matrix is a diagonal matrix with all diagonal elements equal, i.e. $A = kI$ for some scalar $k$.
$A' = (kI)' = kI = A$, so $A$ is always **symmetric**.
It is skew-symmetric or null only when $k = 0$, and the identity matrix only when $k = 1$ — so (B), (C), (D) need not hold.

@topic Symmetric and skew-symmetric matrices
If A and B are symmetric matrics of same order, then $(AB - BA)$ is a
(A) Zero matrix
(B) Identity matrix
(C) Symmetric matrix
(D) Skew symmetric matrix
--- ans D
Given $A' = A$, $B' = B$.
$(AB - BA)' = (AB)' - (BA)' = B'A' - A'B' = BA - AB = -(AB - BA)$.
$\therefore AB - BA$ is a skew symmetric matrix.

=== 11 | aod | 1 | mcq
@topic Absolute maximum and minimum
The least value of $f(x) = e^{-x}$ in $[0, 3]$ is
(A) $e^{-3}$
(B) $-1$
(C) $1$
(D) $-e^{3}$
--- ans A
$f'(x) = -e^{-x} < 0$ for all $x$, so $f$ is strictly decreasing on $[0, 3]$.
Hence the least value is at the right end point: $f(3) = e^{-3}$.
(Also $f(0) = 1$ is the greatest value.)

@topic Order and degree
The order and degree of the differential equation :
$\dfrac{d}{dx}(y')^3 + (y')^3 = 1$ respectively are where $y' = \dfrac{dy}{dx}$
(A) $1, 3$
(B) $2, 1$

@topic Simplification using principal values
Simplify : $\sin^{-1}\sqrt{\dfrac{1 + \cos 2x}{2}}$, $0 < x < \dfrac{\pi}{2}$.
--- ans
Using $1 + \cos 2x = 2\cos^2 x$:
$$\sin^{-1}\sqrt{\frac{2\cos^2 x}{2}} = \sin^{-1}\left|\cos x\right| = \sin^{-1}(\cos x) \quad (\because \cos x > 0 \text{ for } 0 < x < \tfrac{\pi}{2})$$
$$= \sin^{-1}\left[\sin\left(\frac{\pi}{2} - x\right)\right]$$
Since $0 < x < \dfrac{\pi}{2}$, we have $0 < \dfrac{\pi}{2} - x < \dfrac{\pi}{2}$, which lies in the principal value branch $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.
$$\therefore\ \sin^{-1}\sqrt{\frac{1 + \cos 2x}{2}} = \boxed{\frac{\pi}{2} - x}$$

Evaluate : $\cos\left[\sin^{-1}(-1) - \tan^{-1}(-\sqrt{3})\right]$.

=== 24 | vec | 2 | sub
@topic Area of a triangle using cross product
Using vectors, find the area of $\Delta ABC$ with vertices $A(1, 2, 3)$, $B(2, -1, 4)$ and $C(4, 5, -1)$.
--- ans
$\overrightarrow{AB} = (2 - 1)\hat{i} + (-1 - 2)\hat{j} + (4 - 3)\hat{k} = \hat{i} - 3\hat{j} + \hat{k}$
$\overrightarrow{AC} = (4 - 1)\hat{i} + (5 - 2)\hat{j} + (-1 - 3)\hat{k} = 3\hat{i} + 3\hat{j} - 4\hat{k}$
$$\overrightarrow{AB} \times \overrightarrow{AC} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 1 & -3 & 1 \\ 3 & 3 & -4 \end{vmatrix} = (12 - 3)\hat{i} - (-4 - 3)\hat{j} + (3 + 9)\hat{k} = 9\hat{i} + 7\hat{j} + 12\hat{k}$$
$|\overrightarrow{AB} \times \overrightarrow{AC}| = \sqrt{81 + 49 + 144} = \sqrt{274}$
$$\text{Area of } \Delta ABC = \frac{1}{2}\left|\overrightarrow{AB} \times \overrightarrow{AC}\right| = \boxed{\frac{\sqrt{274}}{2}\ \text{sq. units}}$$

=== 26 | int | 3 | sub
@topic Integration by parts (definite)
Evaluate : $\displaystyle\int_{0}^{1} \log(1 + x^2)\,dx$
--- ans
Integrating by parts, taking $\log(1 + x^2)$ as the first function and $1$ as the second function:
$$I = \Big[x\log(1 + x^2)\Big]_0^1 - \int_0^1 \frac{2x}{1 + x^2}\cdot x\,dx = \log 2 - 2\int_0^1 \frac{x^2}{1 + x^2}\,dx$$
$$= \log 2 - 2\int_0^1 \frac{(1 + x^2) - 1}{1 + x^2}\,dx = \log 2 - 2\int_0^1 \left(1 - \frac{1}{1 + x^2}\right)dx$$
$$= \log 2 - 2\Big[x - \tan^{-1}x\Big]_0^1 = \log 2 - 2\left(1 - \frac{\pi}{4}\right)$$
$$\therefore\ I = \boxed{\log 2 - 2 + \frac{\pi}{2}}$$

=== 30a | de | 3 | sub
@topic Homogeneous differential equation
Find the general solution of the differential equation
$$(y^2 - x^2)\,dx = 2xy\,dy$$
--- ans
$$\frac{dy}{dx} = \frac{y^2 - x^2}{2xy} = \frac{1}{2}\left(\frac{y}{x} - \frac{x}{y}\right)$$
which is homogeneous. Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v^2 - 1}{2v} \Rightarrow x\frac{dv}{dx} = \frac{v^2 - 1 - 2v^2}{2v} = -\frac{1 + v^2}{2v}$$
$$\Rightarrow \frac{2v}{1 + v^2}\,dv = -\frac{dx}{x}$$
Integrating both sides $\left(\text{using } \displaystyle\int \frac{2v}{1 + v^2}\,dv = \log(1 + v^2)\right)$:
$$\log(1 + v^2) = -\log|x| + \log|C| \Rightarrow \log\left|(1 + v^2)\,x\right| = \log|C| \Rightarrow (1 + v^2)\,x = C$$
Putting $v = \dfrac{y}{x}$: $\left(1 + \dfrac{y^2}{x^2}\right)x = C \Rightarrow \dfrac{x^2 + y^2}{x} = C$
$$\therefore\ \boxed{x^2 + y^2 = Cx}$$
is the general solution, where $C$ is an arbitrary constant.

=== 30b | de | 3 | sub
@topic Variable separable – particular solution
Find the particular solution of the differential equation
$(1 + e^{2x})\,dy + (1 + y^2)\,e^{x}\,dx = 0$, given that $y(1) = 0$.
--- ans
Separating the variables:
$$\frac{dy}{1 + y^2} = -\frac{e^x}{1 + e^{2x}}\,dx$$
Integrating both sides, with $e^x = t \Rightarrow e^x\,dx = dt$ on the right:
$$\int \frac{dy}{1 + y^2} = -\int \frac{dt}{1 + t^2} \Rightarrow \tan^{-1}y = -\tan^{-1}t + C$$
$$\Rightarrow \tan^{-1}y + \tan^{-1}(e^x) = C$$
Using $y = 0$ when $x = 1$: $\tan^{-1}0 + \tan^{-1}e = C \Rightarrow C = \tan^{-1}e$.
$\therefore$ The required particular solution is
$$\boxed{\tan^{-1}y + \tan^{-1}(e^x) = \tan^{-1}e}$$
(Equivalently, $y = \tan\left(\tan^{-1}e - \tan^{-1}e^x\right) = \dfrac{e - e^x}{1 + e^{x + 1}}$.)

=== 32 | 3d | 5 | sub
@topic Distance between parallel lines
Show that line AB passing through points $A(0, 4, 1)$, $B(2, 3, -1)$ and the line CD passing through points $C(4, 5, 0)$, $D(2, 6, 2)$ are parallel. Also, find distance between them.
--- ans
Direction ratios of AB: $2 - 0,\ 3 - 4,\ -1 - 1 = 2, -1, -2$
Direction ratios of CD: $2 - 4,\ 6 - 5,\ 2 - 0 = -2, 1, 2$
Since $\dfrac{2}{-2} = \dfrac{-1}{1} = \dfrac{-2}{2} = -1$, the direction ratios are proportional, so **AB $\parallel$ CD**.

Equations of the lines in vector form (common direction $\vec{b} = 2\hat{i} - \hat{j} - 2\hat{k}$):
$$AB: \vec{r} = 4\hat{j} + \hat{k} + \lambda\left(2\hat{i} - \hat{j} - 2\hat{k}\right)$$
$$CD: \vec{r} = 4\hat{i} + 5\hat{j} + \mu\left(2\hat{i} - \hat{j} - 2\hat{k}\right)$$
Here $\vec{a}_1 = 4\hat{j} + \hat{k}$, $\vec{a}_2 = 4\hat{i} + 5\hat{j}$, so $\vec{a}_2 - \vec{a}_1 = 4\hat{i} + \hat{j} - \hat{k}$.
$$\vec{b} \times (\vec{a}_2 - \vec{a}_1) = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 2 & -1 & -2 \\ 4 & 1 & -1 \end{vmatrix} = (1 + 2)\hat{i} - (-2 + 8)\hat{j} + (2 + 4)\hat{k} = 3\hat{i} - 6\hat{j} + 6\hat{k}$$
$|\vec{b} \times (\vec{a}_2 - \vec{a}_1)| = \sqrt{9 + 36 + 36} = 9$, $\quad |\vec{b}| = \sqrt{4 + 1 + 4} = 3$
(Since $\vec{b} \times (\vec{a}_2 - \vec{a}_1) \ne \vec{0}$, the point C does not lie on AB, so the lines are distinct parallel lines.)
Distance between the parallel lines:
$$d = \frac{|\vec{b} \times (\vec{a}_2 - \vec{a}_1)|}{|\vec{b}|} = \frac{9}{3} = \boxed{3\ \text{units}}$$

@topic Second order derivative – parametric form
If $x = a(\sin t - t\cos t)$ and $y = b(\cos t + t\sin t)$, then find $\dfrac{dy}{dx}$ and $\dfrac{d^2y}{dx^2}$.
--- ans
$$\frac{dx}{dt} = a\left(\cos t - \cos t + t\sin t\right) = at\sin t$$
$$\frac{dy}{dt} = b\left(-\sin t + \sin t + t\cos t\right) = bt\cos t$$
$$\therefore\ \frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{bt\cos t}{at\sin t} = \boxed{\frac{b}{a}\cot t}$$
Differentiating w.r.t. $x$:
$$\frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{b}{a}\cot t\right)\cdot\frac{dt}{dx} = -\frac{b}{a}\operatorname{cosec}^2 t\cdot\frac{1}{at\sin t}$$
$$\therefore\ \frac{d^2y}{dx^2} = \boxed{-\frac{b\operatorname{cosec}^3 t}{a^2t}}$$
