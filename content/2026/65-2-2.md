@topic Standard integrals
$\displaystyle\int \frac{dx}{1 + \cos x}$ is equal to
(A) $\dfrac{1}{2}\tan\dfrac{x}{2} + C$
(B) $\dfrac{-1}{2}\cot\dfrac{x}{2} + C$
(C) $-\cot\dfrac{x}{2} + C$
(D) $\tan\dfrac{x}{2} + C$
--- ans D
Using $1 + \cos x = 2\cos^2\dfrac{x}{2}$:
$$\int \frac{dx}{1 + \cos x} = \frac{1}{2}\int \sec^2\frac{x}{2}\,dx = \frac{1}{2}\cdot\frac{\tan\frac{x}{2}}{\frac{1}{2}} + C = \tan\frac{x}{2} + C$$

@topic Variable separable
The general solution of the differential equation $x\,dy - y\,dx = 0$ is
(A) $x^2 - y^2 = k$
(B) $xy = k$
(C) $x = ky$
(D) $\log y + \log x = k$
--- ans C
Separating the variables: $\dfrac{dy}{y} = \dfrac{dx}{x}$.
Integrating: $\log|y| = \log|x| + \log|c| \Rightarrow y = cx$, i.e. $x = ky$ (with $k = \dfrac{1}{c}$).

@topic Direction cosines and ratios
Direction cosines of line $x = y = 1 - z$ are
(A) $1, 1, 1$
(B) $\dfrac{1}{\sqrt{3}}, \dfrac{1}{\sqrt{3}}, \dfrac{-1}{\sqrt{3}}$
(C) $0, 0, 1$
(D) $\dfrac{1}{\sqrt{3}}, \dfrac{1}{\sqrt{3}}, \dfrac{1}{\sqrt{3}}$
--- ans B
In standard form: $\dfrac{x - 0}{1} = \dfrac{y - 0}{1} = \dfrac{z - 1}{-1}$, so the direction ratios are $1, 1, -1$.

Direction cosines: $\dfrac{1}{\sqrt{3}}, \dfrac{1}{\sqrt{3}}, \dfrac{-1}{\sqrt{3}}$.

@topic Types of relations
A relation R on set $A = \{1, 2, 3\}$ defined as $R = \{(1, 2), (2, 1), (2, 2)\}$ is
(A) Reflexive only
(B) Reflexive and Transitive
(C) Symmetric and Transitive
(D) Symmetric only
--- ans D
**Not reflexive:** $(1, 1) \notin R$ (also $(3, 3) \notin R$).
**Symmetric:** $(1, 2) \in R$ and $(2, 1) \in R$; $(2, 2)$ is its own reverse.
**Not transitive:** $(1, 2) \in R$ and $(2, 1) \in R$ but $(1, 1) \notin R$.
So R is symmetric only.

@topic Transpose
If $A = \begin{bmatrix} \frac{1}{2}\cos x & -\sin x \\ \sin x & \frac{1}{2}\cos x \end{bmatrix}$ and $A + A' = I$, then value of $x \in \left[\dfrac{-\pi}{2}, \dfrac{\pi}{2}\right]$ is
(A) $\dfrac{\pi}{2}$
(B) $\dfrac{\pi}{3}$
(C) $0$
(D) $\dfrac{-\pi}{2}$
--- ans C
$$A + A' = \begin{bmatrix} \frac{1}{2}\cos x & -\sin x \\ \sin x & \frac{1}{2}\cos x \end{bmatrix} + \begin{bmatrix} \frac{1}{2}\cos x & \sin x \\ -\sin x & \frac{1}{2}\cos x \end{bmatrix} = \begin{bmatrix} \cos x & 0 \\ 0 & \cos x \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$
$\Rightarrow \cos x = 1 \Rightarrow x = 0$ in $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

If $e^{x + y} = 3x$, then $\dfrac{dy}{dx}$ is
(A) $\dfrac{3}{e^{x + y}}$

@topic Foot of perpendicular and image
Find the co-ordinates of foot of perpendicular drawn from $(0, 0, 0)$ to line $\dfrac{x}{1} = \dfrac{y + 1}{-1} = \dfrac{z - 3}{-2}$.
--- ans
Let $P(0, 0, 0)$ and let $Q$ be the foot of the perpendicular on the line
$$\frac{x}{1} = \frac{y + 1}{-1} = \frac{z - 3}{-2} = \lambda$$
Any point on the line is $Q(\lambda,\ -\lambda - 1,\ 3 - 2\lambda)$, so the direction ratios of $PQ$ are $\lambda,\ -\lambda - 1,\ 3 - 2\lambda$.
Direction ratios of the line: $1, -1, -2$.
Since $PQ \perp$ line:
$$1(\lambda) - 1(-\lambda - 1) - 2(3 - 2\lambda) = 0 \Rightarrow 6\lambda - 5 = 0 \Rightarrow \lambda = \frac{5}{6}$$
$\therefore$ Foot of the perpendicular is $\boxed{Q\left(\dfrac{5}{6}, -\dfrac{11}{6}, \dfrac{4}{3}\right)}$

=== 25 | cd | 2 | sub
@topic Parametric differentiation
If $x = \sin t - \cos t$, $y = \sin t\cos t$, find $\dfrac{dy}{dx}$ at $t = \dfrac{\pi}{4}$.
--- ans
$$\frac{dx}{dt} = \cos t + \sin t, \qquad \frac{dy}{dt} = \cos t\cdot\cos t + \sin t\,(-\sin t) = \cos^2 t - \sin^2 t$$
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{\cos^2 t - \sin^2 t}{\cos t + \sin t} = \frac{(\cos t - \sin t)(\cos t + \sin t)}{\cos t + \sin t} = \cos t - \sin t$$
$$\therefore\ \left.\frac{dy}{dx}\right|_{t = \frac{\pi}{4}} = \cos\frac{\pi}{4} - \sin\frac{\pi}{4} = \frac{1}{\sqrt{2}} - \frac{1}{\sqrt{2}} = 0$$

Solve the following linear programming problem graphically:
Maximize $Z = 8000x + 12000y$
Subject to constraints
$3x + 4y \le 60$
$x + 3y \le 30$

--- ans
Draw the lines $3x + 4y = 60$ (through $(20, 0)$, $(0, 15)$) and $x + 3y = 30$ (through $(30, 0)$, $(0, 10)$).

@topic Special forms
Find: $\displaystyle\int \frac{2x + 1}{\sqrt{6x + x^2}}\,dx$
--- ans
Write $2x + 1 = A\dfrac{d}{dx}(6x + x^2) + B = A(6 + 2x) + B$.
Comparing: $2A = 2 \Rightarrow A = 1$; $\ 6A + B = 1 \Rightarrow B = -5$.
$$I = \int \frac{6 + 2x}{\sqrt{6x + x^2}}\,dx - 5\int \frac{dx}{\sqrt{6x + x^2}}$$
For the first integral put $6x + x^2 = t$, $(6 + 2x)\,dx = dt$: $\displaystyle\int \frac{dt}{\sqrt{t}} = 2\sqrt{t} = 2\sqrt{6x + x^2}$.
For the second, $6x + x^2 = (x + 3)^2 - 3^2$:
$$\int \frac{dx}{\sqrt{(x + 3)^2 - 3^2}} = \log\left|(x + 3) + \sqrt{6x + x^2}\right|$$
$$\therefore\ I = 2\sqrt{6x + x^2} - 5\log\left|(x + 3) + \sqrt{6x + x^2}\right| + C$$

=== 32 | itf | 5 | sub
@topic Domain and range
Find the domain of $p(x) = \sin^{-1}(1 - 2x^2)$. Hence, find the value of $x$ for which $p(x) = \dfrac{\pi}{6}$. Also, write the range of $2p(x) + \dfrac{\pi}{2}$.
--- ans
**Domain:** $\sin^{-1}t$ is defined for $-1 \le t \le 1$, so
$$-1 \le 1 - 2x^2 \le 1 \Rightarrow -2 \le -2x^2 \le 0 \Rightarrow 0 \le x^2 \le 1 \Rightarrow -1 \le x \le 1$$
Domain of $p = [-1, 1]$.

**$p(x) = \dfrac{\pi}{6}$:**
$$\sin^{-1}(1 - 2x^2) = \frac{\pi}{6} \Rightarrow 1 - 2x^2 = \sin\frac{\pi}{6} = \frac{1}{2} \Rightarrow x^2 = \frac{1}{4} \Rightarrow x = \pm\frac{1}{2}$$
Both values lie in $[-1, 1]$, so $x = \dfrac{1}{2}$ or $x = -\dfrac{1}{2}$.

**Range of $2p(x) + \dfrac{\pi}{2}$:** As $x$ varies over $[-1, 1]$, $1 - 2x^2$ takes every value in $[-1, 1]$, so the range of $p(x) = \sin^{-1}(1 - 2x^2)$ is $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.
$$-\frac{\pi}{2} \le p(x) \le \frac{\pi}{2} \Rightarrow -\pi \le 2p(x) \le \pi \Rightarrow -\frac{\pi}{2} \le 2p(x) + \frac{\pi}{2} \le \frac{3\pi}{2}$$
$\therefore$ Range of $2p(x) + \dfrac{\pi}{2}$ is $\left[-\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right]$.

@topic Increasing and decreasing functions
Find the sub-interval of $(0, \pi)$ in which $f(x) = \tan^{-1}(\sin x - \cos x)$ is increasing and decreasing.
--- ans
$$f'(x) = \frac{1}{1 + (\sin x - \cos x)^2}\cdot(\cos x + \sin x) = \frac{\cos x + \sin x}{1 + (\sin x - \cos x)^2}$$
The denominator is always positive, so the sign of $f'(x)$ is the sign of $\cos x + \sin x = \sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right)$.
$f'(x) = 0 \Rightarrow \cos x + \sin x = 0 \Rightarrow \tan x = -1 \Rightarrow x = \dfrac{3\pi}{4}$ (in $(0, \pi)$).
This point divides $(0, \pi)$ into $\left(0, \dfrac{3\pi}{4}\right)$ and $\left(\dfrac{3\pi}{4}, \pi\right)$:

| Interval | Sign of $\cos x + \sin x$ | Nature of $f$ |
|---|---|---|
| $\left(0, \dfrac{3\pi}{4}\right)$ | $+$ (here $x + \frac{\pi}{4} \in \left(\frac{\pi}{4}, \pi\right)$) | strictly increasing |
| $\left(\dfrac{3\pi}{4}, \pi\right)$ | $-$ (here $x + \frac{\pi}{4} \in \left(\pi, \frac{5\pi}{4}\right)$) | strictly decreasing |

$\therefore f$ is **increasing in $\left(0, \dfrac{3\pi}{4}\right]$** and **decreasing in $\left[\dfrac{3\pi}{4}, \pi\right)$**.

=== 35b | aod | 5 | sub
@topic Optimisation problems
@fig 2026-65-2-2-q35.webp
A rectangle of perimeter 24 cm is revolved along one of its sides to sweep out a cylinder of maximum volume. Find the dimensions of the rectangle.
--- ans
Let the rectangle have sides $x$ cm and $y$ cm, and let it be revolved about the side of length $y$.
Then the cylinder has radius $r = x$ and height $h = y$.
Perimeter: $2(x + y) = 24 \Rightarrow y = 12 - x$, $\ 0 < x < 12$.
$$V = \pi r^2h = \pi x^2(12 - x) = \pi\left(12x^2 - x^3\right)$$
$$\frac{dV}{dx} = \pi\left(24x - 3x^2\right) = 3\pi x(8 - x)$$
$\dfrac{dV}{dx} = 0 \Rightarrow x = 8$ (as $x \ne 0$).
$$\frac{d^2V}{dx^2} = \pi(24 - 6x);\quad \left.\frac{d^2V}{dx^2}\right|_{x = 8} = \pi(24 - 48) = -24\pi < 0$$
So $V$ is maximum when $x = 8$, and then $y = 12 - 8 = 4$.
$\therefore$ The dimensions of the rectangle are **8 cm × 4 cm** (revolved about the 4 cm side); maximum volume $= \pi(8)^2(4) = 256\pi\ \text{cm}^3$.
