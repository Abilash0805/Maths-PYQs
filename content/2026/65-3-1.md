If $x = t + \dfrac{1}{t}$ and $y = t - \dfrac{1}{t}$, find $\dfrac{dy}{dx}$ at $t = 2$.
--- ans

Find the sub-interval(s) of $\left(0, \dfrac{\pi}{2}\right)$ in which $f(x) = \tan x - 4x$ is increasing.
--- ans
$$f'(x) = \sec^2 x - 4$$
$f'(x) = 0 \Rightarrow \sec^2 x = 4 \Rightarrow \cos x = \dfrac{1}{2}$ (as $\cos x > 0$ in $\left(0, \frac{\pi}{2}\right)$) $\Rightarrow x = \dfrac{\pi}{3}$.

@topic One-one and onto functions
Show that $f : \mathbb{R} \to \mathbb{R}$ defined as $f(x) = \dfrac{x}{\sqrt{1 + x^2}}$ is one-one but not onto.
--- ans
**One-one:** Let $x_1, x_2 \in \mathbb{R}$ with $f(x_1) = f(x_2)$:
$$\frac{x_1}{\sqrt{1 + x_1^2}} = \frac{x_2}{\sqrt{1 + x_2^2}}$$
Since $\sqrt{1 + x^2} > 0$, $f(x)$ has the same sign as $x$; so $x_1$ and $x_2$ are of the same sign (or both zero).
Squaring:
$$x_1^2(1 + x_2^2) = x_2^2(1 + x_1^2) \Rightarrow x_1^2 + x_1^2x_2^2 = x_2^2 + x_1^2x_2^2 \Rightarrow x_1^2 = x_2^2$$
$\Rightarrow x_1 = x_2$ (rejecting $x_1 = -x_2$, as $x_1, x_2$ have the same sign).
Hence $f$ is **one-one**.

**Not onto:** Let $y \in \mathbb{R}$ and suppose $y = \dfrac{x}{\sqrt{1 + x^2}}$.
$$y^2(1 + x^2) = x^2 \Rightarrow x^2(1 - y^2) = y^2 \Rightarrow x = \pm\sqrt{\frac{y^2}{1 - y^2}}$$
$x$ is a real number only when $1 - y^2 > 0$, i.e. $-1 < y < 1$. So the range of $f$ is $(-1, 1)$.
(Indeed $|f(x)| = \dfrac{|x|}{\sqrt{1 + x^2}} < 1$ for all $x$; e.g. $y = 1 \in \mathbb{R}$ has no pre-image.)
Since range $= (-1, 1) \ne \mathbb{R}$ (co-domain), $f$ is **not onto**.

Hence $f$ is one-one but not onto.
