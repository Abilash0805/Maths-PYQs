@topic Transpose of a matrix
If $A = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix}$ satisfies $A' + A = I$, then the value of $\theta$ is :
(A) $\dfrac{\pi}{6}$
(B) $\dfrac{\pi}{3}$
(C) $\dfrac{2\pi}{3}$
(D) $\dfrac{5\pi}{6}$
--- ans B
$A' = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$, so
$$A' + A = \begin{bmatrix} 2\cos\theta & 0 \\ 0 & 2\cos\theta \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$
$\Rightarrow 2\cos\theta = 1 \Rightarrow \cos\theta = \dfrac{1}{2} \Rightarrow \theta = \dfrac{\pi}{3}$.

If $\displaystyle\int_0^4 \frac{1}{x + \sqrt{x}}\,dx = k\log 3$, then the value of $k$ is :
(A) $4$
(B) $-2$
(C) $-4$

@topic Equivalence relations
**Assertion (A):** Let R be a relation on set A of all books in a school library given by $R = \{(x, y) : x, y \in A,\ x \text{ and } y \text{ have the same number of pages}\}$ and S is a relation on set A from the same library such that $S = \{(p, q) : p \text{ and } q \text{ are Mathematics books}\}$. Also, $R \cap S \ne \phi$. Then, $R \cap S$ is an equivalence relation.
**Reason (R):** The intersection of two equivalence relations on a set is an equivalence relation on the set.
(A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A).
(B) Both Assertion (A) and Reason (R) are true, but Reason (R) is **not** the correct explanation of the Assertion (A).
(C) Assertion (A) is true, but Reason (R) is false.
(D) Assertion (A) is false, but Reason (R) is true.
--- ans D
R is an equivalence relation on A. But S is **not reflexive** on A: for a book $b$ that is not a Mathematics book, $(b, b) \notin S$. Hence $(b, b) \notin R \cap S$, so $R \cap S$ is not reflexive and is **not** an equivalence relation on A — Assertion is **false**.
Reason is **true**: if $R_1, R_2$ are equivalence relations on a set, then $R_1 \cap R_2$ is reflexive, symmetric and transitive.

=== 23 | rf | 2 | sub
@topic Equivalence relation
Students are trying to fix thumb pins on a graph sheet on the class notice board. A relation R is defined on the set A of thumb pins as
$$R = \{(P, Q) : P, Q \in A \text{ and distance between P and Q is less than 3 cm}\}$$
Determine if R is an equivalence relation.
--- ans
**Reflexive:** For any pin $P \in A$, distance between P and P is $0 < 3$ cm, so $(P, P) \in R$. R is reflexive.

**Symmetric:** If $(P, Q) \in R$, then $PQ < 3$ cm $\Rightarrow QP < 3$ cm $\Rightarrow (Q, P) \in R$. R is symmetric.

**Transitive:** Take three pins P, Q, S on a straight line with $PQ = 2$ cm and $QS = 2$ cm (Q between P and S). Then $(P, Q) \in R$ and $(Q, S) \in R$, but $PS = 4$ cm $> 3$ cm, so $(P, S) \notin R$. R is not transitive.

Hence **R is not an equivalence relation**.

@topic Bijective function
Determine whether the function $f : \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 2x^3 - 7$, $\forall\, x \in \mathbb{R}$ (Real numbers) is bijective or not.
--- ans
**One-one:** Let $x_1, x_2 \in \mathbb{R}$ with $f(x_1) = f(x_2)$.
$$2x_1^3 - 7 = 2x_2^3 - 7 \Rightarrow x_1^3 = x_2^3 \Rightarrow x_1 = x_2$$
(the cube function is one-one on $\mathbb{R}$). So $f$ is one-one.

**Onto:** Let $y \in \mathbb{R}$. Put $f(x) = y$: $2x^3 - 7 = y \Rightarrow x = \left(\dfrac{y + 7}{2}\right)^{1/3}$, which is a real number for every real $y$.
And $f\!\left(\left(\dfrac{y + 7}{2}\right)^{1/3}\right) = 2\cdot\dfrac{y + 7}{2} - 7 = y$. So every $y \in \mathbb{R}$ has a pre-image; $f$ is onto.

Hence $f$ is **bijective**.
