@topic Direction cosines and ratios
Direction ratios of lines $l_1$ and $l_2$ respectively are $\langle 1, 0, 0 \rangle$ and $\langle 0, -1, 0 \rangle$. The direction ratios of the line perpendicular to both $l_1$ and $l_2$ are :
(A) $\langle 1, 1, 0 \rangle$
(B) $\langle 0, 0, -1 \rangle$
(C) $\langle 1, 1, 1 \rangle$
(D) $\langle 1, 0, -1 \rangle$
--- ans B
A line perpendicular to both is parallel to $\vec{b}_1 \times \vec{b}_2$ with $\vec{b}_1 = \hat{i}$, $\vec{b}_2 = -\hat{j}$:
$$\hat{i} \times (-\hat{j}) = -\hat{k}$$
So the direction ratios are $\langle 0, 0, -1 \rangle$. (Check: $\langle 0, 0, -1 \rangle$ is perpendicular to both given directions; options (A), (C), (D) are not perpendicular to $\langle 1, 0, 0 \rangle$.)

@topic Domain and range
The domain of $\cos^{-1}(4x + 1)$ is :
(A) $[-1, 1]$
(B) $[-3, 5]$
(C) $[-4, 4]$
(D) $\left[-\dfrac{1}{2}, 0\right]$
--- ans D
The domain of $\cos^{-1}t$ is $[-1, 1]$, so
$$-1 \le 4x + 1 \le 1 \;\Rightarrow\; -2 \le 4x \le 0 \;\Rightarrow\; -\frac{1}{2} \le x \le 0$$
Domain $= \left[-\dfrac{1}{2}, 0\right]$.

@topic Operations on matrices
If a matrix X is such that $\begin{bmatrix} 2 & 1 \end{bmatrix}X = \begin{bmatrix} 3 & 4 & 5 \end{bmatrix}$, then the order of matrix X is :
(A) $3 \times 1$
(B) $2 \times 3$
(C) $1 \times 2$

--- ans B
$\begin{bmatrix} 2 & 1 \end{bmatrix}$ has order $1 \times 2$. For the product to be defined, X must have 2 rows; for the product to be $1 \times 3$, X must have 3 columns.

@topic Derivatives of inverse trigonometric functions
If $2\cos^{-1}x = y$, then $\dfrac{dy}{dx}$ is :
(A) $-2\sin^{-1}x$
(B) $-\dfrac{1}{2}\sin\dfrac{y}{2}$
(C) $\dfrac{-1}{\sqrt{1 - 2x^2}}$
(D) $-2\operatorname{cosec}\dfrac{y}{2}$
--- ans D
$2\cos^{-1}x = y \Rightarrow x = \cos\dfrac{y}{2} \Rightarrow \dfrac{dx}{dy} = -\dfrac{1}{2}\sin\dfrac{y}{2}$.
$$\therefore \frac{dy}{dx} = \frac{-2}{\sin\frac{y}{2}} = -2\operatorname{cosec}\frac{y}{2}$$
(Equivalently $\dfrac{dy}{dx} = \dfrac{-2}{\sqrt{1 - x^2}}$.)

@topic Parametric differentiation
If $x = e^{\sin^{-1}t}$ and $y = e^{\cos^{-1}t}$, then find $\dfrac{dy}{dx}$ at $t = \dfrac{1}{\sqrt{2}}$.
--- ans
$$\frac{dx}{dt} = e^{\sin^{-1}t}\cdot\frac{1}{\sqrt{1 - t^2}},\qquad \frac{dy}{dt} = e^{\cos^{-1}t}\cdot\frac{-1}{\sqrt{1 - t^2}}$$
$$\therefore\ \frac{dy}{dx} = \frac{dy/dt}{dx/dt} = -\frac{e^{\cos^{-1}t}}{e^{\sin^{-1}t}}$$
At $t = \dfrac{1}{\sqrt{2}}$: $\sin^{-1}t = \cos^{-1}t = \dfrac{\pi}{4}$, so
$$\left(\frac{dy}{dx}\right)_{t = \frac{1}{\sqrt{2}}} = -\frac{e^{\pi/4}}{e^{\pi/4}} = -1$$

=== 23 | aod | 2 | sub
@topic Increasing and decreasing functions
Find the sub-interval of $(0, \infty)$ in which $f(x) = x\log x$ is increasing.
--- ans
$$f'(x) = \log x + x\cdot\frac{1}{x} = 1 + \log x$$
$f'(x) = 0 \Rightarrow \log x = -1 \Rightarrow x = \dfrac{1}{e}$, which splits $(0, \infty)$ into $\left(0, \dfrac{1}{e}\right)$ and $\left(\dfrac{1}{e}, \infty\right)$.
For $0 < x < \dfrac{1}{e}$: $\log x < -1 \Rightarrow f'(x) < 0$ (decreasing).
For $x > \dfrac{1}{e}$: $\log x > -1 \Rightarrow f'(x) > 0$ (increasing).
$\therefore f$ is increasing in $\left(\dfrac{1}{e}, \infty\right)$ (or $\left[\dfrac{1}{e}, \infty\right)$).

=== 28 | int | 3 | sub
@topic Properties of definite integrals
Evaluate : $\displaystyle\int_0^{\pi/2} \frac{\sin^2 x}{1 + \sin 2x}\,dx$
--- ans
Let $I = \displaystyle\int_0^{\pi/2} \frac{\sin^2 x}{1 + \sin 2x}\,dx \quad\cdots(1)$
Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$, and $\sin 2\left(\frac{\pi}{2} - x\right) = \sin(\pi - 2x) = \sin 2x$:
$$I = \int_0^{\pi/2} \frac{\cos^2 x}{1 + \sin 2x}\,dx \quad\cdots(2)$$
Adding (1) and (2):
$$2I = \int_0^{\pi/2} \frac{dx}{1 + \sin 2x} = \int_0^{\pi/2} \frac{dx}{(\sin x + \cos x)^2} = \int_0^{\pi/2} \frac{\sec^2 x}{(1 + \tan x)^2}\,dx$$
Put $1 + \tan x = t \Rightarrow \sec^2 x\,dx = dt$; when $x = 0$, $t = 1$; as $x \to \dfrac{\pi}{2}$, $t \to \infty$:
$$2I = \int_1^{\infty} \frac{dt}{t^2} = \left[-\frac{1}{t}\right]_1^{\infty} = 0 - (-1) = 1$$
$$\therefore\ I = \frac{1}{2}$$

=== 30a | de | 3 | sub
@topic Homogeneous equations
Find the general solution of the differential equation $(x^2 - y^2)\,dx + 2xy\,dy = 0$.
--- ans
$$\frac{dy}{dx} = \frac{y^2 - x^2}{2xy}$$
which is homogeneous. Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v^2 - 1}{2v} \Rightarrow x\frac{dv}{dx} = \frac{v^2 - 1 - 2v^2}{2v} = -\frac{1 + v^2}{2v}$$
Separating the variables:
$$\int \frac{2v}{1 + v^2}\,dv = -\int \frac{dx}{x} \Rightarrow \log(1 + v^2) = -\log|x| + \log|C|$$
$$\Rightarrow x(1 + v^2) = C$$
Putting $v = \dfrac{y}{x}$: $x\left(1 + \dfrac{y^2}{x^2}\right) = C$, i.e. the general solution is
$$x^2 + y^2 = Cx$$

=== 30b | de | 3 | sub
@topic Variable separable
Solve the differential equation $\sin x\cos y\,dx + \cos x\sin y\,dy = 0$, given that $y = \dfrac{\pi}{4}$ when $x = 0$.
--- ans
Dividing by $\cos x\cos y$:
$$\tan x\,dx + \tan y\,dy = 0 \Rightarrow \int \tan y\,dy = -\int \tan x\,dx$$
$$\Rightarrow -\log|\cos y| = \log|\cos x| + \log|K| \Rightarrow \log|\cos x\cos y| = -\log|K|$$
$$\Rightarrow \cos x\cos y = C$$
Putting $x = 0$, $y = \dfrac{\pi}{4}$: $C = \cos 0\cos\dfrac{\pi}{4} = \dfrac{1}{\sqrt{2}}$.
$\therefore$ The particular solution is
$$\cos x\cos y = \frac{1}{\sqrt{2}} \quad\left(\text{or } \sqrt{2}\cos y = \sec x\right)$$

=== 33 | rf | 5 | sub
@topic One-one and onto functions
Show that a function $f : \mathbb{R}_+ \to A \subset \mathbb{N}$, defined as $f(x) = 4x^2 + 12x + 15$ is one-one. Find set A so that f is onto where $\mathbb{R}_+ = [0, \infty)$. Also, find if there exists $a \in \mathbb{R}_+$ such that $f(a) = 7$. Justify.
--- ans
**Note on the question:** as printed, $f$ is not a function into $\mathbb{N}$ — e.g. $f(0.1) = 0.04 + 1.2 + 15 = 16.24 \notin \mathbb{N}$. (The official marking scheme acknowledges this and awards full marks for attempting the question.) Below, the codomain is taken as $A \subset \mathbb{R}$.

**One-one:** Let $x_1, x_2 \in \mathbb{R}_+$ with $f(x_1) = f(x_2)$:
$$4(x_1^2 - x_2^2) + 12(x_1 - x_2) = 0 \Rightarrow 4(x_1 - x_2)(x_1 + x_2 + 3) = 0$$
Since $x_1, x_2 \ge 0$, $x_1 + x_2 + 3 > 0$; hence $x_1 = x_2$. So $f$ is **one-one**.

**Set A (range of f):** $f(x) = 4x^2 + 12x + 15 = (2x + 3)^2 + 6$.
For $x \ge 0$, $2x + 3 \ge 3$, so $f(x) \ge 9 + 6 = 15$, with $f(0) = 15$.
Conversely, for any $y \ge 15$, $x = \dfrac{\sqrt{y - 6} - 3}{2} \ge 0$ (since $\sqrt{y - 6} \ge 3$) and $f(x) = (\sqrt{y - 6})^2 + 6 = y$.
$\therefore$ Range of $f = [15, \infty)$, and $f$ is onto when $\boxed{A = [15, \infty)}$.

**f(a) = 7:** $7 < 15$, so $7 \notin$ range of $f$. Indeed,
$$4a^2 + 12a + 15 = 7 \Rightarrow a^2 + 3a + 2 = 0 \Rightarrow a = -1 \text{ or } a = -2$$
neither of which belongs to $\mathbb{R}_+$. Hence **no** $a \in \mathbb{R}_+$ exists with $f(a) = 7$.

@topic Graphical method – bounded region
Solve the following Linear Programming Problem graphically :
Maximize $Z = 8x + 8y$
subject to the constraints
$x - 20 \le 0$
$2x + 3y \le 120$
$2x + y \le 60$
$x \ge 0,\ y \ge 0$
--- ans
Draw the lines
$x = 20$ (parallel to the $y$-axis);
$2x + 3y = 120$ through $(60, 0)$ and $(0, 40)$;
$2x + y = 60$ through $(30, 0)$ and $(0, 60)$.
$(0, 0)$ satisfies all three inequalities, so the feasible region lies on the origin side of each line, in the first quadrant.
Intersection of $x = 20$ and $2x + y = 60$: $B(20, 20)$.
Intersection of $2x + y = 60$ and $2x + 3y = 120$: subtracting, $2y = 60 \Rightarrow y = 30,\ x = 15$, i.e. $C(15, 30)$.
