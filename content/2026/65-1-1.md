If $2\cos^{-1}x = y$, then
(A) $0 \le y \le \pi$
(B) $-\pi \le y \le \pi$

@topic Conditional probability
**Assertion (A):** In an experiment of throwing an unbiased die, the probability of getting a prime number given that number appearing on the die being odd is $\dfrac{2}{3}$.
**Reason (R):** For any two events A and B, $P(A|B) = \dfrac{P(A \cup B)}{P(B)}$
(A) Both Assertion (A) and Reason (R) are true and the Reason (R) is the correct explanation of the Assertion (A).
(B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A).
(C) Assertion (A) is true and Reason (R) is false.
(D) Assertion (A) is false and Reason (R) is true.
--- ans C
Odd numbers: $B = \{1, 3, 5\}$; primes among them: $A \cap B = \{3, 5\}$.
$P(A|B) = \dfrac{P(A \cap B)}{P(B)} = \dfrac{2/6}{3/6} = \dfrac{2}{3}$ — Assertion is **true**.
The correct formula is $P(A|B) = \dfrac{P(A \cap B)}{P(B)}$, not $\dfrac{P(A \cup B)}{P(B)}$ — Reason is **false**.

@topic Continuity at a point
Check whether function $f(x)$ defined as
$$f(x) = \begin{cases} \dfrac{|x - 3|}{2(x - 3)}, & x < 3 \\[2mm] \dfrac{x - 6}{6}, & x \ge 3 \end{cases}$$

@topic Derivative of implicit function
If $\sqrt{3}\,(x^2 + y^2) = 4xy$, then find $\dfrac{dy}{dx}$ at $\left(\dfrac{1}{2}, \dfrac{\sqrt{3}}{2}\right)$.
--- ans
Differentiating both sides w.r.t. $x$:
$$\sqrt{3}\left(2x + 2y\frac{dy}{dx}\right) = 4\left(y + x\frac{dy}{dx}\right)$$
$$\Rightarrow \frac{dy}{dx}\left(2\sqrt{3}\,y - 4x\right) = 4y - 2\sqrt{3}\,x \Rightarrow \frac{dy}{dx} = \frac{2y - \sqrt{3}\,x}{\sqrt{3}\,y - 2x}$$
At $\left(\dfrac{1}{2}, \dfrac{\sqrt{3}}{2}\right)$:
$$\frac{dy}{dx} = \frac{\sqrt{3} - \frac{\sqrt{3}}{2}}{\frac{3}{2} - 1} = \frac{\sqrt{3}/2}{1/2} = \sqrt{3}$$

@topic Homogeneous differential equation
Find the general solution of the following differential equation:
$$x^2\frac{dy}{dx} = x^2 + xy + y^2$$
--- ans
$\dfrac{dy}{dx} = 1 + \dfrac{y}{x} + \left(\dfrac{y}{x}\right)^2$ — a homogeneous equation.
Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = 1 + v + v^2 \Rightarrow x\frac{dv}{dx} = 1 + v^2 \Rightarrow \frac{dv}{1 + v^2} = \frac{dx}{x}$$
Integrating: $\tan^{-1}v = \log|x| + C$
$$\therefore\ \tan^{-1}\left(\frac{y}{x}\right) = \log|x| + C$$
is the general solution.

Find the particular solution of the differential equation $xy\dfrac{dy}{dx} = (x + 2)(y + 2)$, given that $y(1) = -1$.

@topic Equivalence relation
A relation R is defined on Z, the set of integers, as
$$R = \{(x, y) : |x - y| \text{ is divisible by a prime number } p,\ x, y \in \mathbb{Z}\}$$
check whether R is an equivalence relation or not.
--- ans
**Reflexive:** For every $x \in \mathbb{Z}$, $|x - x| = 0 = 0 \cdot p$, which is divisible by $p$. So $(x, x) \in R$; R is reflexive.

**Symmetric:** Let $(x, y) \in R$. Then $|x - y|$ is divisible by $p$. Since $|y - x| = |x - y|$, $|y - x|$ is also divisible by $p$, so $(y, x) \in R$; R is symmetric.

**Transitive:** Let $(x, y) \in R$ and $(y, z) \in R$. Then $x - y = pk_1$ and $y - z = pk_2$ for some $k_1, k_2 \in \mathbb{Z}$.
Adding, $x - z = p(k_1 + k_2)$, so $|x - z| = p\,|k_1 + k_2|$ is divisible by $p$. Hence $(x, z) \in R$; R is transitive.

Since R is reflexive, symmetric and transitive, **R is an equivalence relation**.
