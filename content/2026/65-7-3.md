@topic Principal values
The value of $\left[\tan^{-1}(-1) + \cos^{-1}\left(-\dfrac{1}{2}\right) + \sin^{-1}\left(\dfrac{1}{2}\right)\right]$ is :
(A) $\dfrac{7\pi}{12}$
(B) $\dfrac{5\pi}{12}$
(C) $-\dfrac{5\pi}{12}$
(D) $\dfrac{\pi}{3}$
--- ans A
Using the principal value branches:
$\tan^{-1}(-1) = -\dfrac{\pi}{4}$, $\quad\cos^{-1}\left(-\dfrac{1}{2}\right) = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}$, $\quad\sin^{-1}\left(\dfrac{1}{2}\right) = \dfrac{\pi}{6}$.
$$-\frac{\pi}{4} + \frac{2\pi}{3} + \frac{\pi}{6} = \frac{-3\pi + 8\pi + 2\pi}{12} = \frac{7\pi}{12}$$

@topic Rate of change
The motion of a particle is described as $S = 2t^3 - 6t^2 + 8$. Its velocity $\dfrac{dS}{dt}$, when the acceleration $\dfrac{d^2S}{dt^2}$ vanishes is :
(A) $-6$ unit/sec
(B) $0$ unit/sec
(C) $18$ unit/sec
(D) $6$ unit/sec
--- ans A
$v = \dfrac{dS}{dt} = 6t^2 - 12t$, $\quad a = \dfrac{d^2S}{dt^2} = 12t - 12$.
$a = 0 \Rightarrow t = 1$, so $v = 6(1) - 12(1) = -6$ unit/sec.

@topic Integration by parts
$\displaystyle\int e^x\left(\frac{2 + \sin 2x}{1 + \cos 2x}\right)dx$ is equal to :
(A) $\log\cos 2x + C$
(B) $\sec^2 2x + C$
(C) $e^x\tan x + C$
(D) $e^x\cot x + C$
--- ans C
$$\frac{2 + \sin 2x}{1 + \cos 2x} = \frac{2 + 2\sin x\cos x}{2\cos^2 x} = \sec^2 x + \tan x$$
So the integral is $\displaystyle\int e^x\left(\tan x + \sec^2 x\right)dx$, of the form $\displaystyle\int e^x\left[f(x) + f'(x)\right]dx = e^x f(x) + C$ with $f(x) = \tan x$.
$\therefore$ the integral $= e^x\tan x + C$.

@topic Chain rule and implicit differentiation
Differential of $\log\sin x$ with respect to $\sqrt{\cos x}$ is :
(A) $-2\sqrt{\cos x}\cdot\cot x\cdot\operatorname{cosec}x$
(B) $\sqrt{\cos x}\cdot\cot x\cdot\operatorname{cosec}x$
(C) $\dfrac{2\sqrt{\cos x}}{\sin x}$
(D) $\dfrac{1}{\sin x\sqrt{\cos x}}$
--- ans A
Let $u = \log\sin x$, $v = \sqrt{\cos x}$. Then $\dfrac{du}{dx} = \cot x$ and $\dfrac{dv}{dx} = \dfrac{-\sin x}{2\sqrt{\cos x}}$.
$$\frac{du}{dv} = \frac{du/dx}{dv/dx} = \cot x\cdot\frac{-2\sqrt{\cos x}}{\sin x} = -2\sqrt{\cos x}\cdot\cot x\cdot\operatorname{cosec}x$$

@topic Conditional probability
If $P(A) = 0{\cdot}3$, $P(B) = 0{\cdot}7$ and $P(B/A) = 0{\cdot}5$, then $P(A \cup B)$ is :
(A) $0{\cdot}35$
(B) $0{\cdot}85$
(C) $0{\cdot}5$
(D) $0{\cdot}21$
--- ans B
$P(A \cap B) = P(A)\,P(B/A) = 0.3 \times 0.5 = 0.15$.
$P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.3 + 0.7 - 0.15 = 0.85$.

=== 21 | mat | 2 | sub
@topic Operations on matrices
Find the value of $x$ if $A = B$, where
$$A = \begin{bmatrix} 6 & 3x \\ 8 & -6 \end{bmatrix} \text{ and } B = \begin{bmatrix} 6 & x^2 + 2 \\ 8 & x^2 - 5x \end{bmatrix}.$$
--- ans
Equal matrices have equal corresponding elements:
$3x = x^2 + 2 \Rightarrow x^2 - 3x + 2 = 0 \Rightarrow (x - 1)(x - 2) = 0 \Rightarrow x = 1$ or $2$ $\quad\cdots(1)$
$-6 = x^2 - 5x \Rightarrow x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0 \Rightarrow x = 2$ or $3$ $\quad\cdots(2)$
Both conditions must hold, so $x$ is the common value of (1) and (2):
$\therefore$ **$x = 2$**.

@topic Feasible region and corner points
For the following Linear Programming Problem, shade the feasible region on the graph and find the coordinates of its corner points :
Minimize $Z = 18x + 10y$
subject to constraints
$4x + y \ge 20$
$2x + 3y \ge 30$
$x, y \ge 0.$
--- ans
Draw the lines $4x + y = 20$ (through $(5, 0)$, $(0, 20)$) and $2x + 3y = 30$ (through $(15, 0)$, $(0, 10)$).
$(0, 0)$ satisfies neither inequality, so the feasible region lies on the side of each line away from the origin, in the first quadrant.
Intersection: $y = 20 - 4x$ in $2x + 3y = 30$ gives $2x + 60 - 12x = 30 \Rightarrow x = 3$, $y = 8$, i.e. $(3, 8)$.

@topic Chain rule and implicit differentiation
If $y = \sqrt{\log\left\{\sin\left(\dfrac{x^2}{3} + 1\right)\right\}}$, then show that $\dfrac{dy}{dx} = \dfrac{x\cot\left(\dfrac{x^2}{3} + 1\right)}{3y}$.
--- ans
Squaring: $y^2 = \log\left\{\sin\left(\dfrac{x^2}{3} + 1\right)\right\}$.
Differentiating both sides w.r.t. $x$ (chain rule):
$$2y\frac{dy}{dx} = \frac{1}{\sin\left(\frac{x^2}{3} + 1\right)}\cdot\cos\left(\frac{x^2}{3} + 1\right)\cdot\frac{2x}{3} = \frac{2x}{3}\cot\left(\frac{x^2}{3} + 1\right)$$
$$\therefore\ \frac{dy}{dx} = \frac{x\cot\left(\frac{x^2}{3} + 1\right)}{3y}$$
Hence shown.

=== 28 | aod | 3 | sub
@topic Absolute maxima and minima
Find the product of the maximum and minimum values of the function $f(x) = \cos x - \dfrac{1}{2}\cos 2x$, $x \in \left[0, \dfrac{\pi}{2}\right]$.
--- ans
$$f'(x) = -\sin x + \sin 2x = -\sin x + 2\sin x\cos x = \sin x\,(2\cos x - 1)$$
$f'(x) = 0 \Rightarrow \sin x = 0$ or $\cos x = \dfrac{1}{2} \Rightarrow x = 0$ or $x = \dfrac{\pi}{3}$ (in $\left[0, \frac{\pi}{2}\right]$).
Values at the critical points and end points:
$f(0) = 1 - \dfrac{1}{2} = \dfrac{1}{2}$, $\quad f\left(\dfrac{\pi}{3}\right) = \dfrac{1}{2} - \dfrac{1}{2}\left(-\dfrac{1}{2}\right) = \dfrac{3}{4}$, $\quad f\left(\dfrac{\pi}{2}\right) = 0 - \dfrac{1}{2}(-1) = \dfrac{1}{2}$.
Absolute maximum $= \dfrac{3}{4}$ (at $x = \frac{\pi}{3}$), absolute minimum $= \dfrac{1}{2}$ (at $x = 0$ and $x = \frac{\pi}{2}$).
$$\text{Product} = \frac{3}{4}\times\frac{1}{2} = \boxed{\dfrac{3}{8}}$$

@topic Properties of definite integrals
Evaluate :
$$I = \int_{-\pi}^{\pi} \frac{2x(1 + \sin x)}{1 + \cos^2 x}\,dx$$
--- ans
$$I = \int_{-\pi}^{\pi} \frac{2x}{1 + \cos^2 x}\,dx + \int_{-\pi}^{\pi} \frac{2x\sin x}{1 + \cos^2 x}\,dx$$
$\dfrac{2x}{1 + \cos^2 x}$ is an odd function and $\dfrac{2x\sin x}{1 + \cos^2 x}$ is an even function, so
$$I = 0 + 2\int_0^{\pi} \frac{2x\sin x}{1 + \cos^2 x}\,dx = 4\int_0^{\pi} \frac{x\sin x}{1 + \cos^2 x}\,dx = 4J$$
where $J = \displaystyle\int_0^{\pi} \frac{x\sin x}{1 + \cos^2 x}\,dx \quad\cdots(1)$
Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$ (with $\sin(\pi - x) = \sin x$, $\cos(\pi - x) = -\cos x$):
$$J = \int_0^{\pi} \frac{(\pi - x)\sin x}{1 + \cos^2 x}\,dx \quad\cdots(2)$$
Adding (1) and (2):
$$2J = \pi\int_0^{\pi} \frac{\sin x}{1 + \cos^2 x}\,dx$$
Put $\cos x = t$, $-\sin x\,dx = dt$; $x = 0 \Rightarrow t = 1$, $x = \pi \Rightarrow t = -1$:
$$2J = \pi\int_1^{-1} \frac{-dt}{1 + t^2} = \pi\int_{-1}^{1} \frac{dt}{1 + t^2} = \pi\Big[\tan^{-1}t\Big]_{-1}^{1} = \pi\left(\frac{\pi}{4} + \frac{\pi}{4}\right) = \frac{\pi^2}{2}$$
$\Rightarrow J = \dfrac{\pi^2}{4}$.
$$\therefore\ \boxed{I = 4J = \pi^2}$$

=== 34 | de | 5 | sub
@topic Linear differential equations
Solve the differential equation $y + \dfrac{d}{dx}(xy) = x(\sin x + \log x)$.
--- ans
$$y + x\frac{dy}{dx} + y = x(\sin x + \log x) \Rightarrow \frac{dy}{dx} + \frac{2}{x}\,y = \sin x + \log x$$
This is linear in $y$ with $P = \dfrac{2}{x}$, $Q = \sin x + \log x$.
$$\text{I.F.} = e^{\int \frac{2}{x}dx} = e^{2\log x} = x^2$$
Solution: $y\cdot x^2 = \displaystyle\int x^2(\sin x + \log x)\,dx = \int x^2\sin x\,dx + \int x^2\log x\,dx$.
By parts:
$$\int x^2\sin x\,dx = -x^2\cos x + \int 2x\cos x\,dx = -x^2\cos x + 2x\sin x + 2\cos x$$
$$\int x^2\log x\,dx = \frac{x^3}{3}\log x - \int\frac{1}{x}\cdot\frac{x^3}{3}\,dx = \frac{x^3}{3}\log x - \frac{x^3}{9}$$
$$\therefore\ \boxed{x^2y = -x^2\cos x + 2x\sin x + 2\cos x + \frac{x^3}{3}\log x - \frac{x^3}{9} + C}$$
i.e. $y = -\cos x + \dfrac{2\sin x}{x} + \dfrac{2\cos x}{x^2} + \dfrac{x}{3}\log x - \dfrac{x}{9} + \dfrac{C}{x^2}$.
