@topic Principal values
The value of $\cos^{-1}\left[\cos\dfrac{7\pi}{6}\right]$ is :
(A) $\dfrac{7\pi}{6}$
(B) $\dfrac{5\pi}{6}$
(C) $\dfrac{\pi}{3}$
(D) $\dfrac{\pi}{6}$
--- ans B
$\dfrac{7\pi}{6} \notin [0, \pi]$ (principal branch of $\cos^{-1}$), so write $\cos\dfrac{7\pi}{6} = \cos\left(2\pi - \dfrac{7\pi}{6}\right) = \cos\dfrac{5\pi}{6}$.
Since $\dfrac{5\pi}{6} \in [0, \pi]$: $\cos^{-1}\left(\cos\dfrac{7\pi}{6}\right) = \dfrac{5\pi}{6}$.

@topic Rate of change
If the rate of change of the area of a circle is equal to the rate of change of its diameter, then its radius is :
(A) $2\pi$ units
(B) $\pi$ units
(C) $\dfrac{\pi}{2}$ units
(D) $\dfrac{1}{\pi}$ units
--- ans D
Area $A = \pi r^2 \Rightarrow \dfrac{dA}{dt} = 2\pi r\dfrac{dr}{dt}$; diameter $D = 2r \Rightarrow \dfrac{dD}{dt} = 2\dfrac{dr}{dt}$.
Given $\dfrac{dA}{dt} = \dfrac{dD}{dt}$: $2\pi r\dfrac{dr}{dt} = 2\dfrac{dr}{dt} \Rightarrow r = \dfrac{1}{\pi}$ units.

@topic Integration by parts
$\displaystyle\int\left[\sin(\log x) + \cos(\log x)\right]dx$ is equal to :
(A) $-\cos(\log x) + C$
(B) $\dfrac{1}{\cos x} + \dfrac{1}{\sin x} + C$
(C) $\sin(\log x) + C$
(D) $x\sin(\log x) + C$
--- ans D
$$\frac{d}{dx}\big[x\sin(\log x)\big] = \sin(\log x) + x\cos(\log x)\cdot\frac{1}{x} = \sin(\log x) + \cos(\log x)$$
$\therefore$ the integral $= x\sin(\log x) + C$. (Equivalently, by parts: $\int\sin(\log x)\,dx = x\sin(\log x) - \int\cos(\log x)\,dx$.)

@topic Chain rule and implicit differentiation
If $y = \sqrt{y + \cos x}$, then $\dfrac{dy}{dx}$ is equal to :
(A) $\dfrac{1}{2\sqrt{y + \cos x}}$
(B) $\dfrac{\cos x}{2y - 1}$
(C) $\dfrac{-\sin x}{2\sqrt{y + \cos x}}$
(D) $\dfrac{\sin x}{1 - 2y}$
--- ans D
Squaring: $y^2 = y + \cos x$. Differentiating w.r.t. $x$:
$2y\dfrac{dy}{dx} = \dfrac{dy}{dx} - \sin x \Rightarrow (2y - 1)\dfrac{dy}{dx} = -\sin x \Rightarrow \dfrac{dy}{dx} = \dfrac{\sin x}{1 - 2y}$.

@topic Conditional probability
For events A and B, if $P(B) = \dfrac{3}{5}$, $P(A/B) = \dfrac{1}{2}$ and $P(A \cup B) = \dfrac{4}{5}$, then $P(A)$ is :
(A) $\dfrac{1}{2}$
(B) $\dfrac{3}{5}$
(C) $\dfrac{1}{5}$
(D) $\dfrac{3}{10}$
--- ans A
$P(A \cap B) = P(A/B)\,P(B) = \dfrac{1}{2}\cdot\dfrac{3}{5} = \dfrac{3}{10}$.
$P(A \cup B) = P(A) + P(B) - P(A \cap B) \Rightarrow \dfrac{4}{5} = P(A) + \dfrac{3}{5} - \dfrac{3}{10} \Rightarrow P(A) = \dfrac{8 - 6 + 3}{10} = \dfrac{1}{2}$.

@topic Operations on matrices
Solve the given matrix equation for $x$, given $x > 0$ :
$$x\begin{bmatrix} 2x & 2 \\ 3 & x \end{bmatrix} + 2\begin{bmatrix} 8 & 5x \\ 4 & 0 \end{bmatrix} = 2\begin{bmatrix} x^2 + 8 & 24 \\ 10 & 8 \end{bmatrix}$$
--- ans
$$\begin{bmatrix} 2x^2 & 2x \\ 3x & x^2 \end{bmatrix} + \begin{bmatrix} 16 & 10x \\ 8 & 0 \end{bmatrix} = \begin{bmatrix} 2x^2 + 16 & 48 \\ 20 & 16 \end{bmatrix} \Rightarrow \begin{bmatrix} 2x^2 + 16 & 12x \\ 3x + 8 & x^2 \end{bmatrix} = \begin{bmatrix} 2x^2 + 16 & 48 \\ 20 & 16 \end{bmatrix}$$
Equating corresponding elements:
$12x = 48 \Rightarrow x = 4$; $\quad 3x + 8 = 20 \Rightarrow x = 4$; $\quad x^2 = 16 \Rightarrow x = 4$ (as $x > 0$); the $(1, 1)$ entries agree for every $x$.
$\therefore$ **$x = 4$**.

Minimize $Z = 5x + 7y$
subject to constraints
$2x + y \ge 8$
$x + 2y \ge 10$
$x, y \ge 0.$
--- ans
Draw the lines $2x + y = 8$ (through $(4, 0)$, $(0, 8)$) and $x + 2y = 10$ (through $(10, 0)$, $(0, 5)$).

@topic Chain rule and implicit differentiation
If $y = \left\{x + \sqrt{x^2 - a^2}\right\}^n$, then prove that $\dfrac{dy}{dx} = \dfrac{ny}{\sqrt{x^2 - a^2}}$.
--- ans
Differentiating w.r.t. $x$ using the chain rule:
$$\frac{dy}{dx} = n\left\{x + \sqrt{x^2 - a^2}\right\}^{n - 1}\cdot\frac{d}{dx}\left(x + \sqrt{x^2 - a^2}\right) = n\left\{x + \sqrt{x^2 - a^2}\right\}^{n - 1}\left(1 + \frac{2x}{2\sqrt{x^2 - a^2}}\right)$$
$$= n\left\{x + \sqrt{x^2 - a^2}\right\}^{n - 1}\cdot\frac{\sqrt{x^2 - a^2} + x}{\sqrt{x^2 - a^2}} = \frac{n\left\{x + \sqrt{x^2 - a^2}\right\}^{n}}{\sqrt{x^2 - a^2}}$$
$$\therefore\ \frac{dy}{dx} = \frac{ny}{\sqrt{x^2 - a^2}}$$
Hence proved.

=== 28 | aod | 3 | sub
@topic Absolute maxima and minima
Find the sum of maximum and minimum values of $f(x) = \sin x\,(1 + \cos x)$ in the interval $[0, \pi]$.
--- ans
$f(x) = \sin x + \sin x\cos x = \sin x + \dfrac{1}{2}\sin 2x$
$$f'(x) = \cos x + \cos 2x = 2\cos^2 x + \cos x - 1 = (2\cos x - 1)(\cos x + 1)$$
$f'(x) = 0 \Rightarrow \cos x = \dfrac{1}{2}$ or $\cos x = -1 \Rightarrow x = \dfrac{\pi}{3}$ or $x = \pi$ (in $[0, \pi]$).
Values at the critical points and end points:
$f(0) = 0$, $\quad f\left(\dfrac{\pi}{3}\right) = \dfrac{\sqrt{3}}{2}\left(1 + \dfrac{1}{2}\right) = \dfrac{3\sqrt{3}}{4}$, $\quad f(\pi) = 0$.
Absolute maximum $= \dfrac{3\sqrt{3}}{4}$ (at $x = \frac{\pi}{3}$), absolute minimum $= 0$ (at $x = 0$ and $x = \pi$).
$$\text{Sum} = \frac{3\sqrt{3}}{4} + 0 = \boxed{\dfrac{3\sqrt{3}}{4}}$$

@topic Properties of definite integrals
Evaluate :
$$\int_0^{\pi/2} \frac{\sin^2 x}{1 + \sin x\cos x}\,dx$$
--- ans
Let $I = \displaystyle\int_0^{\pi/2} \frac{\sin^2 x}{1 + \sin x\cos x}\,dx \quad\cdots(1)$
Using $\displaystyle\int_0^a f(x)\,dx = \int_0^a f(a - x)\,dx$ (with $\sin\left(\frac{\pi}{2} - x\right) = \cos x$, $\cos\left(\frac{\pi}{2} - x\right) = \sin x$):
$$I = \int_0^{\pi/2} \frac{\cos^2 x}{1 + \cos x\sin x}\,dx \quad\cdots(2)$$
Adding (1) and (2):
$$2I = \int_0^{\pi/2} \frac{\sin^2 x + \cos^2 x}{1 + \sin x\cos x}\,dx = \int_0^{\pi/2} \frac{dx}{1 + \sin x\cos x}$$
Dividing numerator and denominator by $\cos^2 x$:
$$2I = \int_0^{\pi/2} \frac{\sec^2 x}{\sec^2 x + \tan x}\,dx = \int_0^{\pi/2} \frac{\sec^2 x}{1 + \tan x + \tan^2 x}\,dx$$
Put $\tan x = t$, $\sec^2 x\,dx = dt$; $x = 0 \Rightarrow t = 0$, $x \to \dfrac{\pi}{2} \Rightarrow t \to \infty$.
$$2I = \int_0^{\infty} \frac{dt}{t^2 + t + 1} = \int_0^{\infty} \frac{dt}{\left(t + \frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = \frac{2}{\sqrt{3}}\left[\tan^{-1}\frac{2t + 1}{\sqrt{3}}\right]_0^{\infty}$$
$$= \frac{2}{\sqrt{3}}\left(\frac{\pi}{2} - \frac{\pi}{6}\right) = \frac{2}{\sqrt{3}}\cdot\frac{\pi}{3} = \frac{2\pi}{3\sqrt{3}}$$
$$\therefore\ \boxed{I = \dfrac{\pi}{3\sqrt{3}}}$$

=== 34 | de | 5 | sub
@topic Homogeneous equations
Solve the differential equation $(x + y)\,dy + (x - y)\,dx = 0$, given that $y(1) = 1$.
--- ans
$$\frac{dy}{dx} = -\frac{x - y}{x + y} = \frac{y - x}{x + y}$$
The right side is homogeneous of degree 0. Put $y = vx$, $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v - 1}{v + 1} \Rightarrow x\frac{dv}{dx} = \frac{v - 1 - v^2 - v}{v + 1} = -\frac{1 + v^2}{v + 1}$$
Separating the variables:
$$\int \frac{v + 1}{1 + v^2}\,dv = -\int \frac{dx}{x} \Rightarrow \int\frac{v}{1 + v^2}\,dv + \int\frac{dv}{1 + v^2} = -\log|x| + C$$
$$\frac{1}{2}\log(1 + v^2) + \tan^{-1}v = -\log|x| + C$$
Substituting $v = \dfrac{y}{x}$: $\dfrac{1}{2}\log\dfrac{x^2 + y^2}{x^2} + \tan^{-1}\dfrac{y}{x} = -\log|x| + C$
$$\Rightarrow \frac{1}{2}\log(x^2 + y^2) + \tan^{-1}\frac{y}{x} = C$$
Using $y(1) = 1$: $\dfrac{1}{2}\log 2 + \tan^{-1}1 = C \Rightarrow C = \dfrac{1}{2}\log 2 + \dfrac{\pi}{4}$.
Required particular solution:
$$\boxed{\log(x^2 + y^2) + 2\tan^{-1}\frac{y}{x} = \log 2 + \frac{\pi}{2}}$$
