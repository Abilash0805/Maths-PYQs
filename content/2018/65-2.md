@topic Conditional probability
A black and a red die are rolled together. Find the conditional probability of obtaining the sum 8, given that the red die resulted in a number less than 4.
--- ans
Sample space has 36 equally likely outcomes (black, red).
Let $E$: sum is 8, $F$: red die shows a number less than 4.
$F$ has $6 \times 3 = 18$ outcomes, so $P(F) = \dfrac{18}{36}$.
$E \cap F = \{(6, 2), (5, 3)\}$, so $P(E \cap F) = \dfrac{2}{36}$.
$$P(E|F) = \frac{P(E \cap F)}{P(F)} = \frac{2/36}{18/36} = \frac{1}{9}$$

@topic Second order derivatives
If $y = \sin(\sin x)$, prove that $\dfrac{d^2y}{dx^2} + \tan x\dfrac{dy}{dx} + y\cos^2 x = 0$.
--- ans
$$\frac{dy}{dx} = \cos(\sin x)\cdot\cos x$$
Differentiating again (product rule):
$$\frac{d^2y}{dx^2} = -\sin(\sin x)\cos x\cdot\cos x - \cos(\sin x)\sin x = -y\cos^2 x - \cos(\sin x)\sin x$$
Also $\tan x\dfrac{dy}{dx} = \dfrac{\sin x}{\cos x}\cdot\cos(\sin x)\cos x = \cos(\sin x)\sin x$.
$$\therefore\ \frac{d^2y}{dx^2} + \tan x\frac{dy}{dx} + y\cos^2 x = -y\cos^2 x - \cos(\sin x)\sin x + \cos(\sin x)\sin x + y\cos^2 x = 0$$
Hence proved.

@topic Partial fractions
Find:
$$\int \frac{2\cos x}{(1 - \sin x)(1 + \sin^2 x)}\,dx$$
--- ans
Put $\sin x = t \Rightarrow \cos x\,dx = dt$:
$$I = \int \frac{2\,dt}{(1 - t)(1 + t^2)}$$

@topic Total probability and Bayes' theorem
Suppose a girl throws a die. If she gets 1 or 2, she tosses a coin three times and notes the number of tails. If she gets 3, 4, 5 or 6, she tosses a coin once and notes whether a 'head' or 'tail' is obtained. If she obtained exactly one 'tail', what is the probability that she threw 3, 4, 5 or 6 with the die?
--- ans
Let $E_1$: she gets 1 or 2, $E_2$: she gets 3, 4, 5 or 6, $A$: she obtains exactly one tail.
$$P(E_1) = \frac{2}{6} = \frac{1}{3},\quad P(E_2) = \frac{4}{6} = \frac{2}{3}$$
Three tosses — exactly one tail in $\{HHT, HTH, THH\}$: $P(A|E_1) = \dfrac{3}{8}$; one toss: $P(A|E_2) = \dfrac{1}{2}$.
By Bayes' theorem:
$$P(E_2|A) = \frac{P(E_2)P(A|E_2)}{P(E_1)P(A|E_1) + P(E_2)P(A|E_2)} = \frac{\frac{2}{3}\cdot\frac{1}{2}}{\frac{1}{3}\cdot\frac{3}{8} + \frac{2}{3}\cdot\frac{1}{2}} = \frac{\frac{1}{3}}{\frac{1}{8} + \frac{1}{3}} = \frac{\frac{1}{3}}{\frac{11}{24}} = \frac{8}{11}$$

@topic Optimisation problems
An open tank with a square base and vertical sides is to be constructed from a metal sheet so as to hold a given quantity of water. Show that the cost of material will be least when depth of the tank is half of its width. If the cost is to be borne by nearby settled lower income families, for whom water will be provided, what kind of value is hidden in this question?
--- ans
Let the side of the square base be $x$ and the depth be $h$. The volume $V = x^2h$ is fixed, so $h = \dfrac{V}{x^2}$.
The cost of material is least when the surface area of the open tank is least:
$$S = x^2 + 4xh = x^2 + \frac{4V}{x}$$
$$\frac{dS}{dx} = 2x - \frac{4V}{x^2} = 0 \Rightarrow x^3 = 2V = 2x^2h \Rightarrow h = \frac{x}{2}$$
$$\frac{d^2S}{dx^2} = 2 + \frac{8V}{x^3} > 0$$

If $(x^2 + y^2)^2 = xy$, find $\dfrac{dy}{dx}$.
--- ans

@topic Equivalence relations and classes
Let $A = \{x \in \mathbb{Z} : 0 \le x \le 12\}$. Show that
$R = \{(a, b) : a, b \in A,\ |a - b| \text{ is divisible by } 4\}$ is an equivalence relation. Find the set of all elements related to 1. Also write the equivalence class $[2]$.
--- ans
$A = \{0, 1, 2, \dots, 12\}$.

**Reflexive:** For any $a \in A$, $|a - a| = 0$, which is divisible by 4. So $(a, a) \in R$; R is reflexive.

**Symmetric:** Let $(a, b) \in R$. Then $|a - b|$ is divisible by 4. Since $|b - a| = |a - b|$, $|b - a|$ is divisible by 4, so $(b, a) \in R$; R is symmetric.

**Transitive:** Let $(a, b) \in R$ and $(b, c) \in R$. Then $a - b = 4k_1$ and $b - c = 4k_2$ for some $k_1, k_2 \in \mathbb{Z}$.
Adding, $a - c = 4(k_1 + k_2)$, so $|a - c|$ is divisible by 4 and $(a, c) \in R$; R is transitive.

Hence R is an **equivalence relation**.

Elements related to 1: $b \in A$ with $|b - 1|$ divisible by 4, i.e. $b = 1, 5, 9$.
$$\{b \in A : (1, b) \in R\} = \{1, 5, 9\}$$
Equivalence class of 2: $[2] = \{2, 6, 10\}$.
