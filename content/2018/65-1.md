=== 24a | rf | 6 | sub
@topic Equivalence relations and classes
Let $A = \{x \in \mathbb{Z} : 0 < x < 12\}$. Show that $R = \{(a, b) : a, b \in A,\ |a - b| \text{ is divisible by } 4\}$ is an equivalence relation. Find the set of all elements related to 1. Also write the equivalence class.
--- ans
$A = \{1, 2, 3, \dots, 11\}$.

**Reflexive:** For any $a \in A$, $|a - a| = 0$, which is divisible by 4. So $(a, a) \in R$ for all $a \in A$; R is reflexive.

**Symmetric:** Let $(a, b) \in R$. Then $|a - b|$ is divisible by 4. Since $|b - a| = |a - b|$, $|b - a|$ is also divisible by 4, so $(b, a) \in R$; R is symmetric.

**Transitive:** Let $(a, b) \in R$ and $(b, c) \in R$. Then $a - b = 4m$ and $b - c = 4n$ for some $m, n \in \mathbb{Z}$.
Adding, $a - c = 4(m + n)$, so $|a - c|$ is divisible by 4, i.e. $(a, c) \in R$; R is transitive.

Hence R is an **equivalence relation**.

Elements related to 1: $b \in A$ with $|b - 1|$ divisible by 4, i.e. $b = 1, 5, 9$.
$$\{b \in A : (1, b) \in R\} = \{1, 5, 9\}$$
(The reproduction does not name the class asked for; the paper asks for $[2]$.) Equivalence class of 2: $[2] = \{2, 6, 10\}$.
