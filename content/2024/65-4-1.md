@topic Simplification
Express $\tan^{-1}\left(\dfrac{\cos x}{1 - \sin x}\right)$, Where $\dfrac{-\pi}{2} < x < \dfrac{\pi}{2}$ in the simplest form.
--- ans
Using $\cos x = \cos^2\frac{x}{2} - \sin^2\frac{x}{2}$ and $1 - \sin x = \left(\cos\frac{x}{2} - \sin\frac{x}{2}\right)^2$:
$$\frac{\cos x}{1 - \sin x} = \frac{\left(\cos\frac{x}{2} - \sin\frac{x}{2}\right)\left(\cos\frac{x}{2} + \sin\frac{x}{2}\right)}{\left(\cos\frac{x}{2} - \sin\frac{x}{2}\right)^2} = \frac{\cos\frac{x}{2} + \sin\frac{x}{2}}{\cos\frac{x}{2} - \sin\frac{x}{2}} = \frac{1 + \tan\frac{x}{2}}{1 - \tan\frac{x}{2}} = \tan\left(\frac{\pi}{4} + \frac{x}{2}\right)$$
Since $-\dfrac{\pi}{2} < x < \dfrac{\pi}{2}$, $0 < \dfrac{\pi}{4} + \dfrac{x}{2} < \dfrac{\pi}{2}$, which lies in the principal range of $\tan^{-1}$. Hence
$$\tan^{-1}\left(\frac{\cos x}{1 - \sin x}\right) = \frac{\pi}{4} + \frac{x}{2}$$

A card from a well shuffled deck of 52 playing cards is lost. From the remaining cards of the pack, a card is drawn at random and is found to be a king. Find the probability of the lost card being a king.
--- ans
Let $E_1$: the lost card is a king; $E_2$: the lost card is not a king; $A$: the card drawn is a king.
$P(E_1) = \dfrac{4}{52}$, $P(E_2) = \dfrac{48}{52}$; $\ P(A|E_1) = \dfrac{3}{51}$, $P(A|E_2) = \dfrac{4}{51}$.
By Bayes' theorem,
$$P(E_1|A) = \frac{\frac{4}{52}\cdot\frac{3}{51}}{\frac{4}{52}\cdot\frac{3}{51} + \frac{48}{52}\cdot\frac{4}{51}} = \frac{12}{12 + 192} = \frac{12}{204} = \frac{1}{17}$$

A biased die is twice as likely to show an even number as an odd number. If such a die is thrown twice, find the probability distribution of the number of sixes. Also, find the mean of the distribution.
--- ans
Let each odd number have probability $p$; then each even number has probability $2p$: $3p + 3(2p) = 1 \Rightarrow p = \dfrac{1}{9}$.

|---|---|---|---|

@topic One-one and onto functions
Let $A = \mathbb{R} - \{5\}$ and $B = \mathbb{R} - \{1\}$. Consider the function $f : A \to B$, defined by $f(x) = \dfrac{x - 3}{x - 5}$. Show that $f$ is one-one and onto.
--- ans
**One-one:** Let $x_1, x_2 \in A$ with $f(x_1) = f(x_2)$:
$$\frac{x_1 - 3}{x_1 - 5} = \frac{x_2 - 3}{x_2 - 5} \Rightarrow (x_1 - 3)(x_2 - 5) = (x_2 - 3)(x_1 - 5)$$
$$\Rightarrow x_1x_2 - 5x_1 - 3x_2 + 15 = x_1x_2 - 5x_2 - 3x_1 + 15 \Rightarrow -2x_1 = -2x_2 \Rightarrow x_1 = x_2$$
So $f$ is one-one.
**Onto:** Let $y \in B$ (so $y \ne 1$). Solve $y = \dfrac{x - 3}{x - 5}$:
$$xy - 5y = x - 3 \Rightarrow x(y - 1) = 5y - 3 \Rightarrow x = \frac{5y - 3}{y - 1}$$
This is a real number since $y \ne 1$, and $x \ne 5$ (otherwise $5y - 5 = 5y - 3$, impossible), so $x \in A$. Also
$$f\left(\frac{5y - 3}{y - 1}\right) = \frac{\frac{5y - 3}{y - 1} - 3}{\frac{5y - 3}{y - 1} - 5} = \frac{5y - 3 - 3y + 3}{5y - 3 - 5y + 5} = \frac{2y}{2} = y$$
Every $y \in B$ has a pre-image in A, so $f$ is onto. Hence $f$ is **one-one and onto**.

@topic Types of relations
Check whether the relation $S$ in the set of real numbers $\mathbb{R}$ defined by $S = \{(a, b) : \text{where } a - b + \sqrt{2} \text{ is an irrational number}\}$ is reflexive, symmetric or transitive.
--- ans
**Reflexive:** for every $a \in \mathbb{R}$, $a - a + \sqrt{2} = \sqrt{2}$ is irrational, so $(a, a) \in S$. **S is reflexive.**
**Symmetric:** take $a = \sqrt{2}$, $b = 0$: $a - b + \sqrt{2} = 2\sqrt{2}$ is irrational, so $(\sqrt{2}, 0) \in S$.
But $b - a + \sqrt{2} = 0 - \sqrt{2} + \sqrt{2} = 0$ is rational, so $(0, \sqrt{2}) \notin S$. **S is not symmetric.**
**Transitive:** take $a = 0$, $b = -\sqrt{2}$, $c = \sqrt{2}$:
$(a, b)$: $0 + \sqrt{2} + \sqrt{2} = 2\sqrt{2}$ (irrational) $\Rightarrow (0, -\sqrt{2}) \in S$;
$(b, c)$: $-\sqrt{2} - \sqrt{2} + \sqrt{2} = -\sqrt{2}$ (irrational) $\Rightarrow (-\sqrt{2}, \sqrt{2}) \in S$;
$(a, c)$: $0 - \sqrt{2} + \sqrt{2} = 0$ (rational) $\Rightarrow (0, \sqrt{2}) \notin S$. **S is not transitive.**
Hence S is reflexive, but neither symmetric nor transitive.
