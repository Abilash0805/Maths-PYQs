@topic One-one and onto functions
A function $f : \mathbb{R} \to \mathbb{R}$ defined as $f(x) = x^2 - 4x + 5$ is :
(A) injective but not surjective.
(B) surjective but not injective.
(C) both injective and surjective.
(D) neither injective nor surjective.
--- ans D
Not injective: $f(0) = 5 = f(4)$ but $0 \ne 4$.
Not surjective: $f(x) = (x - 2)^2 + 1 \ge 1$, so a value such as $0 \in \mathbb{R}$ (co-domain) has no pre-image; range $= [1, \infty) \ne \mathbb{R}$.
Hence $f$ is **neither injective nor surjective**.

=== 22b | cd | 2 | sub
@topic Differentiability
Check for differentiability of the function f defined by $f(x) = |x - 5|$, at the point $x = 5$.
--- ans
$f(5) = 0$.
$$\text{LHD} = \lim_{h \to 0^-}\frac{f(5 + h) - f(5)}{h} = \lim_{h \to 0^-}\frac{|h|}{h} = \lim_{h \to 0^-}\frac{-h}{h} = -1$$
$$\text{RHD} = \lim_{h \to 0^+}\frac{f(5 + h) - f(5)}{h} = \lim_{h \to 0^+}\frac{h}{h} = 1$$
Since LHD $\ne$ RHD, **$f$ is not differentiable at $x = 5$**.

The area of the circle is increasing at a uniform rate of $2\ \text{cm}^2/\text{s}$. How fast is the circumference of the circle increasing when the radius $r = 5$ cm ?
--- ans
Area $A = \pi r^2 \Rightarrow \dfrac{dA}{dt} = 2\pi r\dfrac{dr}{dt}$.

@topic Logarithmic differentiation
Find $\dfrac{dy}{dx}$, if $(\cos x)^y = (\cos y)^x$.
--- ans
Taking logarithms: $y\log\cos x = x\log\cos y$.
Differentiating both sides w.r.t. $x$:
$$\frac{dy}{dx}\log\cos x + y\cdot\frac{-\sin x}{\cos x} = \log\cos y + x\cdot\frac{-\sin y}{\cos y}\frac{dy}{dx}$$
$$\frac{dy}{dx}\log\cos x - y\tan x = \log\cos y - x\tan y\frac{dy}{dx}$$
$$\frac{dy}{dx}\left(\log\cos x + x\tan y\right) = \log\cos y + y\tan x$$
$$\therefore \frac{dy}{dx} = \frac{\log\cos y + y\tan x}{\log\cos x + x\tan y}$$

=== 26b | cd | 3 | sub
@topic Chain rule and implicit differentiation
If $\sqrt{1 - x^2} + \sqrt{1 - y^2} = a(x - y)$, prove that $\dfrac{dy}{dx} = \sqrt{\dfrac{1 - y^2}{1 - x^2}}$.
--- ans
Put $x = \sin A$, $y = \sin B$, i.e. $A = \sin^{-1}x$, $B = \sin^{-1}y$. Then
$$\cos A + \cos B = a(\sin A - \sin B)$$
$$2\cos\frac{A + B}{2}\cos\frac{A - B}{2} = 2a\cos\frac{A + B}{2}\sin\frac{A - B}{2}$$
$$\Rightarrow \cot\frac{A - B}{2} = a \Rightarrow A - B = 2\cot^{-1}a$$
$$\Rightarrow \sin^{-1}x - \sin^{-1}y = 2\cot^{-1}a \ (\text{a constant})$$
Differentiating w.r.t. $x$:
$$\frac{1}{\sqrt{1 - x^2}} - \frac{1}{\sqrt{1 - y^2}}\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = \frac{\sqrt{1 - y^2}}{\sqrt{1 - x^2}} = \sqrt{\frac{1 - y^2}{1 - x^2}}$$
Hence proved.

Find the particular solution of the differential equation $\dfrac{dy}{dx} - 2xy = 3x^2e^{x^2}$; $y(0) = 5$.
--- ans

--- ans
$$\frac{dy}{dx} = -\frac{xy + y^2}{x^2} = -\frac{y}{x} - \left(\frac{y}{x}\right)^2$$
which is homogeneous. Put $y = vx$, $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = -v - v^2 \Rightarrow x\frac{dv}{dx} = -(v^2 + 2v)$$
Separating the variables:
$$\int \frac{dv}{v(v + 2)} = -\int \frac{dx}{x} \Rightarrow \frac{1}{2}\int\left(\frac{1}{v} - \frac{1}{v + 2}\right)dv = -\log|x| + \log|C|$$
$$\frac{1}{2}\log\left|\frac{v}{v + 2}\right| = \log\left|\frac{C}{x}\right| \Rightarrow \left|\frac{v}{v + 2}\right| = \frac{C^2}{x^2}$$
Replacing $v = \dfrac{y}{x}$: $\dfrac{y}{y + 2x} = \dfrac{k}{x^2}$, i.e. the general solution is
$$x^2y = k(y + 2x)$$
