(B) $\dfrac{1}{8}$
(C) $\dfrac{1}{2}$

If three non-zero vectors are $\vec{a}$, $\vec{b}$ and $\vec{c}$ such that $\vec{a}\cdot\vec{b} = \vec{a}\cdot\vec{c}$ and $\vec{a} \times \vec{b} = \vec{a} \times \vec{c}$, then show that $\vec{b} = \vec{c}$.

@topic One-one and onto functions
Prove that the greatest integer function $f : \mathbb{R} \to \mathbb{R}$, given by $f(x) = [x]$, is neither one-one nor onto.
--- ans
**Not one-one:** $1.1, 1.2 \in \mathbb{R}$ with $1.1 \ne 1.2$, but $f(1.1) = [1.1] = 1 = [1.2] = f(1.2)$. So $f$ is not one-one.

=== 27a | de | 3 | sub
@topic Homogeneous equations
Find the particular solution of the differential equation $\dfrac{dy}{dx} = \dfrac{xy}{x^2 + y^2}$, given that $y = 1$ when $x = 0$.
--- ans
The equation is homogeneous. Put $y = vx$, $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v}{1 + v^2} \Rightarrow x\frac{dv}{dx} = \frac{v - v - v^3}{1 + v^2} = -\frac{v^3}{1 + v^2}$$
Separating the variables:
$$\int\frac{1 + v^2}{v^3}\,dv = -\int\frac{dx}{x} \Rightarrow \int\left(\frac{1}{v^3} + \frac{1}{v}\right)dv = -\int\frac{dx}{x}$$
$$-\frac{1}{2v^2} + \log|v| = -\log|x| + c \Rightarrow -\frac{x^2}{2y^2} + \log\left|\frac{y}{x}\right| + \log|x| = c \Rightarrow -\frac{x^2}{2y^2} + \log|y| = c$$
At $x = 0$, $y = 1$: $0 + \log 1 = c \Rightarrow c = 0$.
$$\boxed{\log|y| = \dfrac{x^2}{2y^2}}$$
