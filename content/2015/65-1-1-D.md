@topic Partial fractions (trigonometric substitution)
Find : $\displaystyle\int \frac{dx}{\sin x + \sin 2x}$
--- ans
$$I = \int \frac{dx}{\sin x(1 + 2\cos x)} = \int \frac{\sin x\,dx}{\sin^2 x(1 + 2\cos x)} = \int \frac{\sin x\,dx}{(1 - \cos x)(1 + \cos x)(1 + 2\cos x)}$$
Put $\cos x = t \Rightarrow -\sin x\,dx = dt$:
$$I = -\int \frac{dt}{(1 - t)(1 + t)(1 + 2t)}$$
Let $\dfrac{1}{(1 - t)(1 + t)(1 + 2t)} = \dfrac{A}{1 - t} + \dfrac{B}{1 + t} + \dfrac{C}{1 + 2t}$, so $1 = A(1 + t)(1 + 2t) + B(1 - t)(1 + 2t) + C(1 - t)(1 + t)$.
$t = 1$: $A = \dfrac{1}{6}$; $\quad t = -1$: $B = -\dfrac{1}{2}$; $\quad t = -\dfrac{1}{2}$: $C = \dfrac{4}{3}$.
$$I = -\int\left[\frac{1/6}{1 - t} - \frac{1/2}{1 + t} + \frac{4/3}{1 + 2t}\right]dt = \frac{1}{6}\log|1 - t| + \frac{1}{2}\log|1 + t| - \frac{2}{3}\log|1 + 2t| + C$$
$$\therefore\ I = \frac{1}{6}\log|1 - \cos x| + \frac{1}{2}\log|1 + \cos x| - \frac{2}{3}\log|1 + 2\cos x| + C$$

=== 10 | int | 4 | sub
@topic Properties of definite integrals (even and odd functions)
Evaluate: $\displaystyle\int_{-\pi}^{\pi} (\cos ax - \sin bx)^2\,dx$
--- ans
$$I = \int_{-\pi}^{\pi} \left(\cos^2 ax + \sin^2 bx\right)dx - \int_{-\pi}^{\pi} 2\cos ax\sin bx\,dx$$
Let $g(x) = 2\cos ax\sin bx$. Then $g(-x) = 2\cos ax\,(-\sin bx) = -g(x)$, so $g$ is odd and its integral over $[-\pi, \pi]$ is $0$.
$\cos^2 ax + \sin^2 bx$ is even, so
$$I = 2\int_0^{\pi} \left(\frac{1 + \cos 2ax}{2} + \frac{1 - \cos 2bx}{2}\right)dx = \int_0^{\pi} (2 + \cos 2ax - \cos 2bx)\,dx$$
$$= \left[2x + \frac{\sin 2ax}{2a} - \frac{\sin 2bx}{2b}\right]_0^{\pi} = 2\pi + \frac{\sin 2a\pi}{2a} - \frac{\sin 2b\pi}{2b}$$
(In particular, when $a$ and $b$ are integers, $I = 2\pi$.)

@topic Theorem of total probability
A bag A contains 4 black and 6 red balls and bag B contains 7 black and 3 red balls. A die is thrown. If 1 or 2 appears on it, then bag A is chosen, otherwise bag B. If two balls are drawn at random (without replacement) from the selected bag. find the probability of one of them being red and another black.
--- ans
Let $E_1$: bag A is chosen, $E_2$: bag B is chosen, $E$: one ball is red and the other black.
$$P(E_1) = \frac{2}{6} = \frac{1}{3},\quad P(E_2) = \frac{4}{6} = \frac{2}{3}$$
$$P(E|E_1) = \frac{{}^4C_1\cdot{}^6C_1}{{}^{10}C_2} = \frac{24}{45} = \frac{8}{15},\quad P(E|E_2) = \frac{{}^7C_1\cdot{}^3C_1}{{}^{10}C_2} = \frac{21}{45} = \frac{7}{15}$$
By the theorem of total probability:
$$P(E) = P(E_1)P(E|E_1) + P(E_2)P(E|E_2) = \frac{1}{3}\cdot\frac{8}{15} + \frac{2}{3}\cdot\frac{7}{15} = \frac{8 + 14}{45} = \frac{22}{45}$$

@topic Vector (cross) product
If $\vec{r} = x\hat{i} + y\hat{j} + z\hat{k}$, find $(\vec{r} \times \hat{i}) \cdot (\vec{r} \times \hat{j}) + xy$
--- ans
Using $\hat{i} \times \hat{i} = \vec{0}$, $\hat{j} \times \hat{i} = -\hat{k}$, $\hat{k} \times \hat{i} = \hat{j}$:
$$\vec{r} \times \hat{i} = (x\hat{i} + y\hat{j} + z\hat{k}) \times \hat{i} = -y\hat{k} + z\hat{j} = 0\hat{i} + z\hat{j} - y\hat{k}$$
Using $\hat{i} \times \hat{j} = \hat{k}$, $\hat{j} \times \hat{j} = \vec{0}$, $\hat{k} \times \hat{j} = -\hat{i}$:
$$\vec{r} \times \hat{j} = (x\hat{i} + y\hat{j} + z\hat{k}) \times \hat{j} = x\hat{k} - z\hat{i} = -z\hat{i} + 0\hat{j} + x\hat{k}$$
$$(\vec{r} \times \hat{i}) \cdot (\vec{r} \times \hat{j}) = (0)(-z) + (z)(0) + (-y)(x) = -xy$$
$$\therefore\ (\vec{r} \times \hat{i}) \cdot (\vec{r} \times \hat{j}) + xy = -xy + xy = 0$$

@topic Derivative of inverse trigonometric function by substitution
If $y = \tan^{-1}\left(\dfrac{\sqrt{1 + x^2} + \sqrt{1 - x^2}}{\sqrt{1 + x^2} - \sqrt{1 - x^2}}\right)$, $x^2 \le 1$, then find $\dfrac{dy}{dx}$.
--- ans
Put $x^2 = \cos\theta$, i.e. $\theta = \cos^{-1}x^2$. As $0 \le x^2 \le 1$, $\theta \in \left[0, \dfrac{\pi}{2}\right]$, so $\dfrac{\theta}{2} \in \left[0, \dfrac{\pi}{4}\right]$.
Then $\sqrt{1 + \cos\theta} = \sqrt{2}\cos\dfrac{\theta}{2}$ and $\sqrt{1 - \cos\theta} = \sqrt{2}\sin\dfrac{\theta}{2}$.
$$y = \tan^{-1}\left(\frac{\cos\frac{\theta}{2} + \sin\frac{\theta}{2}}{\cos\frac{\theta}{2} - \sin\frac{\theta}{2}}\right) = \tan^{-1}\left(\frac{1 + \tan\frac{\theta}{2}}{1 - \tan\frac{\theta}{2}}\right) = \tan^{-1}\left[\tan\left(\frac{\pi}{4} + \frac{\theta}{2}\right)\right]$$
For $x \ne 0$, $\dfrac{\pi}{4} + \dfrac{\theta}{2} \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$, which lies in $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$, so
$$y = \frac{\pi}{4} + \frac{\theta}{2} = \frac{\pi}{4} + \frac{1}{2}\cos^{-1}x^2$$
Differentiating w.r.t. $x$:
$$\frac{dy}{dx} = \frac{1}{2}\cdot\frac{-1}{\sqrt{1 - x^4}}\cdot 2x = -\frac{x}{\sqrt{1 - x^4}}$$

@topic Second order derivative – parametric form
If $x = a\cos\theta + b\sin\theta$, $y = a\sin\theta - b\cos\theta$, show than $y^2\dfrac{d^2y}{dx^2} - x\dfrac{dy}{dx} - y = 0$.
--- ans
(The printed result has a sign misprint: the correct relation, proved below, is $y^2\dfrac{d^2y}{dx^2} - x\dfrac{dy}{dx} + y = 0$.)
$$\frac{dx}{d\theta} = -a\sin\theta + b\cos\theta = -y,\qquad \frac{dy}{d\theta} = a\cos\theta + b\sin\theta = x$$
$$\therefore\ \frac{dy}{dx} = \frac{x}{-y} = -\frac{x}{y} \Rightarrow y\frac{dy}{dx} + x = 0 \quad\cdots(1)$$
Differentiating (1) w.r.t. $x$:
$$y\frac{d^2y}{dx^2} + \left(\frac{dy}{dx}\right)^2 + 1 = 0$$
Using $\dfrac{dy}{dx} = -\dfrac{x}{y}$ for one factor: $y\dfrac{d^2y}{dx^2} - \dfrac{x}{y}\cdot\dfrac{dy}{dx} + 1 = 0$.
Multiplying by $y$:
$$y^2\frac{d^2y}{dx^2} - x\frac{dy}{dx} + y = 0$$
Hence proved (with $+y$; with $-y$ the left side would equal $-2y \ne 0$).

@topic Rate of change of quantities
The side of an equilateral triangle is increasing at the rate of 2 cm/s. At what rate is its area increasing when the side of the triangle is 20 cm ?
--- ans
Let $x$ be the side and $A$ the area of the equilateral triangle at time $t$. Given $\dfrac{dx}{dt} = 2$ cm/s.
$$A = \frac{\sqrt{3}}{4}x^2 \Rightarrow \frac{dA}{dt} = \frac{\sqrt{3}}{4}\cdot 2x\,\frac{dx}{dt} = \frac{\sqrt{3}}{2}\,x\,\frac{dx}{dt}$$
At $x = 20$ cm:
$$\frac{dA}{dt} = \frac{\sqrt{3}}{2}\cdot 20\cdot 2 = 20\sqrt{3}\ \text{cm}^2/\text{s}$$
The area is increasing at the rate of $20\sqrt{3}\ \text{cm}^2/\text{s}$.

=== 20 | rf | 6 | sub
@topic Equivalence relation
Let N denote the set of all natural numbers and R be the relation on $\mathbb{N} \times \mathbb{N}$ defined by $(a, b)\,R\,(c, d)$ if $ad(b + c) = bc(a + d)$. Show that R is an equivalence relation.
--- ans
Since all of $a, b, c, d \in \mathbb{N}$ are non-zero, dividing by $abcd$:
$$(a, b)\,R\,(c, d) \iff \frac{b + c}{bc} = \frac{a + d}{ad} \iff \frac{1}{c} + \frac{1}{b} = \frac{1}{d} + \frac{1}{a}$$

**Reflexive:** For any $(a, b) \in \mathbb{N} \times \mathbb{N}$, $ab(b + a) = ba(a + b)$. So $(a, b)\,R\,(a, b)$; R is reflexive.

**Symmetric:** Let $(a, b)\,R\,(c, d)$, i.e. $ad(b + c) = bc(a + d)$.
Then $cb(d + a) = da(c + b)$ (the same equation with the sides interchanged), which means $(c, d)\,R\,(a, b)$. So R is symmetric.

**Transitive:** Let $(a, b)\,R\,(c, d)$ and $(c, d)\,R\,(e, f)$. Then
$$\frac{1}{b} + \frac{1}{c} = \frac{1}{a} + \frac{1}{d} \quad\cdots(1) \qquad \frac{1}{d} + \frac{1}{e} = \frac{1}{c} + \frac{1}{f} \quad\cdots(2)$$
Adding (1) and (2) and cancelling $\dfrac{1}{c} + \dfrac{1}{d}$:
$$\frac{1}{b} + \frac{1}{e} = \frac{1}{a} + \frac{1}{f} \Rightarrow \frac{b + e}{be} = \frac{a + f}{af} \Rightarrow af(b + e) = be(a + f)$$
So $(a, b)\,R\,(e, f)$; R is transitive.

Since R is reflexive, symmetric and transitive, **R is an equivalence relation**.

@topic Linear differential equation (dx/dy + Px = Q)
Solve the differential equation:
$$(\tan^{-1}y - x)\,dy = (1 + y^2)\,dx.$$
--- ans
$$\frac{dx}{dy} = \frac{\tan^{-1}y - x}{1 + y^2} \Rightarrow \frac{dx}{dy} + \frac{1}{1 + y^2}\,x = \frac{\tan^{-1}y}{1 + y^2}$$
This is linear in $x$ with $P = \dfrac{1}{1 + y^2}$, $Q = \dfrac{\tan^{-1}y}{1 + y^2}$.
$$\text{I.F.} = e^{\int \frac{dy}{1 + y^2}} = e^{\tan^{-1}y}$$
Solution: $x\,e^{\tan^{-1}y} = \displaystyle\int \frac{\tan^{-1}y\;e^{\tan^{-1}y}}{1 + y^2}\,dy$.
Put $\tan^{-1}y = t$, $\dfrac{dy}{1 + y^2} = dt$:
$$\int t\,e^{t}\,dt = t\,e^{t} - e^{t} + C = e^{\tan^{-1}y}\left(\tan^{-1}y - 1\right) + C$$
$$\therefore\ x\,e^{\tan^{-1}y} = e^{\tan^{-1}y}\left(\tan^{-1}y - 1\right) + C \quad\text{or}\quad x = \tan^{-1}y - 1 + C\,e^{-\tan^{-1}y}$$

=== 22b | de | 6 | sub
@topic Homogeneous differential equation – particular solution
Find the particular solution of the differential equation $\dfrac{dy}{dx} = \dfrac{xy}{x^2 + y^2}$ given that $y = 1$, when $x = 0$.
--- ans
$\dfrac{dy}{dx} = \dfrac{y/x}{1 + (y/x)^2}$ — a homogeneous equation.
Put $y = vx \Rightarrow \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:
$$v + x\frac{dv}{dx} = \frac{v}{1 + v^2} \Rightarrow x\frac{dv}{dx} = \frac{v - v - v^3}{1 + v^2} = -\frac{v^3}{1 + v^2}$$
$$\Rightarrow \frac{1 + v^2}{v^3}\,dv = -\frac{dx}{x} \Rightarrow \int\left(\frac{1}{v^3} + \frac{1}{v}\right)dv = -\int \frac{dx}{x}$$
$$\Rightarrow -\frac{1}{2v^2} + \log|v| = -\log|x| + C \Rightarrow \log|vx| - \frac{x^2}{2y^2} = C$$
$$\Rightarrow \log|y| - \frac{x^2}{2y^2} = C$$
Given $y = 1$ when $x = 0$: $\log 1 - 0 = C \Rightarrow C = 0$.
$\therefore$ The particular solution is
$$\log|y| - \frac{x^2}{2y^2} = 0 \quad\text{or}\quad x^2 = 2y^2\log|y|$$

@topic Local maxima and minima (second derivative test)
Find the local maxima and local minima, of the function $f(x) = \sin x - \cos x$, $0 < x < 2\pi$. Also find the local maximum and local minimum values.
--- ans
$$f'(x) = \cos x + \sin x$$
$f'(x) = 0 \Rightarrow \sin x = -\cos x \Rightarrow \tan x = -1 \Rightarrow x = \dfrac{3\pi}{4},\ \dfrac{7\pi}{4}$ in $(0, 2\pi)$.
$$f''(x) = -\sin x + \cos x$$
At $x = \dfrac{3\pi}{4}$: $f''\left(\dfrac{3\pi}{4}\right) = -\dfrac{1}{\sqrt{2}} - \dfrac{1}{\sqrt{2}} = -\sqrt{2} < 0$, so $x = \dfrac{3\pi}{4}$ is a point of **local maximum**.
Local maximum value $= f\left(\dfrac{3\pi}{4}\right) = \dfrac{1}{\sqrt{2}} - \left(-\dfrac{1}{\sqrt{2}}\right) = \sqrt{2}$.

At $x = \dfrac{7\pi}{4}$: $f''\left(\dfrac{7\pi}{4}\right) = \dfrac{1}{\sqrt{2}} + \dfrac{1}{\sqrt{2}} = \sqrt{2} > 0$, so $x = \dfrac{7\pi}{4}$ is a point of **local minimum**.
Local minimum value $= f\left(\dfrac{7\pi}{4}\right) = -\dfrac{1}{\sqrt{2}} - \dfrac{1}{\sqrt{2}} = -\sqrt{2}$.
